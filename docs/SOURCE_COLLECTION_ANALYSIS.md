## 경로를 늘렸을 때의 비용 계산

경로 수만으로 시간을 비례 예측하지 않는다. 출처마다 신규 원문 수, 피드 보존 기간, 아카이브 페이지 수, 본문 크기, 요청 간격, PDF/OCR 여부가 다르다.

동시6경로의 이상적인 경과 시간 하한은 `max(가장 긴 경로 시간, 경로 시간 합계 / 6)`이다. 이번 데이터에서는 약12분14초다. 실제15분9초와의 차이는 경로 시작 순서·순차 창·병합·작업 분배의 영향을 포함한다. 이 하한을 다음 실행의 보장 시간으로 사용하지 않는다.

가령 추가30경로의 순차 작업 시간이 경로당20초이면 합계600초로, 작업이 고르게 분배될 때 최소 약100초의 worker 부담이다. 반면 상세300개에 원문당3초가 걸리는 새 매체 하나는 그 경로에 약15분이 필요하다. 두 예의 숫자는 계산 가정이며 새 출처 실측값이 아니다. 실제로195개를 전부 활성화한 실행 시간은 아직 측정하지 않았다.

보관 예산도 새 원문 판본·parse와 실행 기록 증가량으로 정한다. 이번 참조량173MiB를 하루 증가량이라고 곱해 사용하지 않는다. 조건부 요청과 판본 재사용, 기록 보존 기간을 적용한 뒤 실제 새 파일 증가량을 재야 한다.
