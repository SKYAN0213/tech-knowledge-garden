# 연결 지도

IT·AI·로봇 뉴스를 읽으며 뜻과 작동 원리를 배울 필요가 있는 **전문 용어**를 연결한다. 일반 단어를 많이 모으는 지도가 아니다. 기사 제목은 노드로 만들지 않으며, 용어를 선택하면 관련 뉴스를 표시한다.

## 노드 선정

GPT가 원문을 읽고 다음 조건을 모두 확인한 용어만 포함한다.

1. 일반 독자가 기사 이해를 위해 별도 설명을 필요로 하는 기술 용어다. 구체적인 메커니즘, 프로토콜, 모델 구조, 평가 방법, 측정 개념 또는 보안 원리여야 한다.
2. 무엇인지, 어떻게 작동하는지, 무엇과 혼동하기 쉬운지를 독립적으로 설명할 수 있다.
3. 실제로 읽은 일차 자료, 한 문장 정의, 완성된 설명 노트가 있다.
4. 왜 이 용어를 배워야 하는지 구체적인 선정 이유를 남긴다.

빈도, 긴 이름, 영문 표기, 약어라는 이유만으로 포함하지 않는다. 책임·상태·가격·허용·근거 같은 일반어, 응용 분야나 사업 주제만 묶은 넓은 분류, 제품·회사·기사 제목은 노드로 만들지 않는다. `keywords`는 노트와 사이트 검색의 보조 정보이며 지도 노드나 기사 연결을 자동 생성하는 재료가 아니다. `aliases`에는 같은 용어의 정확한 이름·약어만 넣고 일반 연관어를 넣지 않는다.

선정 결과는 각 canonical concept의 frontmatter에 기록한다.

```yaml
map_review:
  decision: include
  kind: mechanism
  reason: 문맥이 길어질 때 추론 메모리와 속도가 달라지는 이유를 키·값 재사용으로 설명하는 기술이다.
  reviewed: 2026-09-13
```

`kind`는 `mechanism`, `protocol`, `architecture`, `model`, `evaluation`, `metric`, `security` 중 하나다. 제외할 때는 `decision: exclude`와 구체적인 이유·검토일을 기록한다. 미검토 노트는 자동으로 포함하지 않는다. 포함 결정에 정의·설명 경로·출처·선정 이유가 빠지면 검사가 실패한다. 이 검사는 구조를 확인하며 용어의 학습 가치는 GPT의 원문 검토로 판단한다. 사용자의 노트별 공개 승인 절차가 아니다. 제외된 문서와 기존 링크는 읽을 수 있다.

2026-09-13 검토 결과는 [선정 기록](../data/graph-node-review-2026-09-13.json)에 있다. 기존 23개 문서 중 12개를 포함하고 넓은 주제 11개는 지도에서 제외했다. 실제 기사에 필요한 KV 캐시, OIDC, 제로샷 추론, p95·p99 지연을 원문으로 설명한 독립 노트 4개를 추가했다. 현재 노드는 16개, 확인된 연결은 17개다. 숫자를 맞추는 목표나 상한은 없으며 적합한 새 용어가 축적되면 늘어난다.

## 연결과 기사

`learning-connections/v3`는 선정된 전문 용어만 노드로 제공한다. 선은 양쪽 모두 선정된 용어 사이의 **확인된 무방향 연관성**이다. 같은 쌍의 선은 하나로 합치고 여러 확인 이유는 보존한다. 제외된 중간 노드를 제거하면서 이웃을 임의로 이어 붙이지 않는다. 공동 등장만으로 선을 만들지 않는다.

```yaml
connections:
  - target: inference
    reason: 모델 서빙에서 이전 토큰의 어텐션 키·값을 재사용해 반복 계산을 줄인다.
```

연관성이 확인되면 충분하며 방향·참조 유형·인용은 필수가 아니다. 원문이 있으면 `evidence: [https://...]`를 추가한다. 기존 `relations`의 유형·근거·source/inference 구분은 원본에서 보존한다. Obsidian 본문에는 `- [[Knowledge/…|용어]] — 확인한 이유`를 적고, 연결이 없으면 `없음`으로 둔다. `npm run refresh`가 같은 선정 기준으로 Obsidian 지도의 용어 목록과 관계 표를 만든다.

뉴스는 별도 `articles` 데이터이며 다음 순서로 표시한다.

1. 기사에 해당 용어가 명시적으로 지정됨.
2. 제목·요약·실제 기사 본문에 선정된 용어의 정식 이름 또는 정확한 별칭이 등장함.
3. 확인된 선 하나로 연결된 이웃 용어에 해당하는 기사. 경유 용어를 표시함.

같은 순위에서는 최신 기사가 먼저다. 세 번째 단계에서 다시 이웃을 따라 확장하지 않는다. 한글 정규화와 영문 단어 경계를 적용하며 안내 문구·섹션명·출처 목록은 매칭에서 제외한다. 이는 주제 연결이며 인과관계나 과거 기사 사실의 재검증을 뜻하지 않는다. 42개 기사 중 현재 30개에 선정 용어가 직접 연결되며, 나머지도 뉴스·브리핑에서 계속 읽을 수 있다.

홈과 상단 메뉴에서 전체 지도를 볼 수 있다. 기사·개념 페이지는 선정 용어가 있을 때만 해당 용어에 초점을 둔 지도를 표시한다. 선택 상태는 `?focus=`로 공유한다. 이전 기사 초점 주소는 해당 기사의 첫 선정 용어로, 이전 키워드 주소는 일치하는 선정 용어로 연결한다. 일반어·제외 항목의 옛 초점은 해제한다.

## 엔진과 조작

[Sigma.js 3](https://www.sigmajs.org/)의 WebGL, [Graphology ForceAtlas2](https://graphology.github.io/standard-library/layout-forceatlas2.html)의 자동 배치, Louvain 커뮤니티 색상을 유지한다. 연결 가중치·반발력·노드 크기를 고려해 작은 점과 가는 선을 배치한다. 모두 MIT 라이선스이며 외부 서비스 호출이나 이용료가 없다.

| 엔진                                                           | 적합한 용도             | 선택                                     |
| -------------------------------------------------------------- | ----------------------- | ---------------------------------------- |
| Sigma.js + ForceAtlas2                                         | 연결을 탐색하는 2D 지도 | 사용 중                                  |
| [3d-force-graph](https://github.com/vasturiano/3d-force-graph) | 회전 가능한 3D 네트워크 | 깊이·가려짐이 필요한 요구가 생길 때 검토 |
| [Cytoscape.js](https://js.cytoscape.org/)                      | 그래프 편집·분석        | 편집기 요구가 생길 때 검토               |

검색·용어 목록·연결 필터·이동·확대·드래그·맞춤을 지원한다. 다시 배치는 Web Worker에서 600회 계산한다. WebGL이 없으면 검색·용어 목록·관련 뉴스로 전환하며, Worker 실패 시 현재 지도를 유지한다. 노드 수를 시각적 밀도를 위해 부풀리지 않는다.

## 검증

```sh
npm test
npx tsc --noEmit
npm run build
node scripts/verify-site.mjs
```

일반 키워드의 자동 유입 방지, 포함 결정의 필수 정보, 실제 별칭 매칭, 제외 노드의 연결 우회 방지, 기사 순위와 탐색 범위, 이전 초점 주소, 문서·문단 링크와 RSS를 검사한다. 브라우저에서는 일반어 검색 결과 없음, 전문 용어 선택 → 정의·관련 기사 → 기사 열기, 홈·본문 지도, 재배치, 모바일 너비와 그래픽 미지원 목록을 확인한다.

`node scripts/benchmark-connections.mjs`는 현재 데이터와 합성 노드 1,000개·연결 2,200개의 배치 계산만 측정한다. 합성 자료는 공개 화면에 추가하지 않으며 결과를 실제 휴대폰 성능으로 해석하지 않는다.
