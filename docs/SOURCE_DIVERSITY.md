# 출처를 넓혀 조사하기

2026-09-14 사용자 요청. 기존 8개 분야, 기술·제품/기업·운영 조사, 국내외 논문·교수 창업, 추가 로봇 제조사 조사를 모두 유지한다. 이 규칙은 소수 매체만 탐색하도록 해석될 수 있는 과거 출처 목록보다 우선한다. 추가 유료 API·구독·예약 없이 기존 GPT 웹 조사와 오전 8시 실행에서 적용한다.

## 발견 경로와 기사 근거

`data/research-watchlist.json`의 기업·기관과 `data/research-source-channels.json`의 추가 경로를 함께 읽는다. 둘 다 출발점이며 허용 목록이나 조사의 상한이 아니다. 검색·전문지·학회 프로그램·전시회 참가사 목록에서 사건과 새로운 당사자를 발견한 뒤, 개별 발표·공시·논문·인터뷰 원문을 읽는다. 검색 요약, 재전재, 행사 일정 자체를 기사 근거로 쓰지 않는다.

| 출처 종류 | 조사 목적 |
| --- | --- |
| 산업 전문지·지역 매체 | 대형 기술기업의 블로그에 없는 기업·납품·현장·인력·투자 사건 발견. 로봇신문, 디일렉, KIPOST, 전자신문, The Robot Report 등을 확인한다. |
| 기업 발표·IR·공시 | 제품·사업 전략·실적·인수·인력·설비의 당사자 자료. 국내 DART/KIND와 해당 국가 공시, 기업 IR을 함께 확인한다. |
| 고객·부품사·시스템 통합사 | 고객의 도입·공장 가동·조달, 감속기·서보·센서·제어기 공급, 설치·통합 사례를 당사자 양쪽에서 확인한다. 제조사의 홍보만으로 고객 성과를 단정하지 않는다. |
| 협회·표준·공공기관 | IFR/A3 등 업계 통계, 정책·표준·보조금·인증·안전·수출 규제. 협회 자체 통계와 회원사 보도자료를 구분한다. |
| 학회·학술지·연구실 | arXiv/OpenReview/학회 원문과 대학 발표를 함께 탐색한다. 로봇·제조는 ICRA/IROS/RSS/자동화·제어·용접 연구도 포함한다. |
| 기술이전·창업·투자자 | 대학 TLO·창업원·연구실·회사·투자자의 발표를 연결한다. 교수 창업과 자문·공동저자·기술이전의 구분은 기존 근거 기준을 유지한다. |

전문지나 독립 매체를 읽는 것은 원문 검증의 대체가 아니다. 기술 설명·성능·용어·재무 수치는 일차 자료로 대조한다. 독립 취재의 사실·인터뷰는 기자·날짜·인용 주체와 원문을 확인하고 보도에 귀속하여 쓸 수 있다. 기업이 발표하지 않았다는 이유만으로 신뢰할 수 있는 독립 취재를 자동 배제하지 않는다. 보도자료를 그대로 전한 매체 여러 곳은 독립 근거 여러 개로 세지 않는다. 유료 본문을 읽지 못하면 검색 미리보기로 내용을 채우지 않는다.

## 매일 수행 순서

1. `npm run context`의 기존 사건·출처 분포와 추적 목록을 읽는다. 8개 분야 × 두 조사 경로 × 국내/해외 32행을 준비한다.
2. 각 분야에서 국내·해외 산업 보도와 공식 경로를 먼저 훑는다. 이후 발견한 사건의 개별 원문을 확인한다. OpenAI·GitHub 등 특정 출처에서 충분한 기사를 찾았어도 다른 분야의 최초 탐색을 생략하지 않는다.
3. 명단 밖 검색을 분야별로 한 번 이상 수행한다. 기업명 외에 `수주·납품·공장 가동·사업 매각·감원·기술이전` 등 사건과 `용접·도장·핸들링·반도체 후공정` 등 공정·제품으로 검색한다. 영어는 orders/deployment/commissioning/divestiture/workforce/licensing 등을 쓴다.
4. 로봇 제조사 추가 관심 범위는 HD현대로보틱스·두산로보틱스·FANUC·KUKA·ABB·야스카와·가와사키·나치·Universal Robots·Techman·레인보우로보틱스·ESTUN·EFORT·JAKA·AUBO를 유지한다. 실제 법인·브랜드·부문·거래 상태는 원문으로 구분한다. 일본은 `決算・受注・新製品・溶接・協働ロボット`, 중국은 `工业机器人・协作机器人・订单・投产・融资`, 독일은 `Auftrag・Werk・Inbetriebnahme・Geschäftsbericht` 등 현지어로도 조사한다. 한국어·영어판만 확인하고 끝내지 않는다.
5. 자료가 적은 분야에서 고객·공급사·협회·연구실 경로를 추가 확인한다. 접속 실패 시 GPT 검색 → 공식 사이트의 해당 언어 목록 → 개별 공식 PDF/공시 → 상대 당사자 자료 순으로 전환한다. 홈페이지 200 응답·로그인 화면·검색 스니펫을 내용 확인으로 세지 않는다.
6. 분야별 최대 5건·총 40건을 유지하고 사건의 정보 가치로 선정한다. 같은 회사의 사소한 변경은 중요 사건을 밀어내지 않도록 검토한다. 같은 사건의 여러 보도·언어판·여러 브리핑 등장은 합쳐 조사한다.
7. 발행 전 최근 7일·30일의 출처 분포와 조사 기록을 대조한다. 아래 편중 조건이면 부족한 경로를 추가 조사한다. 편중을 해소하려고 오래된 뉴스나 약한 자료를 채우지 않는다.

## 발행 편중과 실제 조사 기록

`npm run context`의 `source_diversity`는 새 형식에서 추출된 고유 사건의 첫 원문 도메인 분포다. 기사 수는 시장 성장·회사 점유율·조사 완성도가 아니다. 구형 미추출 회차 수와 날짜 범위를 함께 표시한다. CDN이나 서로 다른 언어 도메인이 같은 발표의 사본인지 GPT가 대조한다.

- 10건 이상인 기간에서 한 출처가 40%를 넘거나 상위 두 출처가 60%를 넘으면 추가 탐색 신호로 삼는다. 자동 삭제나 발행 금지 기준으로 쓰지 않는다.
- 실제 조사에는 분야·지역·출처 종류·발견 URL·최종 원문 URL·언어·내용 확인 시점·판정을 기록한다. 명단에 등록하거나 접속에 성공했다고 조사 완료로 세지 않는다.
- 7일간 특정 분야·지역·고객/공급망·연구/사업화 경로의 확인이 없으면 다음 실행에서 우선 조사한다. 단순 발행 건수 비율로 이를 대신하지 않는다.
- 접속·취재 실패와 추가 조사 사유는 비공개 Research에 보관한다. 공개 뉴스·브리핑·RSS에는 운영 안내를 넣지 않는다.
- 기존 coverage_end를 유지한다. 이번 확장으로 뒤늦게 찾은 과거 사건은 소급 검토 또는 배경 기록으로 처리하며 오늘의 새 소식으로 재발행하지 않는다.
