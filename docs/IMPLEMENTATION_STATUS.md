## 앱 프로젝트 연결 대기

실제 파일과 저장소는 `tech-knowledge-garden`에 있으며 원본 개인 비서 프로젝트와 iCloud Tech Knowledge는 보존되어 있습니다. 현재 대화와 예약 작업의 Codex 앱 프로젝트 ID는 아직 기존 프로젝트입니다.

Codex에서 이 저장소 폴더를 프로젝트로 등록해야 새 프로젝트 ID로 예약 작업을 연결할 수 있습니다. 현재 제공된 도구에는 프로젝트 등록·현재 대화 이동 기능이 없으며 Codex 앱의 컴퓨터 제어도 차단되어 있습니다. 파일이나 앱 내부 데이터베이스를 수정해 이를 우회하지 않았습니다. 예약 프롬프트는 새 저장소를 절대 경로로 지정하지만, 새 프로젝트에 연결된 실제 예약 실행은 아직 검증하지 않았습니다.

등록 후에는 `list_projects`에서 이 경로의 ID를 확인하고 `automation_update`로 기존 `tech-ai-briefing-08`의 projectId만 변경합니다. 새 예약을 만들지 않습니다. 새로운 대화가 필요하면 이 프로젝트에서 시작하고 AGENTS.md와 이 문서를 읽어 이어갑니다.
