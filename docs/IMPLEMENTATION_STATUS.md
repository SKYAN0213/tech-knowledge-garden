- 주제별로 현재 판단, 반대 조건, 다음 확인, 날짜별 근거, 재사용 원칙과 전문 개념을 연결한다. 원문 사건의 반복 등장으로 집계가 늘지 않는다. 최근 7일과 이전 7일 수는 수집·정리 범위의 기록이며 산업 성장률이 아니다. 미정리와 검토한 빈 결과를 구분한다.
