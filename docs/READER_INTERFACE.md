# 공개 읽기 화면

홈에서 최근 브리핑의 주요 소식과 분야별 최근 기사를 읽고, 뉴스·브리핑·지식·기업·연결 지도를 탐색한다. 전문용어·누적 주제·지난 브리핑은 홈의 보조 열에서 연결한다. 모바일에서는 메뉴를 가로로 배치하고 본문을 한 열로 표시한다.

- `News/index`: 기존 기사 목록과 분야·테마·기업 필터. 기사 URL과 RSS GUID는 보존한다.
- `Knowledge/index`: 검토한 전문용어 정의와 관련 기사. 기업·제품명은 용어 노드로 만들지 않는다.
- `Companies/index`: 관심 회사의 실제 기사 태그를 기준으로 날짜순 소식을 조회한다. 회사 별칭을 정체성으로 자동 병합하지 않는다.
- `Briefings/weekly`: 원 발표일 기준 기간별 사건. 기사 빈도를 시장 성장으로 해석하지 않는다.

용어 검색은 `q`, 회사 선택은 `company`, 기간은 `from/to`, 전체 검색은 `search/search_type`, 기존 뉴스 필터는 `q/sector/theme/entity/kind`에 보존한다. 공유 URL·뒤로가기를 지원하며 잘못된 기간이나 없는 회사는 전체 결과로 대체하지 않는다.

전체 검색은 이미 공개한 기사 문장을 반환한다. 사건별 발표일·기사·해당 원문을 보존하고, 정의의 검토 날짜와 회사/주제의 최근 기사 날짜를 구분한다. 새 사실이나 답변을 생성하지 않는다. Esc로 검색을 닫으면 검색 버튼으로 포커스가 돌아간다.

공개 지식 모델과 검색 색인은 검토된 canonical 공개 자료에서 생성한다. 미발행 native 원고·후보·운영 기록을 공개 데이터에 넣지 않는다. 기존 용어 본문과 Obsidian 링크는 Quartz 렌더링을 그대로 유지한다. 지도는 전용 화면과 용어 페이지에서 제공하며 뉴스·브리핑에는 넣지 않는다.

화면의 RSS 구독 문구와 반복 링크는 제거했다. 기존 `briefing.xml`과 자동 피드 발견 메타데이터, `/rss` 호환 주소는 유지한다. 직접 호환 페이지는 브리핑 피드로 표시한다.

화면만 배포할 때는 Git에 이미 발행된 작성 원본과 `data/drive-source-state.json`을 유지한다. 재정리 중인 로컬 원고와 새 원고를 함께 커밋하지 않는다. 기존 `Publish Garden`에서 검증·생성 후 GitHub Pages에 배포하고 실제 공개 화면을 읽어 확인한다. 콘텐츠 발행은 기존 Drive 보관·승인 경로를 따른다.
