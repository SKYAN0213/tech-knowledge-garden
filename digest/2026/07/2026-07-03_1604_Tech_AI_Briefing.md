제품·서비스 · 오류 수정 · 기능 추가

Claude Code 2.1.199는 2026년 7월 3일(한국시간) 공개됐다. 릴리스 노트는 서버 오류로 중단된 스트리밍 출력과 서브에이전트의 부분 작업을 보존하고, API 오류를 성공으로 보고하던 문제를 고쳤다고 설명했다. Linux·macOS의 백그라운드 실행 오류와 인증서·재시도 처리도 수정했다.

##### 출력 보존과 에이전트 간 오류 전달

API가 응답 일부를 전송한 뒤 과부하·서버 오류를 내면 해당 출력을 남기고 불완전한 응답임을 표시한다. 서브에이전트가 요청 제한·서버 오류로 끊겼을 때는 작업한 부분을 부모 에이전트에 반환하며, 사용량 한도 같은 API 오류도 성공 결과로 처리하지 않고 전달한다.

SendMessage는 재시작된 에이전트가 예전 이름을 재사용해 대상이 어긋났을 때 이를 감지하고 호출자에게 대상을 다시 지정하도록 요청한다. SessionStart·Setup·SubagentStart 훅이 종료 코드 2로 끝나면 숨겨졌던 표준 오류를 대화 기록에 표시한다.

##### 인증서 오류와 일시적 서버 오류의 재시도

TLS 검사 프록시, NODE\_EXTRA\_CA\_CERTS 누락, 인증서 만료로 생긴 SSL 오류는 재시도를 소진하기 전에 즉시 종료하고 해결 힌트를 표시한다. 구독자의 사용량 한도와 무관한 일시적 서버 429 오류에는 대기 시간을 늘려 가며 자동 재시도하는 동작을 적용했다.

CLAUDE\_CODE\_RETRY\_WATCHDOG는 용량 부족에 해당하지 않는 일시적 오류의 기본 재시도 횟수를 300으로 높이고, CLAUDE\_CODE\_MAX\_RETRIES에 적용하던 15회 상한을 해제한다.

##### Linux·macOS 백그라운드 작업

Linux에서는 비정상 종료로 손상된 작업자 기록이 남았을 때 데몬과 실행 중인 모든 에이전트가 약 50초마다 종료되던 문제를 수정했다. macOS에서는 SSH로 백그라운드 에이전트를 처음 실행할 때 audit session 전환에 실패하던 2.1.196의 회귀 오류를 고쳤다.

claude stop과 작업 재시작이 동시에 일어나도 중지 요청을 따르게 했다. 긴 명령 중 진행 표시가 수분간 멈추는 문제를 수정하고, 메모리가 부족한 백그라운드 세션에는 구체적인 메모리 부족 안내를 표시한다. daemon 하위 명령을 대화 입력으로 잘못 해석하는 명령 처리도 고쳤다.

##### 세션·스킬과 브라우저 권한

백그라운드 작업 종료 때 원격 세션의 Working·Idle 상태가 잠시 오가는 현상을 수정했다. 다른 에이전트가 일할 때 대기 중인 서브에이전트가 패널에서 사라지던 문제도 고쳤으며, 대기 항목이 많으면 펼칠 수 있는 요약 행으로 접는다. 서브에이전트 화면에서 /model·/fast를 입력하면 주 에이전트에 적용되는 명령임을 알려준다.

새 메시지 없이 세션을 열거나 재개할 때 기록 파일이 불필요하게 커지는 문제와 ←·/background 전환 뒤 /color가 사라지는 문제를 수정했다. 손상된 설정을 초기화하기 전에는 파일을 백업하며, 서로 다른 빌드·설정 디렉터리의 Chrome 연결이 재접속 페이지를 반복해서 여는 문제도 고쳤다.

/skill-a /skill-b처럼 슬래시 스킬을 앞에 연속 지정하면 첫 번째만 읽던 동작을 바꿔 최대 5개까지 모두 읽는다. 계획 모드에서 상태를 바꾸는 브라우저 도구에는 승인 요청을 표시하고, 읽기 전용 browser\_batch는 자동 허용하도록 수정했다. claude agents의 세션 목록에서는 PR 링크를 \#번호로 표시한다.
