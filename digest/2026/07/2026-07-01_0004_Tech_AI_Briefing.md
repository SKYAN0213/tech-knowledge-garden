### 소프트웨어·클라우드 · 2건

#### [GitHub, Dependabot의 npm 설정 추론 중단…scope를 우선 적용](https://skyan0213.github.io/tech-knowledge-garden/news/c54465745fc299ec)

발표 2026-06-30

제품·서비스 · 기능 변경 · GitHub

GitHub는 2026년 6월 30일(한국시간) Dependabot이 npm 비공개 레지스트리의 .npmrc 설정을 lockfile에서 추론하는 방식을 중단한다고 발표했다. 대신 dependabot.yml의 registry에 scope를 지정하면 그 설정으로 .npmrc를 생성한다.

##### 설정의 우선순위

scope를 지정하면 저장소에 커밋한 .npmrc를 포함한 다른 설정 출처보다 우선한다. scope를 지정하지 않았고 저장소에 .npmrc가 있으면 기존 파일을 계속 사용한다.

##### 변경 배경

GitHub는 기존 방식이 lockfile의 resolved URL을 읽어 .npmrc를 재구성했다고 설명했다. 잘못된 URL, npm·Yarn·pnpm 사이의 lockfile 형식 차이 등이 레지스트리 인증 실패를 일으켰다는 설명이다.

##### 제공 대상

모든 github.com 사용자가 이용할 수 있으며, GitHub Enterprise Server에서는 3.23 버전에 포함될 예정이다.

[GitHub 원문](https://github.blog/changelog/2026-06-30-dependabot-no-longer-infers-npmrc)

#### [GitHub, 오래된 Dependabot 보안 알림을 CSV 보관으로 전환 예고](https://skyan0213.github.io/tech-knowledge-garden/news/c12b394bcd713139)

발표 2026-06-30

제품·서비스 · 기능 변경 · GitHub

GitHub는 2026년 6월 30일(한국시간) 닫힌 Dependabot 보안 알림에 대한 데이터 보존 정책을 예고했다. 정책은 github.com과 GitHub Enterprise Cloud에 적용하며 GitHub Enterprise Server는 대상에서 제외한다.

##### 열린 알림과 닫힌 알림의 조회 범위

열린 알림은 오래돼도 화면과 API에서 조회할 수 있고, 닫힌 알림은 종료 후 2년 동안 조회할 수 있다. 그보다 오래된 닫힌 알림은 보관 저장소로 옮기고, 기업·조직·저장소 관리자와 보안 관리자가 해당 수준의 보안 알림 페이지에서 CSV로 내려받도록 한다.

##### 갱신된 공지의 적용 일정

갱신된 공지는 적용 예정일을 2026년 9월 25일로 명시한다. Dependabot 이외의 알림 유형에 대한 변경 일정은 시행 최소 60일 전에 changelog로 알리겠다고 밝혔다.

##### 보관 기간과 저장 지역

GitHub는 계정이 유지되는 동안 보관 알림의 원래 내용을 보존한다고 설명했다. 데이터 거주 지역을 지정한 Enterprise Cloud에서는 보관 알림도 기존 데이터와 같은 지역에 남는다. 관련 저장소·조직·계정을 삭제하거나 기업 계약이 종료되면 알림 데이터도 삭제된다.

##### 실제 결함 이미지와 합성 데이터

NVIDIA는 Roboflow가 Defect Image Generation skill과 Cosmos를 비전 AI 플랫폼에 통합해 실제 학습 자료가 부족할 때 Corning 같은 고객을 위한 합성 결함 이미지를 만드는 사례를 소개했다.

회사에 따르면 Corning의 광섬유 제조 엔지니어링팀과 진행한 벤치마크에서 실제 결함 이미지 8개를 합성 데이터로 보강해 학습한 모델은 가장 어려운 결함 종류에서 평균 정밀도 95%와 완전한 재현율을 얻었다.

##### 도시 환경을 만들고 영상 작업을 연결

OpenUSD는 3D 세계를 기술·합성·재사용하는 공통 구조이며, 이를 기반으로 한 Omniverse는 조명·날씨·교통·카메라 각도·가림 조건을 달리한 시뮬레이션과 합성데이터·디지털 트윈을 구성한다.

Linker Vision 사례는 VSS로 검색·요약·알림·보고·스트림 관리를 구성하고, Omniverse 디지털 트윈으로 도시 환경을 시험하며, Cosmos로 영상을 보강하고 TAO로 모델을 미세 조정한다. NVIDIA는 가오슝 사례의 개발 작업량이 85%, 사고 대응 시간이 최대 80% 줄었다고 소개했다.

##### 작업 순서와 표준 절차 확인

Foxconn에서 사용하는 DeepHow의 Live SOP Verification agent는 Metropolis VSS로 영상 검색·요약·분석을 수행하고 Cosmos로 조립 동작과 순서가 표준 작업 절차에 맞는지 해석한다.

NVIDIA는 GB300 서버 생산 라인 사례에서 초회 통과 수율이 3% 개선됐고, 핵심 작업 단계의 미세 동작을 이해하는 과제 수준 정확도가 99%였다고 밝혔다.
