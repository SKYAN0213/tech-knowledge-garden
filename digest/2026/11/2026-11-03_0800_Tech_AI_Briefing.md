### [이스트소프트, JDC 사내 생성형 AI 구축사업 수주](https://skyan0213.github.io/tech-knowledge-garden/news/197b664138856028)

발표 2026-10-21

이스트소프트는 2026년 10월 21일 제주국제자유도시개발센터(JDC)의 사내 생성형 AI 언어모델(sLLM) 구축사업을 수주했다. 이스트소프트는 외부망과 분리된 JDC 내부 서버에 sLLM과 AI 에이전트를 결합한 업무지원 플랫폼을 구축해, 흩어진 업무 지식을 연결하고 임직원이 정보를 찾고 근거에 기반해 판단하도록 지원할 계획이다. 사업 계획에는 개발·면세사업, 예산, 안전관리, 계약, 인사 영역별 챗봇에 일상 질의응답용 30B급 언어모델과 복잡한 장문 추론용 120B급 이상 언어모델을 각각 적용하는 내용이 포함됐다. 또 약 3.8TB 규모의 JDC 내부 문서를 임베딩한 RAG 기반 AI 문서검색 서비스를 제공하고 ECM 등 기존 시스템과 외부 데이터를 연동하며, 폐쇄망에 맞춘 보안·모니터링 체계와 LLMOps, 실행형 에이전트 및 업무 흐름을 설계·실행하는 환경도 마련할 예정이다.

### [Amazon Connect Customer, 고객 생애가치·재발신별 지표 제공](https://skyan0213.github.io/tech-knowledge-garden/news/b2b6e2c37d42dac4)

발표 2026-10-26

Amazon Connect Customer는 2026년 10월 26일 공개한 기능으로 고객 생애가치(LTV)와 재발신 여부에 따라 지표를 볼 수 있게 했다. 재발신 고객의 지표를 나머지 연락처와 비교하거나 LTV가 가장 높은 고객군의 결과를 따로 확인할 수 있다. AWS 제품 설명은 LTV가 높은 고객을 효과적인 담당자에게 연결하고, 반복 발신자가 이탈하는 지식 기반·셀프서비스 흐름을 조정하며, 만족도가 낮아지는 세그먼트의 상담원 안내를 다듬는 방안을 활용 예로 들었으며, 실제 도입이나 개선 성과를 보고한 것은 아니다.

발표 2026-10-21

#### AI 팩토리 컴퓨팅 인프라와 공급 계획

##### [네이버, 브룩필드와 AI 인프라 계약…엔비디아 10억달러 투자 조건 충족](https://skyan0213.github.io/tech-knowledge-garden/news/6379423fb58e81ec)

발표 2026-10-27

투자·기업거래 · 지분 투자 · 투자 유치 · 네이버 · 브룩필드 · 엔비디아 · 네이버클라우드

네이버는 2026년 10월 27일 브룩필드와 약 11조9000억원(90억달러) 규모의 AI 컴퓨팅 인프라 확보 계약을 체결했다고 밝혔다. 이번 계약은 네이버·엔비디아·브룩필드가 함께 추진하는 글로벌 AI 팩토리 사업의 일부로, 브룩필드는 가칭 ‘에셋’ 특수목적법인을 세워 최대 90억달러를 투자하고 GPU와 데이터센터 등 AI 인프라를 확보해 컴퓨팅 자원을 네이버클라우드에 공급할 계획이다. 네이버는 7월 22일 브룩필드와 최대 90억달러 투자 사전합의를 맺고 7월 24일 엔비디아와 10억달러 전략적 지분 투자 계약을 체결했으며, 이번 본계약으로 자금조달 협상이 마무리되고 엔비디아 투자 선결 조건이 충족돼 해당 투자는 실행 절차에 들어갔다. 네이버는 제3자 배정 유상증자를 마무리해 1GW급 AI 팩토리 구축 사업을 본격화할 계획이며, 유상증자의 구체적인 내용은 추후 공개하기로 했다.

###### 인프라 투자와 사용료 구조

인프라 구축에 필요한 초기 투자금은 브룩필드가 부담하고, 네이버클라우드는 사업 매출에 연계해 사용료를 지급하는 구조다. 네이버는 이 방식이 대규모 설비 투자에 따른 초기 자금 부담을 줄일 수 있을 것으로 보고 있다.

네이버는 네이버클라우드의 사용료 지급 의무를 최대 8년간 보증한다. 회사 측은 지급보증만으로 실제 현금 지출이나 비용이 발생하는 것은 아니지만, 네이버클라우드가 지급 의무를 이행하지 않으면 모회사에 재무적 책임이 생길 가능성이 있다고 설명했다.

###### 가동 일정과 장기 구축 구상

AI 팩토리는 2027년 상반기 55MW 규모로 가동을 시작하고 2028년에는 200MW까지 확대할 예정이다. 네이버는 각 세종을 핵심 거점으로 삼아 장기적으로 1GW 규모의 AI 인프라를 확보한다는 계획이다.

사업 계획은 6월 8일 처음 발표됐으며, 네이버는 7월 24일 당시 55MW였던 초기 구축 계획을 2028년 200MW까지 확대하기로 했다.

###### 각 사의 역할

네이버클라우드는 확보한 컴퓨팅 자원으로 AI 서비스를 운영하고 외부 고객을 확보할 계획이다. 네이버는 기존에 쌓은 대규모 GPU 클러스터 구축 경험과 데이터센터 운영 기술을 사업에 활용할 예정이다.

엔비디아는 차세대 고성능 컴퓨팅 플랫폼인 DSX를 중심으로 기술 협력을 제공한다.

#### [GitHub CLI, 만료형 자동 갱신 OAuth 자격 증명 공개 프리뷰](https://skyan0213.github.io/tech-knowledge-garden/news/16e9261d8a8c087e)

발표 2026-10-21

제품·서비스 · 기능 추가 · GitHub

GitHub는 2026년 10월 22일(한국시간) GitHub CLI의 만료형 자동 갱신 OAuth 자격 증명을 공개 프리뷰로 제공한다고 밝혔으며, 사용자가 기능을 켜면 gh가 만료형 액세스 토큰과 회전하는 리프레시 토큰을 함께 저장해 필요할 때 액세스 토큰을 갱신하고 재인증 없이 인증을 유지하며 유출된 액세스 토큰은 무기한 유효한 것이 아니라 몇 시간 안에 사용할 수 없게 된다고 설명했다. GitHub는 시작하려면 GitHub CLI v2.103.0을 설치하거나 업그레이드한 뒤 로그인 때 `--expiring`을 지정하거나 `gh config set expiring_credentials enabled`를 실행하라고 안내했으며, 설정하면 gh는 별도 일상 명령 없이 백그라운드에서 자격 증명을 갱신하고 `gh auth status`에서 상태와 현재 액세스 토큰의 만료 시점을 확인할 수 있다. GitHub 설명에 따르면 만료형 토큰은 게시일 기준 github.com과 ghe.com에서 이용할 수 있고 GitHub Enterprise Server는 GHES 3.23부터 발급하며, 그 이전 버전이나 이를 지원하지 않는 서버에서는 비만료 토큰 동작으로 대체된다. 이 기능은 선택 적용으로 기존 로그인과 직접 제공한 토큰은 그대로 작동하며, GitHub는 향후 릴리스에서 신규 로그인에 기본값으로 적용할 계획이라고 밝혔다.

##### HTTPS Git 사용 조건

HTTPS로 Git에 인증하면서 만료형 토큰을 쓰려면 GitHub는 `gh auth setup-git`으로 gh를 Git 자격 증명 도우미로 설정하라고 강력히 권장한다. GitHub는 토큰이 수명 이후 캐시되지 않도록 Git 2.46 이상으로 업그레이드할 것도 강력히 권하며, 이전 버전에서도 gh는 작동하지만 업그레이드 권고를 한 번 표시한다.

##### 토큰을 저장해 쓰는 작업 흐름

`gh auth token`의 결과를 저장해 나중에 재사용하거나 토큰을 다른 도구에 복사하는 스크립트·확장은 토큰이 만료된 뒤 실패할 수 있다. gh 바깥에서 토큰을 쓸 때는 `gh auth token`을 사용할 때마다 새로 읽어야 하며, 이 명령은 필요할 때 토큰을 갱신하고 값을 캐시하지 않는다. GitHub는 장기간 유효한 토큰이 필요한 작업 흐름에서는 해당 작업에 만료형 토큰을 적용하지 말라고 안내하며, Git 자격 증명 도우미를 사용하면 gh가 자격 증명을 갱신해 HTTPS Git 작업을 이어간다.

연구 초안은 단백질 결합, 소분자 결합, 효소 스캐폴딩, DNA 결합의 네 벤치마크 스위트를 다뤘다. RFD4-Proteina는 연구자가 후보를 탐색하고 실험실 시험 우선순위를 정하는 데 도움을 주며, 설계가 시험 조건에서 실제로 어떻게 성능을 내는지는 실험으로 확인한다.

##### 잠재적 응용

NVIDIA가 제시한 잠재적 응용에는 질병 과정을 차단하거나 진단 검사에서 질병 징후를 감지하는 단백질 설계가 포함된다. 이는 가능한 응용에 대한 설명이며 해당 진단·치료 효과가 이미 실현됐다는 의미는 아니다.

##### 발표 당시 이용 경로

2026년 10월 21일 발표 당시 RFD4-Proteina는 Amazon Bio Discovery, Anthropic의 Claude Science, Benchling, Databricks, Google Cloud, Hugging Face, Nebius, OpenAI, Tamarind Bio를 비롯한 파트너를 통해 이용 가능했다. NVIDIA는 연구자와 개발자가 모델을 에이전트·클라우드·과학 컴퓨팅 워크플로에 통합할 수 있다고 밝혔다.
