#### [GitHub Copilot 사용량 API, OpenCode 등 도구별 요청·토큰 집계 추가](https://skyan0213.github.io/tech-knowledge-garden/news/4e3efbae3e238940)

발표 2026-10-24

제품·서비스 · 기능 추가 · GitHub

2026년 10월 24일(한국시간) GitHub는 Copilot 사용량 지표 API가 OpenCode처럼 기존 보고서에 잡히지 않던 도구의 모델 사용량도 보고하도록 확장하고 `totals_by_client` 배열을 추가했다고 밝혔다. 새 집계는 엔터프라이즈·조직·사용자 단위 보고서의 1일 및 28일 버전에 적용되며, 28일 통합 보고서에서는 날짜별 `day_totals` 항목에 표시된다. GitHub는 IDE 밖 도구가 편집기 telemetry를 보내지 않아 `totals_by_ide`에서 빠졌던 사용량을 서버 요청 집계로 보완해, 도구별 사용과 요청·토큰 규모를 파악하고 지원·거버넌스 결정을 내릴 수 있다고 설명했다.

##### 도구별 집계 필드

각 `totals_by_client` 항목은 하나의 client를 나타낸다. `client`에는 요청을 보낸 도구가 표시되며 예시는 `opencode`, `claude_code`, `codex`, `zed`, `copilot_cli`, `github_app`, `cloud_agent`, `code_review`, `vscode`, `jetbrains`다. 인식되지 않은 값은 `other`로 묶인다.

`request_count`는 해당 client의 성공한 모델 요청 수다. 이는 prompt 수가 아니라 model call 수이므로 한 prompt가 여러 call을 만들 수 있고, prompt나 interaction 횟수와 직접 비교해서는 안 된다. `session_count`는 서로 다른 세션 수이며 `token_usage`는 prompt token, output token, 요청당 평균 token을 담는다.

`totals_by_model`은 요청·token 지표를 모델별로 나눈다. `model_selection_mode`는 직접 요청한 `user_selected`, 자동 선택 `auto`, 제품이 고른 `product_selected`를 구분하고, 아직 개별 보고되지 않는 선택 방식은 `other`, 정규화할 수 없는 값은 `unknown`으로 나타난다. Copilot code review와 cloud agent는 제품이 모델을 고르므로 `product_selected`이며, code review 모델은 `unknown`으로 보고된다.

##### 식별·접근 조건과 호환성

GitHub는 각 요청에 실린 integration ID로 client를 식별한다. 따라서 `client`는 실제 도구 신원을 검증한 값이 아니라 요청에 담긴 ID를 바탕으로 한 best-effort 그룹이다. 이 API의 `totals_by_client`는 Copilot을 사용하는 모든 도구의 모델 traffic, 즉 요청과 토큰을 측정한다. 이는 Claude나 Codex 같은 GitHub agent app이 시작한 job 수를 집계하는 agent app activity와는 다른 지표다.

이 지표는 엔터프라이즈 소유자와 billing manager, 조직 소유자, 또는 `View Copilot Metrics` 권한을 가진 사용자 지정 조직·엔터프라이즈 역할이 볼 수 있다. Copilot usage metrics 정책도 활성화되어 있어야 한다.

GitHub는 변경이 추가 방식이라 기존 필드는 그대로 유지되고, 보고할 사용량이 없으면 `totals_by_client`가 빈 배열이라고 밝혔다.

발표 2026-10-22

제품·서비스 · 기능 추가 · GitHub

GitHub은 한국시간 2026년 10월 23일 공개한 변경으로 GitHub Copilot 사용 지표에 조직이 만든 skills, custom agents, MCP servers, slash commands, plugins의 설정 이름을 other나 custom 대신 표시한다. 이름은 기업·조직의 사용자별 1일·28일 및 집계 1일 보고서와 집계 28일 보고서의 day\_totals 등에 반영되며, 각 totals\_by\_* 배열은 레코드당 최대 25개 항목으로 늘어 종전 5개를 넘는 나머지 활동은 끝의 other 항목에 합쳐진다. API 보고서는 enterprise owners와 billing managers, organization owners, 또는 View Copilot Metrics 권한을 부여하는 custom organization·enterprise role을 가진 사용자가 이용할 수 있으며 Copilot 사용 지표 정책이 켜져 있어야 한다.

##### 보고서에 반영되는 범위

이름별 집계 배열은 totals\_by\_skill, totals\_by\_custom\_agent, totals\_by\_mcp, totals\_by\_slash\_cmd, totals\_by\_plugin이다. interaction\_count와 distinct\_*\_use\_count 필드는 이전과 같은 방식으로 계산된다.

##### 이름 수집 조건

이름은 Copilot CLI 대화형 세션과 prompt mode, GitHub Copilot 앱, JetBrains 같은 ACP 연동, Copilot SDK에서 보고된다. prompt mode·앱·ACP에는 Copilot CLI 1.0.97 이상이, SDK에는 v1.0.21 이상이 필요하다. IDE는 agent 경험이 Copilot SDK v1.0.21 이상에서 실행될 때 이름을 보고하며 IDE 내장 채팅 telemetry에서는 이름을 보고하지 않는다.

##### 유포와 실행 회피

ASEC은 일부 샘플이 Rust로 작성됐으며 동적 JMP를 활용한 안티 디스어셈블, CPU 메모리 캐시 조회를 이용한 안티 샌드박스, DLL 인젝션을 사용했다고 분석했다. 보고서는 이러한 기법이 기존 인포스틸러에서 흔하지 않았다고 설명한다.

실행 환경을 샌드박스나 가상 환경으로 판단한 샘플은 정보 탈취를 수행하지 않고 종료했다. 최근 유포된 일부 샘플은 내부에 암호화해 둔 DLL을 복호화한 뒤 Explorer 프로세스에 주입했다.

참조 문자열은 사용 직전까지 암호화해 두며, 샘플별로 달라지는 변형 색인 테이블을 사용한다. 복호화 함수에 전달된 정수 값으로 테이블을 회전해 같은 평문도 키에 따라 다르게 암호화할 수 있고, 암호문 끝에 임의 문자열을 붙여 원래 길이를 추정하기 어렵게 했다.

##### C2 통신과 수집 범위

실행되면 설치 프로그램 목록, CPU 이름, 그래픽 드라이버 정보, CPUID 명령 데이터, Windows 버전 등 PC 기본 정보를 공격자가 통제하는 C2 서버로 보낸다. 이후 서버 설정 데이터가 정보 수집 대상과 추가 동작을 정한다.

확인된 C2 설정은 인증서, SSH 키, 암호화폐 지갑, 설정 파일과 문서를 포함한 폭넓은 프로그램·파일을 탈취 대상으로 지정했다. 실제 수집 범위는 C2 설정에 따라 달라질 수 있으며 VPN이나 원격접속 자격정보가 노출되면 내부 시스템 무단 접근이나 추가 공격에 악용될 수 있다고 ASEC은 경고했다.

경보 활동 타임라인은 경보에 취해진 모든 조치와 상태 변경의 감사 기록을 제공한다. 목록은 저장소, 커미터, 비밀정보 유형, 귀속 방식(멤버십 또는 검증된 도메인), 열린 상태·닫힌 상태로 필터링하고 정렬할 수 있다.

##### SatraGO 임상 설계와 결과

SatraGO-1과 SatraGO-2는 성인 활동성 중등도\~중증 TED와 만성 TED를 대상으로 효능·지속성·내약성을 평가하도록 동일하게 설계된 무작위배정, 위약 대조, 다기관 3상 시험이다. 두 시험은 19개국에서 총 258명을 등록해 Enspryng 또는 위약에 1:1로 배정했다.

Roche는 SatraGO-2에서 활동성·만성 환자를 합친 전체 집단에서도 일관된 결과를 얻었다고 보고했으며, TED의 활동성이나 기간에 관계없이 양호한 안전성 프로필을 보였다고 설명했다. SatraGO 시험에서 새로운 안전성 신호는 확인되지 않았고 안전성 프로필은 기존 시신경척수염범주질환(NMOSD) 자료와 일치했다.

Roche 자료에 따르면 TED는 미국에서 10만 명당 약 155명에게 영향을 주는 희귀 진행성 자가면역질환으로, 치료하지 않으면 안면 변형과 시력을 위협하는 합병증으로 이어질 수 있다. 갑상선기능항진증 환자의 약 50%는 적어도 경증 TED를 겪지만, 갑상선기능저하증이나 정상 갑상선 기능을 가진 사람에게도 나타날 수 있다고 회사는 설명했다.

##### Enspryng의 작용과 기존 적응증

Roche 그룹 Chugai가 개발한 Enspryng은 용해성 및 막 결합 IL-6 수용체에 결합해 IL-6 신호를 억제하도록 설계된 인간화 단클론항체다. 회사는 Chugai의 항체 재활용 기술이 pH 의존적으로 표적에 반복 결합해 항체 순환을 연장하고 IL-6 신호 억제를 지속하도록 하며, IL-6R 억제로 자가항체 유발 병리의 상류 신호를 막는다고 설명했다.
