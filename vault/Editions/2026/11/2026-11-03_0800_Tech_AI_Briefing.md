[S7]

### 하강과 항해를 잇는 날개형 돛

날개형 돛은 공중에서 낙하 속도를 줄이는 역할을 한 뒤 수면에 닿으면 돛으로 바뀌어 바람으로 로봇을 이동시킨다. 원문은 이 구조에 별도의 낙하산이나 착륙 장치가 필요하지 않다고 설명했다.

하강 중에는 공기 흐름에 맞춰 회전하는 자동회전 방식으로 속도를 낮추고 자세를 안정적으로 유지한다. 수면에서는 물고기 꼬리지느러미에서 영감을 얻은 방향타가 방향 전환을 돕고, 바람이 약한 상황에서도 항해 방향을 조정하도록 설계됐다.

플랫폼에는 액추에이터 3개와 항법 센서 3개가 탑재돼 있다. [S7]

GM코리아는 10월 29일 테크 미디어 라운드 테이블에서 상하이GM(SAIC-GM)이 생산하는 중형 SUV 뷰익 엘렉트라 E7의 PHEV 시스템을 소개했다. GM은 중국에서 설계·생산하고 배터리도 중국에서 만든 PHEV를 한국 시장에 투입할 계획이며, 엘렉트라 E7은 11월 뷰익 브랜드의 국내 첫 모델로 출시될 예정이다. 엘렉트라 E7의 배터리 용량은 최대 31.7kWh이며, 전기모터만으로 최대 126km를 주행하고 엔진과 배터리를 함께 사용하면 1,000km 이상 주행한다고 소개됐다. [S8]

GM은 엘렉트라 E7에 리튬인산철(LFP) 배터리를 탑재했다고 밝혔지만 구체적인 공급업체는 공개하지 않았다. 별도로 중국 현지 등록 차량 정보에는 시대상치와 정리신능이 셀 공급사로 기재됐다고 보도됐다.

상하이GM은 두 업체가 생산한 셀을 차량 규격에 맞춰 배터리 팩으로 조립한다. [S8]

PHEV는 외부에서 배터리를 충전하고 전기 주행 비중을 높이며, 배터리가 부족하면 엔진을 활용한다. 엘렉트라 E7은 출발과 도심 주행에서 주로 전기모터를 쓰고 급가속이나 고속 주행에서는 엔진이 구동을 보조한다.

이 차는 완속충전과 직류(DC) 급속충전을 지원하며, 배터리 잔량 20%에서 80%까지 30분 이내에 충전할 수 있다고 소개됐다. [S8]

GM은 차량을 중국에서 생산하지만 개발에는 글로벌 연구개발 조직이 참여했다고 밝혔다. GM과 상하이자동차의 합작법인이 개발과 생산을 맡고, 미국 본사와 한국 등 각 지역 엔지니어가 협력하는 체계를 활용했다고 설명했다. [S8]

### 중국에서 양산한 차량을 국내에 공급

엘렉트라 E7은 중국에서 개발과 양산을 마쳐 별도 국내 생산설비 투자 없이 공급할 수 있다. 국내 신규 생산라인 구축보다 신차 투입에 필요한 비용과 시간을 줄일 수 있고, GM은 한국 시장에 부족했던 PHEV 제품군을 확보하게 됐다고 보도됐다. [S8]

네이버는 2026년 10월 27일 브룩필드와 약 11조9000억원(90억달러) 규모의 AI 컴퓨팅 인프라 확보 계약을 체결했다고 밝혔다. 이번 계약은 네이버·엔비디아·브룩필드가 함께 추진하는 글로벌 AI 팩토리 사업의 일부로, 브룩필드는 가칭 ‘에셋’ 특수목적법인을 세워 최대 90억달러를 투자하고 GPU와 데이터센터 등 AI 인프라를 확보해 컴퓨팅 자원을 네이버클라우드에 공급할 계획이다. 네이버는 7월 22일 브룩필드와 최대 90억달러 투자 사전합의를 맺고 7월 24일 엔비디아와 10억달러 전략적 지분 투자 계약을 체결했으며, 이번 본계약으로 자금조달 협상이 마무리되고 엔비디아 투자 선결 조건이 충족돼 해당 투자는 실행 절차에 들어갔다. 네이버는 제3자 배정 유상증자를 마무리해 1GW급 AI 팩토리 구축 사업을 본격화할 계획이며, 유상증자의 구체적인 내용은 추후 공개하기로 했다. ### 인프라 투자와 사용료 구조

인프라 구축에 필요한 초기 투자금은 브룩필드가 부담하고, 네이버클라우드는 사업 매출에 연계해 사용료를 지급하는 구조다. 네이버는 이 방식이 대규모 설비 투자에 따른 초기 자금 부담을 줄일 수 있을 것으로 보고 있다.

네이버는 네이버클라우드의 사용료 지급 의무를 최대 8년간 보증한다. 회사 측은 지급보증만으로 실제 현금 지출이나 비용이 발생하는 것은 아니지만, 네이버클라우드가 지급 의무를 이행하지 않으면 모회사에 재무적 책임이 생길 가능성이 있다고 설명했다. [S12]

사업 계획은 6월 8일 처음 발표됐으며, 네이버는 7월 24일 당시 55MW였던 초기 구축 계획을 2028년 200MW까지 확대하기로 했다. [S12]

네이버클라우드는 확보한 컴퓨팅 자원으로 AI 서비스를 운영하고 외부 고객을 확보할 계획이다. 네이버는 기존에 쌓은 대규모 GPU 클러스터 구축 경험과 데이터센터 운영 기술을 사업에 활용할 예정이다.

엔비디아는 차세대 고성능 컴퓨팅 플랫폼인 DSX를 중심으로 기술 협력을 제공한다. [S12]

## GitHub CLI, 만료형 자동 갱신 OAuth 자격 증명 공개 프리뷰

**분야:** 사이버보안
**테마:** 제품·서비스
**보조 테마:** 없음
**세부 태그:** 기능 추가
**기업·기관:** GitHub

GitHub는 2026년 10월 22일(한국시간) GitHub CLI의 만료형 자동 갱신 OAuth 자격 증명을 공개 프리뷰로 제공한다고 밝혔으며, 사용자가 기능을 켜면 gh가 만료형 액세스 토큰과 회전하는 리프레시 토큰을 함께 저장해 필요할 때 액세스 토큰을 갱신하고 재인증 없이 인증을 유지하며 유출된 액세스 토큰은 무기한 유효한 것이 아니라 몇 시간 안에 사용할 수 없게 된다고 설명했다. GitHub는 시작하려면 GitHub CLI v2.103.0을 설치하거나 업그레이드한 뒤 로그인 때 `--expiring`을 지정하거나 `gh config set expiring_credentials enabled`를 실행하라고 안내했으며, 설정하면 gh는 별도 일상 명령 없이 백그라운드에서 자격 증명을 갱신하고 `gh auth status`에서 상태와 현재 액세스 토큰의 만료 시점을 확인할 수 있다. GitHub 설명에 따르면 만료형 토큰은 게시일 기준 github.com과 ghe.com에서 이용할 수 있고 GitHub Enterprise Server는 GHES 3.23부터 발급하며, 그 이전 버전이나 이를 지원하지 않는 서버에서는 비만료 토큰 동작으로 대체된다. 이 기능은 선택 적용으로 기존 로그인과 직접 제공한 토큰은 그대로 작동하며, GitHub는 향후 릴리스에서 신규 로그인에 기본값으로 적용할 계획이라고 밝혔다. [S24]

### HTTPS Git 사용 조건

HTTPS로 Git에 인증하면서 만료형 토큰을 쓰려면 GitHub는 `gh auth setup-git`으로 gh를 Git 자격 증명 도우미로 설정하라고 강력히 권장한다. GitHub는 토큰이 수명 이후 캐시되지 않도록 Git 2.46 이상으로 업그레이드할 것도 강력히 권하며, 이전 버전에서도 gh는 작동하지만 업그레이드 권고를 한 번 표시한다. [S24]

### 토큰을 저장해 쓰는 작업 흐름

`gh auth token`의 결과를 저장해 나중에 재사용하거나 토큰을 다른 도구에 복사하는 스크립트·확장은 토큰이 만료된 뒤 실패할 수 있다. gh 바깥에서 토큰을 쓸 때는 `gh auth token`을 사용할 때마다 새로 읽어야 하며, 이 명령은 필요할 때 토큰을 갱신하고 값을 캐시하지 않는다. GitHub는 장기간 유효한 토큰이 필요한 작업 흐름에서는 해당 작업에 만료형 토큰을 적용하지 말라고 안내하며, Git 자격 증명 도우미를 사용하면 gh가 자격 증명을 갱신해 HTTPS Git 작업을 이어간다. [S24]

2026년 10월 22일 AWS는 Amazon OpenSearch Serverless 검색 및 벡터 컬렉션의 기본 새로 고침 간격을 10초에서 5초로 줄였다고 밝혔다. AWS는 쓰기 후 읽기 가시성이 자동으로 빨라지고 별도 설정 변경이나 사용자 조치가 필요 없다고 설명했다. 이 변경은 차세대 Amazon OpenSearch Serverless 검색 및 벡터 컬렉션에 기본 적용되며, AWS는 지속 수집과 거의 실시간 검색이 필요한 전문 검색·RAG·시맨틱 검색·추천·개인화 사용 사례에서 최신 데이터에 더 빨리 접근해 검색 결과와 RAG 응답의 관련성 및 정확성을 높일 수 있다고 설명했다. AWS는 5초 기본 간격을 발표 당시 Amazon OpenSearch Serverless를 제공하던 모든 24개 리전에서 이용할 수 있다고 밝혔다. [S25]
