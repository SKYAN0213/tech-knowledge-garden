## OpenAI Presence, 기업용 음성·채팅 에이전트를 제한적 정식 제공

**분야:** AI
**테마:** 제품·서비스
**보조 테마:** 없음
**세부 태그:** 신제품
**기업·기관:** OpenAI, BBVA, SoftBank, IAG

OpenAI는 7월 22일 고객 지원과 사내 업무에 음성·채팅 에이전트를 배치하는 Presence를 발표했다. 적격 기업에 제한적 정식 제공 프로그램으로 공급하며, OpenAI 현장 엔지니어와 일부 시스템 통합사가 배치를 담당한다. [S1]

### 업무·권한·평가를 함께 설정

기업은 에이전트가 맡을 업무를 정하고 필요한 지식과 시스템 접근만 부여한다. 업무 정책·표준 절차·가드레일·승인 행동·시뮬레이션·평가 도구를 함께 설정한다.

출시 전에는 결과·정책 준수·도구 사용·사람 이관을 검사한다. 출시 후 운영 신호를 바탕으로 Codex가 수정안을 제안하고, 팀이 현행 버전과 시험·승인한 뒤 적용한다. [S1]

### OpenAI가 공개한 자사 운영 수치

OpenAI는 자사 영어 전화 지원에서 문의의 75%를 사람 도움 없이 해결하고, 출시팀과 진행한 10일의 개선으로 사람 이관 비율을 15%포인트 낮췄다고 보고했다. [S1]

### 고객별 탐색·시험 단계

BBVA는 멕시코의 일상 은행 업무 음성 지원을 탐색하고, SoftBank는 일본어 고객 대화를 시험하며, IAG는 악천후 등 수요가 높은 상황의 지원을 탐색한다고 소개했다. Presence는 셀프서비스 제품이 아니다. [S1]

## Copilot 영향 대시보드, 사용 단계별 PR 지표와 6개월 추세 표시

**분야:** 소프트웨어·클라우드
**테마:** 제품·서비스
**보조 테마:** 없음
**세부 태그:** 기능 추가
**기업·기관:** GitHub

GitHub는 7월 22일 기업 관리자와 조직 소유자를 위한 Copilot 사용 영향 대시보드를 출시했다고 발표했다. 코드 중심·에이전트 중심·다중 에이전트 또는 Copilot 앱 사용 집단과 미참여 집단을 나눠 PR 처리 지표를 보여준다. [S2]

### 집단별 표시 지표

사용자 한 명당 월평균 병합 PR 수·PR 병합 속도 중앙값·집단별 사용자 수와 전체 비중·하루 평균 코드 줄 수를 제공한다.

미참여 집단과 참여 Copilot 사용자의 평균 처리량·속도를 비교하고, 6개월의 집단 성장과 PR 처리량 추세를 보여준다. [S2]

### 분류 기간과 접근 권한

집단 분류는 최근 28일의 제품 사용에 따른 ai_adoption_phase를 사용한다. 대시보드는 Copilot 사용 지표 접근 권한을 가진 기업 관리자와 조직 소유자가 사용할 수 있다. [S2]

## OpenAI, Genesis 연구자 약 2,000명에 Codex 이용 지원 계획

**분야:** 우주·기초과학
**테마:** 투자·기업거래
**보조 테마:** 없음
**세부 태그:** 자본 배분
**기업·기관:** OpenAI

OpenAI는 7월 22일 미국 에너지부 Genesis Mission 참여 연구자에게 모델 접근과 기술 협력·연구 자원을 지원할 계획을 발표했다. 국립연구소와 대학의 연구자 약 2,000명에게 400만 달러 규모의 Codex 이용을 지원하고 두 과학 캠페인에 300만 달러의 API 지원을 약속했다. [S3]

### API 이용 지원 조건과 모델 접근

참여 연구자가 250만 달러를 지출하면 최대 1,000만 달러의 API 이용을 제공하는 조건도 발표했다. 적격 생물학 연구자에게 GPT-Rosalind를 제공하고, 일부 연구소 책임자에게 모델·기능의 조기 접근을 지원할 계획이다.

일부 국립연구소 사이버보안 연구자에게 방어 연구를 위한 접근도 확대할 계획이다. [S3]

### 초기 과학 캠페인 후보

고온 초전도체 연구는 AI·시뮬레이션·재료 전문지식·실험을 결합해 더 높은 온도와 실용적 압력에서 작동하는 재료를 탐색하는 방향이다.

Atlas of the Machine-Accessible Frontier는 기존 지식·데이터·계산으로 AI 연구가 접근할 수 있는 문제와 물리 실험 근거가 필요한 문제를 구분하는 캠페인 후보다. [S3]
