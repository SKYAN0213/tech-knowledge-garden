## Claude Opus 5, GitHub Copilot에 단계적 제공

**분야:** 소프트웨어·클라우드
**테마:** 제품·서비스
**보조 테마:** 없음
**세부 태그:** 기능 추가
**기업·기관:** GitHub, Anthropic

GitHub는 7월 24일 Anthropic의 Claude Opus 5를 Copilot 모델 선택지에 추가한다고 발표했다. 대상은 Pro+·Max·Business·Enterprise 이용자이며, 제공은 단계적으로 확대된다. [S1]

### 지원 환경과 기업 사용 설정

VS Code·Visual Studio·JetBrains·Xcode·Eclipse와 Copilot CLI·클라우드 에이전트·앱, github.com, GitHub Mobile에서 선택할 수 있다. Business와 Enterprise에서는 관리자가 Claude Opus 5 정책을 활성화해야 한다. [S1]

### 사용량 기반 과금

모델 사용량에는 제공사의 API 정가가 적용된다. [S1]
