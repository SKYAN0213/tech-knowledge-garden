# 산업용 로봇의 현장 재학습과 운전 수명주기

ABB는 10월 15일 Fashion Inductor에 AI Robot Trainer를 통합했다. 회사 발표는 운전 중 이상 감시에서 학습 데이터 생성과 셀별 재학습, 실제 로봇 배포까지 이어지는 흐름을 설명한다.
