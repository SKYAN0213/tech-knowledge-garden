# x402

## 한 문장 정의

x402는 HTTP의 402 Payment Required 응답으로 결제 조건을 알리고, 클라이언트가 결제 증명을 첨부한 요청으로 유료 자원을 받도록 하는 공개 결제 프로토콜이다. [Cloudflare 설명](https://blog.cloudflare.com/monetization-gateway/)

## 용어 카드

- 이름: x402
- 이름의 유래: HTTP 상태 코드 402

## 작동 원리

클라이언트가 결제가 필요한 자원을 요청하면 서버는 402 응답과 함께 가격, 받는 자산, 결제 목적지를 보낸다. 클라이언트는 결제한 뒤 증명을 첨부해 같은 자원을 다시 요청한다. facilitator가 증명을 검증하면 서버가 자원을 제공한다. [Cloudflare 설명](https://blog.cloudflare.com/monetization-gateway/)

이 교환은 일반 HTTP 요청·응답 안에서 이루어진다. 별도 결제 페이지로 이동하거나 별도 결제 API를 호출하는 절차를 요구하지 않는다. 결제 금액은 구매자에게서 판매자의 지갑으로 직접 정산된다. [Cloudflare 설명](https://blog.cloudflare.com/monetization-gateway/)

## 실제 예시

Cloudflare는 Monetization Gateway의 초기 결제를 스테이블코인과 x402로 처리할 계획을 발표했다. 웹페이지·데이터셋·API·MCP 도구에 과금을 적용하는 구상이며, 해당 발표에서 대기자 모집을 시작했다. [Cloudflare 설명](https://blog.cloudflare.com/monetization-gateway/)
