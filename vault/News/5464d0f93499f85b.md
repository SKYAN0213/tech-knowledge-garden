# AWS, Bedrock AgentCore 웹 검색을 GovCloud 포함 4개 리전으로 확대


AWS는 2026년 10월 15일 Amazon Bedrock AgentCore의 Web Search를 미국 동부 오하이오, 미국 서부 오리건, 아시아태평양 시드니, AWS GovCloud(US-West) 등 4개 추가 리전에서 제공한다고 밝혔다. AWS는 Web Search를 에이전트가 조사·요약·질의응답에 활용할 최신 웹 정보를 얻는 완전 관리형 도구라고 설명했다. 회사는 애플리케이션과 사용자에 가까운 리전에서 검색해 지연을 낮출 수 있으며 GovCloud(US-West) 제공으로 정부 업무의 규정 준수·데이터 거주 요구를 지원한다고 밝혔다.
