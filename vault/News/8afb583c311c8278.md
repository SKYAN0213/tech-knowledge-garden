# AWS, Trainium용 PyTorch 백엔드 TorchNeuron 공개 베타 출시


AWS는 2026년 10월 20일 AWS Trainium용 오픈소스 네이티브 PyTorch 백엔드 TorchNeuron의 공개 베타를 출시했다. AWS에 따르면 TorchNeuron은 AI 과학자와 연구자가 Trainium에서 PyTorch로 모델을 실험하고 구축하도록 지원한다. AWS는 개발자가 .to('neuron')으로 PyTorch 코드를 전환하면서 eager execution, torch.compile, 표준 PyTorch API와의 호환성을 유지할 수 있고, Neuron Kernel Interface (NKI) 통합으로 사용자 지정 연산자와 Trainium 하드웨어 최적화를 지원한다고 밝혔다. TorchNeuron은 GitHub에서 오픈소스로 제공되며 Amazon EC2 Trainium2 및 Trainium3 인스턴스에서 이용할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-announce-native-pytorch-support-trainium>)
