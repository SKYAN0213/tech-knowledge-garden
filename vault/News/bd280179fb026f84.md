# 자기 증류 모델의 평균 정답률과 답변 다양성을 따로 비교한 연구


연구진은 2026년 6월 24일 arXiv에 샘플 정답 시범을 사용하는 온폴리시 자기 증류의 출력 다양성 연구를 사전공개했다. 한 모델이 교사와 학생을 맡고 교사가 정답 시범을 문맥으로 받아 학생 출력에 피드백을 주는 방식에서, 답변을 더 생성해도 정답률이 잘 늘지 않는 현상을 분석했다. [원문 1](<https://arxiv.org/abs/2606.26091v1>)

### 학습 신호와 출력 집중

저자들은 시범과 학생 출력의 점별 조건부 상호정보량으로 학습 후 분포가 기울어지는 구조를 설명했다. 같은 정도로 맞는 답들 사이의 확률 차이가 커져 기존에 우세한 응답 방식에 출력이 집중될 수 있다고 제시했다. [원문 1](<https://arxiv.org/abs/2606.26091v1>)

### 실험에서 구분한 성능

제어된 그래프 경로 찾기와 과학 질의응답 시험에서 평균 성능은 강화학습과 비슷하거나 높았지만 기능·의미 다양성은 낮았다고 초록은 보고한다. 여러 전략이 필요한 분포 밖 조건에서는 실패가 나타났다. [원문 1](<https://arxiv.org/abs/2606.26091v1>)
