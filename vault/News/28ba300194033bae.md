# VS Code Agents 전용 창의 사용량을 별도로 집계


GitHub는 9월 11일 Copilot 사용량 보고서에 VS Code Agents 전용 창의 활동 지표를 정식으로 추가했다. 기업·조직의 1일 및 28일 집계 보고서에는 이 창의 활성 사용자 수, 세션 수, 사용자 메시지 수가 선택 항목으로 포함된다. 기업 소유자·결제 관리자·조직 소유자와 관련 조회 권한을 부여받은 사용자가 지표를 볼 수 있으며, Copilot 사용량 지표 정책도 켜져 있어야 한다. [원문 1](<https://github.blog/changelog/2026-09-11-add-vs-code-agents-to-copilot-usage-metrics/>)

### 별도로 집계하는 범위

GitHub는 전용 창의 지표를 편집기 창 Agent Mode와 일반 Copilot 사용량 집계와 구분한다.

사용자별 보고서에는 전용 창 사용 여부와 사용자별 세션·메시지 수가 포함된다. 해당 데이터가 없으면 선택 항목은 생략되거나 null로 표시될 수 있다. [원문 1](<https://github.blog/changelog/2026-09-11-add-vs-code-agents-to-copilot-usage-metrics/>)
