# 모델 응답 선택형 결합의 정확도 상한을 공동 실패율로 설명한 연구


연구진은 2026년 6월 25일 arXiv에 여러 언어 모델의 공동 실패율과 결합 시스템의 정확도 상한을 다룬 사전공개 논문을 등록했다. 구성 모델의 답 중 하나를 출력하는 방식에서는 모든 모델이 같은 질문을 틀리는 비율 베타 때문에 정확도가 1에서 베타를 뺀 값을 넘을 수 없다고 설명했다. [원문 1](<https://arxiv.org/abs/2606.27288v1>)

### 오류 상관과 공동 실패의 차이

평균적인 모델 쌍의 오류 상관이 같아도 모든 모델이 동시에 틀리는 비율은 달라질 수 있다는 점이 출발점이다. 저자들은 베타의 Clopper–Pearson 한계로 라우터 학습 전에 가능한 개선 폭을 평가하는 방법을 제시했다. [원문 1](<https://arxiv.org/abs/2606.27288v1>)

### 초록에 보고한 비교 조건

초록은 21개 제공사의 67개 모델을 비교했다고 밝힌다. 개방형 수학 문제에서 관측한 공동 실패율은 0.052였고 전체 모델의 Gaussian copula 모형 예측은 0.023이었다.

같은 수준의 모델 품질에서는 오류 상관이 낮은 이질적 모델 조합이 높은 상관의 Self-MoA보다 나았다. 저자들은 검사 가능한 과제에서 강한 질문별 라우팅 신호가 없으면 결합이 최상위 단일 모델을 넘는 경우가 드물었다고 보고했다. [원문 1](<https://arxiv.org/abs/2606.27288v1>)
