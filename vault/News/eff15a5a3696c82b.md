# AWS, Megaport와 Interconnect 라스트마일 프리뷰 출시


AWS는 2026년 10월 22일 Megaport와 함께 지사·데이터센터·원격지에서 AWS로 연결하는 완전 관리형 서비스 AWS Interconnect - last mile의 프리뷰를 출시했다. 프리뷰는 Megaport를 통해 미국 산호세(us-west-1)와 북버지니아(us-east-1) 대도시권에서 제공된다. 정식 출시(GA) 때는 AWS Console에서 대역폭을 1 Gbps에서 100 Gbps까지 동적으로 조정할 수 있도록 할 계획이다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-announces-AWS-interconnect-last-mile-megaport-preview/>)

### 연결 정보와 활성화 키로 구성

고객은 AWS Management Console에서 리전, 대역폭, Direct Connect Gateway ID, 파트너 구독자 ID를 선택해 사설 고속 연결을 만든다. AWS는 Megaport 프로비저닝용 활성화 키를 생성하고, 사전 프로비저닝 용량으로 BGP 피어링·VLAN·ASN 구성을 자동화한다.

고객은 Console·CLI·API로 연결을 생성할 수 있으며, 파트너는 GitHub에 공개된 API 패키지를 통해 서비스를 도입할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-announces-AWS-interconnect-last-mile-megaport-preview/>)
