# GitHub Copilot Free·Student, 모델 수동 선택 대신 자동 선택으로 통일


GitHub는 2026년 6월 25일(한국시간), Copilot Free·Student 요금제의 모델 선택을 자동 선택으로 통일한다고 발표했다. 작업별 모델을 자동으로 선택하며, 해당 요금제에서는 자동 선택이 기본이자 유일한 선택 방식이 된다. [원문 1](<https://github.blog/changelog/2026-06-24-changes-to-model-selection-for-free-and-student-plans/>)

### 접근 범위와 표시 변경

자동 선택은 여러 모델 계열을 이용하지만 요금제 제한을 따른다. GitHub는 Microsoft가 출시한 모델의 Preview 표시도 제거한다고 밝혔다. [원문 1](<https://github.blog/changelog/2026-06-24-changes-to-model-selection-for-free-and-student-plans/>)
