# 안랩 ARTEX 실험, 취약 웹서버와 내부 호스트 4대까지 접근 확인


안랩 시큐리티대응센터(ASEC)는 2026년 10월 15일 ARTEX 노출 인프라와 공격 활동 정황, 별도 환경에서 수행한 자율 침투 실험을 분석한 내용을 공개했다. 두 실험에서 사용자는 대상·목표·허용 범위만 입력했다. 파일 업로드 취약 웹 서버 실험은 프로그램 실행까지, Apache ActiveMQ 5.15.15 노출 환경 실험은 초기 접근 뒤 내부 호스트 4대에서 원격 명령 실행까지 도달했다. [원문 1](<https://asec.ahnlab.com/ko/95844/>)

### 노출 IP 수와 공격자 식별은 별개

ASEC가 ARTEX 운영 인프라로 확인한 공개 IP 600개 중 미국·중국·홍콩·싱가포르 주소는 541개(90.2%)였다. ASEC는 IP 위치 정보만으로 운영자 국적이나 공격 출발지를 판단할 수 없다고 밝혔다.

ASEC는 User-Agent 하나만으로 ARTEX 활동을 확인하거나 차단하기 어렵고 HTTP가 아닌 통신에는 이 값이 없을 수 있다며 웹·네트워크·인증 기록과 단말 탐지 결과를 함께 분석할 것을 제시했다. [원문 1](<https://asec.ahnlab.com/ko/95844/>)
