# 구글, 코드 변경마다 AI 보안 검사…오픈소스 Mantis 공개


구글 AI·인프라 팀은 9월 19일 취약점 스캔과 패치를 AI 에이전트로 구글의 소프트웨어 개발 수명주기에 통합했다고 밝혔다. 구글은 자체 인프라에 배포하는 수억 줄 규모의 코드에서 변경 건을 계속 검사해, 매월 수백 건의 취약점이 코드베이스나 프로덕션에 도달하기 전에 막고 있다고 밝혔다. 구글은 Mantis 하네스를 오픈소스로 제공하며, 일부 사례에서 오탐률을 3%까지 낮췄고 분류 에이전트가 92% 초과 정밀도로 1분 미만에 작업한다고 밝혔다. [원문 1](<https://cloud.google.com/blog/topics/systems/using-ai-agents-to-secure-google-infrastructure/>)

### 코드 제출 전후로 취약점을 검사

사전 제출 검사는 각 코드 체크인 때 실시간으로 실행된다. 야간 통합 테스트의 사후 제출 스캔은 여러 변경에 걸쳐 들어온 취약점을 확인하는 두 번째 방어층이다. [원문 1](<https://cloud.google.com/blog/topics/systems/using-ai-agents-to-secure-google-infrastructure/>)

### 공격 경로를 확인하고 수정안은 사람이 검토

Mantis는 실시간 코드베이스 메타데이터를 쓰는 지역화 위협 모델을 보안 에이전트에 연결하고, 패키지·라이브러리 의존성 호출 그래프로 스캔 문맥을 보강한다.

분류 에이전트는 코드 구조와 호출 경로, 사전 색인한 도메인 안전 규칙을 살펴 취약 경로가 공격자에게 실제로 도달 가능한지 검증한다. 수정 에이전트는 스캔 결과와 재현 증거를 바탕으로 내부 코딩 기준에 맞는 수정안을 만들고, 원래 변경 요청의 검토 과정에 제출한다. [원문 1](<https://cloud.google.com/blog/topics/systems/using-ai-agents-to-secure-google-infrastructure/>)
