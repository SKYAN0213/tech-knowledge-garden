# NVIDIA, Azure GB300 기반 Claude의 Microsoft Foundry 정식 제공 발표


NVIDIA는 2026년 6월 30일(한국시간) Azure에서 GB300 Blackwell Ultra GPU로 실행되는 Anthropic Claude 모델의 Microsoft Foundry 정식 제공을 발표했다. 구성에는 GB300 NVL72 시스템과 Quantum-X800 InfiniBand 네트워킹을 사용한다. [원문 1](<https://blogs.nvidia.com/blog/anthropic-nvidia-gb300-blackwell-ultra-microsoft-azure/>)

### 인프라 제공과 에이전트 실행 환경

NVIDIA는 도메인별 에이전트 기능을 위해 자사의 도구와 verified agent skills를 Anthropic 스택에 통합하는 협업도 진행한다고 설명했다. 이번 공지는 Microsoft·NVIDIA·Anthropic이 앞서 발표한 협력의 연장선으로 소개됐다.

Azure에서 Claude 에이전트를 실행하는 Secure Agent Workspace Reference Design은 신원·네트워크 접근·자격 증명·실행 정책을 인프라 계층에서 관리하는 청사진이다. [원문 1](<https://blogs.nvidia.com/blog/anthropic-nvidia-gb300-blackwell-ultra-microsoft-azure/>)
