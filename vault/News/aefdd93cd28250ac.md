# GitHub Copilot 앱, 사용자 키와 로컬 모델로 에이전트 세션 실행 지원


GitHub는 2026년 6월 23일(한국시간), Copilot 앱에서 사용자의 모델 제공자와 인증 키를 사용하는 BYOK 기능을 발표했다. OpenAI·Azure OpenAI·Microsoft Foundry·Anthropic, LM Studio·Ollama 및 OpenAI 호환 엔드포인트를 에이전트 세션에 연결할 수 있다. [원문 1](<https://github.blog/changelog/2026-06-23-github-copilot-app-support-for-byok/>)

### 설정과 세션별 모델 선택

Settings의 Model Providers에 엔드포인트와 API 키를 등록한다. LM Studio·Ollama에는 호스트를 지정하며, 등록한 모델은 Copilot 제공 모델과 함께 선택 목록에 나타난다. 키는 로컬 운영체제의 키체인에 보관되고 UI에서 다시 읽지 않는다고 GitHub는 설명했다. [원문 1](<https://github.blog/changelog/2026-06-23-github-copilot-app-support-for-byok/>)

### 기존 계정과 조직 정책

사용자는 기존 제공자의 결제·할당량·지역·데이터 처리 조건을 유지하며 자체 클라우드 계정이나 내부 게이트웨이로 추론 요청을 보낼 수 있다. Business·Enterprise 요금제에서 앱을 이용하려면 관리자가 정책에서 Copilot CLI를 활성화해야 한다. [원문 1](<https://github.blog/changelog/2026-06-23-github-copilot-app-support-for-byok/>)
