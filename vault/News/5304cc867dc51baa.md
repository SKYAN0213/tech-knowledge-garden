# 안랩 컨소시엄, 한국연구재단 업무망 AI 이용 보안통제 97건 구현


안랩은 10월 12일 한국연구재단의 국가 망 보안체계(N2SF) 도입 사업에서 생성형 AI 이용 모델과 업무 단말 인터넷 이용 모델을 함께 적용했다고 발표했다. 컨소시엄은 보안통제 97건의 구현과 솔루션 연동을 마쳤으며, 10월 말부터 적용 대상을 전사로 넓혀 11월 말 구축을 완료할 예정이다. [원문 1](<https://company.ahnlab.com/kr/news/press_release_view.do?seqPressRelease=11210>)

### 접속과 데이터 전송을 따로 통제

사용자 신원·권한과 단말 상태를 검증한 뒤 승인된 서비스만 연결하고 외부 웹 콘텐츠는 격리해 실행한다. 정보는 기밀(C)·민감(S)·공개(O)로 나누며, 공개 등급 AI 서비스에는 공개 등급 파일만 전송하도록 통제한다. [원문 1](<https://company.ahnlab.com/kr/news/press_release_view.do?seqPressRelease=11210>)
