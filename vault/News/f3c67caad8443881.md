# GitHub, MAI-Code-1-Flash를 Copilot Business·Enterprise에 정식 제공


GitHub는 6월 27일(한국시간) Microsoft AI의 자체 코딩 모델 MAI-Code-1-Flash를 Copilot Business와 Enterprise에서 정식 제공한다고 발표했다. 이용 요금은 제공업체의 정가를 기준으로 사용량에 따라 부과되며, 두 플랜의 관리자가 Copilot 설정에서 해당 모델 정책을 활성화해야 사용자가 접근할 수 있다. GitHub는 이 모델이 코딩과 Copilot에 맞춰 설계됐으며, 에이전트가 코딩 작업을 많이 반복하는 흐름에 적합한 빠른 응답을 제공한다고 설명했다. [원문 1](<https://github.blog/changelog/2026-06-26-mai-code-1-flash-for-copilot-business-and-copilot-enterprise>)
