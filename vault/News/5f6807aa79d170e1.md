# OpenAI, Codex 업무 연구 공개…긴 작업 요청과 비개발자 사용 추적


OpenAI는 2026년 6월 25일 Codex 사용 기록으로 에이전트의 업무 활용을 조사한 경제 연구를 소개했다. 개인·조직·OpenAI 내부 사용을 구분하고, 여러 도구를 쓰며 장시간 진행하는 위임 작업과 비개발자의 사용 변화를 분석했다. [원문 1](<https://openai.com/index/how-agents-are-transforming-work/>)

### 작업 시간 지표의 뜻

회사는 2026년 5월 개인 사용자 표본의 80.6%가 사람이 30분 이상 걸릴 것으로 추정한 요청을 한 번 이상 했다고 밝혔다. 이는 사용자 비율이며 전체 요청의 비율이 아니다.

시간은 실제 절약 시간을 측정한 값이 아니라 Codex 대화를 읽은 판정용 언어 모델의 추정이다. 개인 사용자 중 무작위 0.1% 표본의 질의를 사용했다. [원문 1](<https://openai.com/index/how-agents-are-transforming-work/>)

### 직무를 넘나드는 사용

OpenAI 내부의 업무 부서에서 생성한 Codex 결과 중 4분의 1 이상은 엔지니어링·코딩 작업으로 분류됐다. 이 지표는 결과 토큰과 추정 직무를 비교한 것이며 회사 밖 전체 근로자의 생산성 측정은 아니다. [원문 1](<https://openai.com/index/how-agents-are-transforming-work/>)
