# NVIDIA, Transformers v5 기반 NeMo AutoModel 학습 구조와 MoE 비교 공개


NVIDIA는 2026년 6월 25일(한국시간) Hugging Face에 NeMo AutoModel의 전문가 혼합 모델 학습 구조와 성능 비교를 공개했다. Transformers v5의 모델 로딩 API를 유지하면서 전문가 병렬화, 통신·연산 결합과 최적화 커널을 추가하는 방식이다. [원문 1](<https://huggingface.co/blog/nvidia/accelerating-fine-tuning-nvidia-nemo-automodel>)

### 모델과 체크포인트 호환

NeMoAutoModelForCausalLM은 Transformers의 AutoModelForCausalLM을 상속한다. 모델 종류에 따라 최적화 구현이나 기본 Hugging Face 경로를 사용하고 저장 결과는 표준 Hugging Face 체크포인트 형식을 유지한다. [원문 1](<https://huggingface.co/blog/nvidia/accelerating-fine-tuning-nvidia-nemo-automodel>)

### 속도 비교의 실행 조건

단일 노드 비교는 H100 80GB GPU 8개, 시퀀스 길이 4,096, 로컬 배치 크기 1에서 진행했다. NeMo는 전문가 병렬화 크기 8과 균등 라우팅 게이트를 사용했고, Transformers v5는 같은 더미 토큰에 기본 라우터를 적용했다.

NVIDIA는 Qwen3-30B-A3B와 Nemotron 3 Nano 30B-A3B에서 최적화한 v5 대비 약 3.4\~3.7배 높은 학습 처리량과 29\~32% 적은 GPU 메모리를 보고했다. 라우팅 방식이 다른 해당 학습 비교 결과다. [원문 1](<https://huggingface.co/blog/nvidia/accelerating-fine-tuning-nvidia-nemo-automodel>)

### 전문가 병렬화의 역할

전문가 가중치를 GPU에 나누고 DeepEP로 토큰 전달과 전문가 계산을 겹친다. NeMo에서는 전문가 병렬화와 데이터 병렬화를 별도 축으로 구성한다. [원문 1](<https://huggingface.co/blog/nvidia/accelerating-fine-tuning-nvidia-nemo-automodel>)
