# GitHub, 철회된 Dependabot 경고를 webhook·API에서 구분


GitHub는 2026년 한국시간 10월 13일 Dependabot이 취약점 경고를 철회할 때 webhook과 REST API에서 그 상태를 식별할 수 있도록 동작을 추가했다고 밝혔다. dependabot\_alert webhook 이벤트에는 withdrawn 동작이 추가됐고, 페이로드에는 경고 번호·GHSA 및 CVE ID·패키지·manifest 경로 등 경고 제거 전 식별 정보가 담긴다. [원문 1](<https://github.blog/changelog/2026-10-13-improved-detection-for-withdrawn-dependabot-alerts>)

### API 응답 코드로 철회 상태 확인

철회된 경고를 조회하거나 갱신하는 REST API 요청은 기존 404 Not Found 대신 410 Gone을 반환해 철회된 경고와 존재하지 않았던 경고를 구분한다. [원문 1](<https://github.blog/changelog/2026-10-13-improved-detection-for-withdrawn-dependabot-alerts>)

### Enterprise Server 포함 일정

이 변경은 github.com의 모든 저장소에서 제공되며 GitHub Enterprise Server 3.24에도 포함될 예정이다. [원문 1](<https://github.blog/changelog/2026-10-13-improved-detection-for-withdrawn-dependabot-alerts>)
