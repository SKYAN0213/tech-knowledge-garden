# Transformers.js, 해시로 모델 파일을 공유하는 Cross-Origin Storage 실험 소개


Hugging Face 블로그는 2026년 6월 23일(한국시간), Transformers.js에서 Cross-Origin Storage 제안을 시험하는 방법을 소개했다. 서로 다른 웹사이트가 같은 모델·WebAssembly 파일을 반복 저장하는 문제를 줄이기 위해, 파일의 암호학적 해시를 키로 사용하는 공유 저장소를 제안한다. [원문 1](<https://huggingface.co/blog/cross-origin-storage>)

### 저장 시 검증과 공개 범위

파일을 쓸 때 선언한 해시와 실제 내용이 일치해야 저장된다. origins 설정은 전역 공개, 지정한 사이트 목록, 기본값인 같은 사이트 범위를 구분하며, API는 URL 대신 해시로 파일을 찾는다. [원문 1](<https://huggingface.co/blog/cross-origin-storage>)

### 선택적으로 켜는 실험 경로

글에서 소개한 API는 아직 브라우저에 기본 구현되지 않은 초기 제안이다. 확장 프로그램의 polyfill과 Transformers.js의 experimental\_useCrossOriginStorage 설정으로 시험하며, API가 없으면 기본 Cache API 경로를 사용한다.

공유 파일이 이용자의 방문 기록을 드러내지 않도록, 브라우저가 파일 존재 확인을 제한하는 방식을 제안한다. 저장소 조회 오류가 나면 앱은 네트워크 다운로드로 돌아가도록 설명했다. [원문 1](<https://huggingface.co/blog/cross-origin-storage>)
