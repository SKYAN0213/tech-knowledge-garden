# RubyGems, 5월 악성 패키지 500개 이상 제거한 사건의 조사 결과 공개


RubyGems 운영팀은 9월 11일 지난 5월의 스팸 패키지 대량 등록 사건에 대한 조사 결과를 공개했다. 당시 신규 계정 등록을 일시 중단하고 관련 계정을 차단했으며, 악성 패키지 500개 이상을 배포 목록에서 내렸다. 기존 이용자의 설치·패키지 게시 기능은 유지됐고 신규 가입은 5월 16일 재개됐다. [S7]

### 운영팀이 확인한 피해 범위와 연구자의 주장

연구자들은 일부 패키지에 다른 사용자의 API 키를 얻으려는 코드가 있었다고 보고했다. 운영팀은 그런 시도가 성공했다는 증거를 찾지 못했다고 밝혔다. 연구자들이 제기한 OpenAI 에이전트의 활동이라는 해석에 대해서도, 운영팀은 확보한 자료로 AI가 생성·게시했는지 판정하지 않았다. [S7]
