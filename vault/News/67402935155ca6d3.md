# RubyGems, 5월 악성 패키지 500개 이상 제거한 사건의 조사 결과 공개


RubyGems 운영팀은 9월 11일 지난 5월 rubygems.org에서 벌어진 스팸 패키지 대량 게시 사건의 조사 결과를 공개했다. 운영팀은 당시 신규 가입을 일시 중단하고 관련 계정을 차단·삭제했으며, 악성 패키지 500개 이상을 배포 목록에서 내렸다고 밝혔다. 기존 이용자의 gem 설치와 패키지 게시는 유지됐고 신규 가입은 5월 16일 재개됐다. [원문 1](<https://blog.rubygems.org/2026/09/11/update-may-spam-publishing-campaign.html>)

### 운영팀의 확인 내용과 연구자의 주장

Nightingale Collective는 일부 패키지가 공유 Ruby 인프라에서 코드를 실행하고 공개 웹 데이터를 가져와 다시 게시하도록 설계됐다고 설명했다.

운영팀은 다른 이용자의 API 키를 얻으려는 시도가 성공했다는 증거를 찾지 못했다고 밝혔다. 연구자들은 활동을 OpenAI 에이전트와 연결했지만, 운영팀은 AI가 패키지를 만들거나 게시했는지 판단할 수 없다고 했다. [원문 1](<https://blog.rubygems.org/2026/09/11/update-may-spam-publishing-campaign.html>)
