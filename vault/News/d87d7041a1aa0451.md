# KAIST 연구팀, 스마트폰 AI에 서버 지식을 재사용하는 CURE 개발


KAIST는 2026년 9월 21일 전산학부 이재길 교수 연구팀이 스마트폰의 소형 AI와 서버의 대형 AI를 연결하는 기기-서버 협업 기술 CURE(Cumulative Knowledge Reuse, 누적 지식 재사용)를 개발했다고 밝혔다. 대학 측에 따르면 CURE는 서버의 대형 AI에게서 얻은 지식을 스마트폰에 저장해 비슷한 문제에 재사용하고, 높은 정확도를 유지하면서 서버 호출을 평균 55.61% 줄였다. 연구진은 비슷한 문제가 반복될수록 서버 의존을 낮추고 더 빠르게 판단하는 모바일 AI의 가능성을 제시했다.
