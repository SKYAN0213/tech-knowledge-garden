# PHP 세션 취약점 CVE-2026-115560 임시 조치 권고


2026년 10월 24일자 권고문은 PHP 세션 처리 과정의 원격 코드 실행 취약점 CVE-2026-115560에 대해 PHP 개발팀이 발표한 임시 조치를 안내했다. 이 취약점은 설정 파일의 session.serialize\_handler가 php\_binary 또는 php\_serialize이고, session\_start() 전에 ini\_set()으로 해당 값을 php로 바꾸며, session.upload\_progress.enabled가 활성화된 세 조건을 모두 충족할 때 영향을 받는다. 보안 업데이트가 아직 배포되지 않아, 권고문은 업데이트 전까지 php.ini나 PHP-FPM pool 설정 등에서 session.upload\_progress.enabled=0으로 설정하고 모든 PHP 워커를 재시작하도록 안내했다. 영향받는 버전은 제조사 미공개 상태이며, 10월 21일 배포된 PHP 보안 업데이트 8.5.12, 8.4.27, 8.3.36, 8.2.35로도 해결되지 않고 차기 정기 업데이트에서 해결 버전이 배포될 예정이다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72237>)

### 임시 조치 적용 조건

session.upload\_progress.enabled는 기본값으로 활성화되어 있다. PHP2Shell(CVE-2026-109619) 임시 조치로 이미 이 값을 0으로 설정했다면 추가 적용은 필요하지 않다고 권고문은 설명한다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72237>)
