# GitHub AI Scan 정식 제공…Copilot 라이선스 없이 이용


GitHub가 한국시간 10월 16일 풀 리퀘스트(PR) 변경 코드를 검사하는 AI Scan을 정식 제공했다. Copilot 라이선스 없이 공개 저장소에서 이용할 수 있고, 조직의 비공개·내부 저장소에는 Code Security 또는 Advanced Security가 필요하며 Code Security AI Credits를 소비한다. [원문 1](<https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available>)

### 검사 범위와 병합 처리

CodeQL이 지원하지 않는 PHP·Shell/Bash·Terraform HCL·Dockerfile 등의 취약점을 보완 탐지하고 결과는 권고로 표시해 병합을 차단하지 않는다. 포크와 Dependabot이 만든 PR은 검사 대상에서 제외된다. [원문 1](<https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available>)
