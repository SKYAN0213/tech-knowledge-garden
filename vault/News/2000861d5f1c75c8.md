# AMD ROCm RCCL 입력 검증 취약점, 원격 코드 실행 가능성 보고


AMD는 9월 30일 ROCm RCCL 프록시 통신 경로의 입력 검증 취약점 CVE-2026-43598을 공개했다. 손상된 peer rank 또는 네트워크 인접 공격자 조건에서 메모리 노출과 ASLR 우회, RCCL 프로세스 내 원격 코드 실행으로 이어질 가능성이 있으며 CVSS 4.0 기본 점수는 7.7이다. 회사는 열거한 Instinct 제품에 ROCm 7.14 완화 버전을 적용할 것을 권고했다. [원문 1](<https://www.amd.com/en/resources/product-security/bulletin/amd-sb-6033.html>)

### 공격 조건과 완화 버전

권고문은 공격 조건으로 손상된 peer rank 또는 네트워크 인접 공격자를 명시한다. CVSS 기본 점수는 구현 환경에 따라 달라질 수 있으며 실제 시스템의 조건과 대조해야 한다. 제품 표의 완화 버전 ROCm 7.14는 7월 15일 공개된 것으로 기록돼 있다. [원문 1](<https://www.amd.com/en/resources/product-security/bulletin/amd-sb-6033.html>)

### 제품 표의 CVE 정정

AMD는 10월 6일 제품 표의 CVE를 정정했다. 현재 표에는 본문과 같은 CVE-2026-43598이 기재돼 있으며, 최초 공개일인 9월 30일과 정정일을 구분한다. [원문 1](<https://www.amd.com/en/resources/product-security/bulletin/amd-sb-6033.html>)
