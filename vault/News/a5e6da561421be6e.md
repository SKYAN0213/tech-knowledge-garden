# NLR, 자연어로 건물 에너지 모델을 만드는 OpenStudio-MCP 공개


National Laboratory of the Rockies(NLR)는 2026년 10월 15일 AI 비서가 자연어 요청을 OpenStudio 건물 모델링 작업으로 바꾸도록 연결하는 OpenStudio-MCP를 공개했다. 이 도구는 미국 에너지부의 EnergyPlus 시뮬레이션 엔진을 사용한다. NLR는 검증된 도구 사용 절차를 담은 모델링 스킬 150개 이상으로 사무실·학교의 기본 모델 작성, 조명·냉난방 설비 교체 같은 개선 적용, 전체 시뮬레이션 실행을 지원한다고 설명했다. [원문 1](<https://www.nlr.gov/news/detail/program/2026/building-energy-modeling-made-easy-with-natural-language-prompts>)

### 자동화하는 준비 작업과 남는 계산 시간

OpenStudio-MCP는 모델 수정 코드 작성, 실행, 출력 정리와 결과 점검 같은 반복 작업을 맡는다. NLR 연구자는 시뮬레이션 자체의 계산 시간은 물리 모델의 크기와 상세도에 좌우되며 도구가 이를 바꾸지는 않는다고 설명했다.

NLR는 OpenStudio-MCP를 오픈소스·무료 도구로 제공하며 일반 AI 비서와 연결해 사용할 수 있고 다른 개발자가 자신의 응용프로그램에 통합할 수 있다고 밝혔다. [원문 1](<https://www.nlr.gov/news/detail/program/2026/building-energy-modeling-made-easy-with-natural-language-prompts>)
