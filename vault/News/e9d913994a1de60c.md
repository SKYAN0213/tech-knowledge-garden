# 吉翼智能, 첫 산업·서비스 로봇과 Z-1 모델 공개


吉翼智能은 6월 27일 창춘에서 첫 산업용·상업 서비스 로봇과 자체 Z-1 체화지능 모델을 공개했다고 吉林省 정부가 6월 28일 보도했다. 산업용 质检家는 자동차 와이어 하니스 검사를, 상업 서비스용 小睦는 약국의 야간 무인 서비스를 겨냥한다. Z-1은 운동 제어를 반영한 토큰화와 강화학습을 사용하는 두 로봇의 의사결정 모델로 소개됐다. [원문 1](<https://www.jl.gov.cn/szfzt/gzlfz/gzdt/202606/t20260628_3645561.html>)

### 검사 로봇과 의약품 서비스

质检家에는 7축 로봇팔과 자체 산업 비전이 쓰였다. 정부 보도에 실린 발표 현장의 사람·로봇 비교에서는 작업 효율이 사람의 3배 이상이었다고 소개됐지만, 이를 모든 검사 공정의 성능으로 일반화할 시험 조건은 제시되지 않았다. 小睦는 10만 종을 넘는 의약품 데이터베이스를 갖추고 지역 의약품 체인과 협력을 진행한다고 보도됐다. [원문 1](<https://www.jl.gov.cn/szfzt/gzlfz/gzdt/202606/t20260628_3645561.html>)

### 모델 성능 주장과 생산 목표

정부 보도는 Z-1의 학습 효율이 300% 향상됐다고 전했다. 이는 발표에 귀속된 모델 성능 수치다. 회사가 세운 2030년 수십만 대급 생산능력 목표는 향후 계획이며 실제 생산량으로 집계하지 않는다. [원문 1](<https://www.jl.gov.cn/szfzt/gzlfz/gzdt/202606/t20260628_3645561.html>)
