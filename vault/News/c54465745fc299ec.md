# GitHub, Dependabot의 npm 설정 추론 중단…scope를 우선 적용


GitHub는 2026년 6월 30일(한국시간) Dependabot이 npm 비공개 레지스트리의 .npmrc 설정을 lockfile에서 추론하는 방식을 중단한다고 발표했다. 대신 dependabot.yml의 registry에 scope를 지정하면 그 설정으로 .npmrc를 생성한다. [원문 1](<https://github.blog/changelog/2026-06-30-dependabot-no-longer-infers-npmrc>)

### 설정의 우선순위

scope를 지정하면 저장소에 커밋한 .npmrc를 포함한 다른 설정 출처보다 우선한다. scope를 지정하지 않았고 저장소에 .npmrc가 있으면 기존 파일을 계속 사용한다. [원문 1](<https://github.blog/changelog/2026-06-30-dependabot-no-longer-infers-npmrc>)

### 변경 배경

GitHub는 기존 방식이 lockfile의 resolved URL을 읽어 .npmrc를 재구성했다고 설명했다. 잘못된 URL, npm·Yarn·pnpm 사이의 lockfile 형식 차이 등이 레지스트리 인증 실패를 일으켰다는 설명이다. [원문 1](<https://github.blog/changelog/2026-06-30-dependabot-no-longer-infers-npmrc>)

### 제공 대상

모든 github.com 사용자가 이용할 수 있으며, GitHub Enterprise Server에서는 3.23 버전에 포함될 예정이다. [원문 1](<https://github.blog/changelog/2026-06-30-dependabot-no-longer-infers-npmrc>)
