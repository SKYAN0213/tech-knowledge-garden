# AWS Lambda MicroVMs, 4개 리전 추가해 총 14개 리전으로 확대


AWS는 2026년 10월 22일 Lambda MicroVMs를 아시아 태평양(홍콩·말레이시아·태국)과 유럽(스페인) 등 4개 추가 리전에 제공해 총 14개 AWS 리전에서 사용할 수 있다고 밝혔다. AWS는 이번 출시로 개발자가 최종 사용자 가까운 4개 추가 리전에서 Lambda MicroVMs를 실행해 지연 시간 및 데이터 레지던시 요구를 맞추는 데 도움을 받을 수 있다고 설명했다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-microvms-4-additional-regions>)

### 격리와 상태 보존을 갖춘 실행 환경

AWS는 Lambda MicroVMs를 사용자 또는 AI가 생성한 코드를 실행하는 서버리스 컴퓨팅 프리미티브로 설명한다. VM 수준 격리와 거의 즉시 이뤄지는 실행·재개, 상태 보존을 제공한다고 밝혔다.

개발자는 가상화 인프라를 직접 관리하지 않고 격리·속도·상태 보존 중 하나를 포기하지 않으면서 사용자나 작업마다 독립된 컴퓨팅 환경을 줄 수 있으며, AWS가 든 활용 예는 AI 코딩 어시스턴트, 대화형 개발 환경, 취약점 스캐너다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-microvms-4-additional-regions>)

### 이미지 생성부터 접속까지

개발자는 Dockerfile로 MicroVM 이미지를 만든 뒤 그 이미지에서 MicroVM을 실행한다. 사용자나 작업별 MicroVM에는 전용 HTTPS URL을 부여할 수 있고, 이 URL은 HTTP/2·gRPC·WebSockets를 지원한다.

서비스는 AWS Lambda 콘솔, AWS CloudFormation, AWS Cloud Development Kit 또는 Agent Toolkit for AWS를 사용하는 에이전트 개발 도구로 이용할 수 있다고 AWS는 안내했다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/lambda-microvms-4-additional-regions>)
