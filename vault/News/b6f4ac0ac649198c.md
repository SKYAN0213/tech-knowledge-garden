# ASEC, 불법 프로그램 위장 Rust 인포스틸러의 정보 탈취·추가 악성코드 기능 분석


2026년 10월 21일 AhnLab SEcurity intelligence Center(ASEC)는 불법 프로그램으로 위장한 신종 정보탈취형 악성코드(인포스틸러)를 확인했다고 밝혔다. ASEC에 따르면 이 악성코드는 8월 중순 처음 발견됐고, 초기 소규모 배포에서 Autolt를 사용한 뒤 Explorer 프로세스 인젝션이나 독립 실행 방식으로 바뀌어 9월 초 대량 유포가 본격화됐으며 일부 샘플은 별도 다운로더를 거쳤다. 악성코드는 브라우저와 업무용 프로그램에 저장된 정보를 노리고, C2 설정에 따라 수집 범위와 후속 동작이 달라져 추가 피해로 이어질 수 있다고 ASEC는 설명했다. [원문 1](<https://asec.ahnlab.com/ko/95936/>)

### 유포와 실행 회피

ASEC은 일부 샘플이 Rust로 작성됐으며 동적 JMP를 활용한 안티 디스어셈블, CPU 메모리 캐시 조회를 이용한 안티 샌드박스, DLL 인젝션을 사용했다고 분석했다. 보고서는 이러한 기법이 기존 인포스틸러에서 흔하지 않았다고 설명한다.

실행 환경을 샌드박스나 가상 환경으로 판단한 샘플은 정보 탈취를 수행하지 않고 종료했다. 최근 유포된 일부 샘플은 내부에 암호화해 둔 DLL을 복호화한 뒤 Explorer 프로세스에 주입했다.

참조 문자열은 사용 직전까지 암호화해 두며, 샘플별로 달라지는 변형 색인 테이블을 사용한다. 복호화 함수에 전달된 정수 값으로 테이블을 회전해 같은 평문도 키에 따라 다르게 암호화할 수 있고, 암호문 끝에 임의 문자열을 붙여 원래 길이를 추정하기 어렵게 했다. [원문 1](<https://asec.ahnlab.com/ko/95936/>)

### C2 통신과 수집 범위

실행되면 설치 프로그램 목록, CPU 이름, 그래픽 드라이버 정보, CPUID 명령 데이터, Windows 버전 등 PC 기본 정보를 공격자가 통제하는 C2 서버로 보낸다. 이후 서버 설정 데이터가 정보 수집 대상과 추가 동작을 정한다.

ASEC은 송신 데이터를 XOR로 암호화한 뒤 Windows의 LZNT1 알고리즘으로 압축하고, 수신 데이터는 XOR로 복호화한다고 설명했다. XOR 키는 샘플마다 달랐으며, 보고서는 네트워크 통신 내용 기반 탐지를 피하려는 의도일 수 있다고 추정했다.

확인된 C2 설정은 인증서, SSH 키, 암호화폐 지갑, 설정 파일과 문서를 포함한 폭넓은 프로그램·파일을 탈취 대상으로 지정했다. 실제 수집 범위는 C2 설정에 따라 달라질 수 있으며 VPN이나 원격접속 자격정보가 노출되면 내부 시스템 무단 접근이나 추가 공격에 악용될 수 있다고 ASEC은 경고했다. [원문 1](<https://asec.ahnlab.com/ko/95936/>)

### 추가 payload와 점검 항목

C2 설정에 지정된 외부 URL에서 payload를 내려받아 실행하는 기능도 있다. 분석된 설정에서는 이 기능이 활성화되어 있어 다른 악성코드를 배포하는 드로퍼로 활용될 수 있다고 ASEC은 설명했다.

ASEC은 신뢰할 수 없는 출처에서 내려받거나 압축을 푼 대용량 ZIP 안의 실행 파일을 실행한 이력을 확인하라고 권고했다. 함께 살펴볼 흔적으로는 autoit.exe 또는 explorer.exe 관련 비정상 코드 주입, 의심스러운 C2 통신, 정보 탈취와 추가 악성코드 설치 흔적을 들었다. [원문 1](<https://asec.ahnlab.com/ko/95936/>)
