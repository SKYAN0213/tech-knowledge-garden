# AWS, AgentCore 공동 인프라에서 고객 데이터·메모리·비용을 나누는 예제 공개


AWS는 2026년 6월 24일(한국시간), Amazon Bedrock AgentCore로 여러 고객이 인프라를 공유하면서 데이터를 분리하는 구현 예제를 공개했다. 진료소·병원을 가정한 예제에서 서비스 등급·고객·사용자 계층에 따라 문서 검색, 에이전트 기억, 모델 사용과 비용 추적을 구성했다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/shared-infrastructure-isolated-tenants-pool-model-multi-tenancy-with-amazon-bedrock-agentcore/>)

### 검색·도구·메모리의 고객 범위

Cognito 토큰의 서비스 등급과 clinic\_id를 고객 문맥으로 전달한다. 서비스 등급별 S3 버킷 안의 고객 경로로 문서를 나누고, Knowledge Base 검색에는 clinic\_id 메타데이터 필터를 적용한다.

Gateway는 Lambda의 patient\_context·clinic\_config 함수를 MCP 도구로 제공한다. 고객 문맥을 헤더로 전달하며, 도구 Lambda는 고객 태그를 가진 임시 자격증명으로 DynamoDB의 접근 범위를 제한하는 패턴을 사용한다.

메모리는 서비스 등급·clinic\_id·사용자 ID를 합친 actor\_id와 이름공간으로 구분한다. 실행 시 얻는 임시 자격증명에 같은 세 가지 태그를 넣어 접근 범위를 제한한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/shared-infrastructure-isolated-tenants-pool-model-multi-tenancy-with-amazon-bedrock-agentcore/>)

### 서비스 등급 비용과 고객별 토큰 사용량

서비스 등급마다 Bedrock Project와 비용 태그를 두고 추론 요청에 프로젝트 ID를 전달한다. 고객별 사용량은 clinic\_id·모델·입출력 토큰을 구조화 로그로 기록하며, 비용은 토큰 수와 모델별 단가로 추산하는 방식이다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/shared-infrastructure-isolated-tenants-pool-model-multi-tenancy-with-amazon-bedrock-agentcore/>)
