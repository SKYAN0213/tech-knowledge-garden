# Amazon SageMaker Unified Studio, 역할별 custom designations 지원


Amazon SageMaker Unified Studio는 2026년 10월 29일, 관리자가 조직의 역할에 맞춰 이름 붙인 권한 집합인 custom designations를 정의해 프로젝트 구성원에게 할당하는 기능을 발표했다. 기존에는 권한이 거의 같은 Owner와 Contributor만 지정할 수 있었지만, 새 designation은 프로젝트의 모든 작업을 통제하며 관리자가 권한 범주를 골라 도메인 수준에서 정의하고 그 도메인의 여러 프로젝트에 할당하면 시스템이 작업별 허용 여부를 판정한다. AWS가 든 예에서 Data Steward는 구독 요청 승인과 자산 게시 권한을 받을 수 있고 Analyst는 데이터 조회와 노트북 실행으로 제한될 수 있으며, 데이터 엔지니어·스튜어드·분석가와 자동화 파이프라인은 권한을 나눠 권한 격리용 별도 프로젝트를 만들 필요 없이 같은 프로젝트에서 작업할 수 있다. 각 도메인에는 관리형 designation 두 개(Owner와 Contributor)가 포함되고 관리자는 추가 designation을 최대 10개까지 만들 수 있으며, 이 기능은 Amazon SageMaker Unified Studio가 제공되는 모든 AWS 리전에서 이용할 수 있다.
