# Google Cloud, 에이전트 격리용 GKE Agent Substrate와 고속 저장 VM 공개


Google Cloud는 9월 30일 월간 인프라 업데이트에서 GKE Agent Substrate의 샌드박스 실행·격리와 M4N·Z4D VM을 소개했다. 회사는 GKE Agent Substrate의 밀도가 일반 컨테이너 런타임보다 10배 높고 재개 시간은 500밀리초 미만이라고 설명했다. M4N과 Z4D는 정식 제공됐으며 에이전트 격리 파일 작업공간을 연결하는 Filestore agent volumes는 프리뷰 접근 신청 단계다. [원문 1](<https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month>)

### 샌드박스 재개와 영구 작업공간

GKE Agent Substrate는 커널·네트워크 격리를 적용하며 회사가 제시한 suspend/resume 활성화 수는 초당 500회를 넘는다. Filestore agent volumes는 Agent Substrate·Agent Sandbox와 연계해 전용 격리 파일 작업공간을 연결하는 별도 저장 구성으로 소개됐다. [원문 1](<https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month>)

### M4N 저장 성능과 Z4D bare metal 구성

M4N은 Titanium과 Hyperdisk Extreme 조합에서 최대 25,000MiB/s 호스트 저장 성능과 최대 100만 IOPS를 제공한다고 회사는 설명했다. Z4D는 bare metal 구성의 로컬 SSD 용량과 지연을 에이전트 microVM 실행에 활용하는 VM이다. 해당 수치는 회사가 제시한 구성과 최대치 조건을 따른다. [원문 1](<https://cloud.google.com/blog/topics/ai-infrastructure/whats-new-in-ai-infrastructure-this-month>)
