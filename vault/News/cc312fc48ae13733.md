# OpenAI, Genesis 연구자 약 2,000명에 Codex 이용 지원 계획


OpenAI는 7월 22일 미국 에너지부 Genesis Mission 참여 연구자에게 모델 접근과 기술 협력·연구 자원을 지원할 계획을 발표했다. 국립연구소와 대학의 연구자 약 2,000명에게 400만 달러 규모의 Codex 이용을 지원하고 두 과학 캠페인에 300만 달러의 API 지원을 약속했다. [원문 1](<https://openai.com/index/advancing-the-next-era-of-national-science/>)

### API 이용 지원 조건과 모델 접근

참여 연구자가 250만 달러를 지출하면 최대 1,000만 달러의 API 이용을 제공하는 조건도 발표했다. 적격 생물학 연구자에게 GPT-Rosalind를 제공하고, 일부 연구소 책임자에게 모델·기능의 조기 접근을 지원할 계획이다.

일부 국립연구소 사이버보안 연구자에게 방어 연구를 위한 접근도 확대할 계획이다. [원문 1](<https://openai.com/index/advancing-the-next-era-of-national-science/>)

### 초기 과학 캠페인 후보

고온 초전도체 연구는 AI·시뮬레이션·재료 전문지식·실험을 결합해 더 높은 온도와 실용적 압력에서 작동하는 재료를 탐색하는 방향이다.

Atlas of the Machine-Accessible Frontier는 기존 지식·데이터·계산으로 AI 연구가 접근할 수 있는 문제와 물리 실험 근거가 필요한 문제를 구분하는 캠페인 후보다. [원문 1](<https://openai.com/index/advancing-the-next-era-of-national-science/>)
