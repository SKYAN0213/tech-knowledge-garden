# AWS, AgentCore Gateway에 Bedrock API와 모델 대체 라우팅 추가


AWS는 2026년 10월 22일 Amazon Bedrock AgentCore Gateway의 추론 엔드포인트가 Amazon Bedrock InvokeModel 및 InvokeModelWithResponseStream API와 추론 트래픽용 모델 대체 라우팅을 지원한다고 밝혔다. AWS에 따르면 기본 목적지가 요청 제한, 용량 부족 또는 연결 불가 상태일 때 게이트웨이는 대체 모델이나 제공자로 요청을 라우팅해 클라이언트마다 별도의 재시도 로직을 구현할 필요를 줄인다. 이 기능은 중국을 제외하고 AgentCore Gateway를 제공하는 모든 AWS 리전에서 이용할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/agentcore-gateway-invokemodel-fallback/>)

### 전환 규칙과 클라이언트 연결

사용자는 게이트웨이 규칙에 대체 목적지의 순서와 전환 조건을 지정한다. 전환 조건에는 요청 제한, 서버 오류, 응답 시간 초과 등이 있으며, 내장 회로 차단기는 현재 실패 중인 목적지를 건너뛴다.

AWS는 대체 목적지를 찾는 내부 시도가 게이트웨이 뒤에서 처리되므로 클라이언트는 요청 하나를 보내고 응답 하나를 받는다고 설명한다.

기존 Amazon Bedrock SDK 연동을 게이트웨이에 연결하면 제공자별로 클라이언트 코드를 다시 작성하지 않고도 하나의 관리 엔드포인트를 통해 모델 제공자에 접근할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/agentcore-gateway-invokemodel-fallback/>)
