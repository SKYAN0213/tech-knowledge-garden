# AWS GovCloud Kiro에서 Claude Sonnet 5.5·Opus 5.5 이용 가능


AWS는 2026년 10월 9일, Anthropic의 Claude Sonnet 5.5와 Claude Opus 5.5를 AWS GovCloud (US) 리전의 Kiro IDE와 CLI에서 이용할 수 있다고 밝혔다. AWS 공지에 따르면 Kiro 내부 벤치마킹에서 Opus 5.5는 장시간 에이전트 코딩 작업을 Opus 5보다 약 40% 적은 도구 호출과 약 절반의 토큰으로 완료했으며, 1M 컨텍스트 윈도우와 2.0x 크레딧 배수로 제공된다. AWS는 Sonnet 5.5가 Sonnet 5보다 출력이 30% 초과 빠르며 1M 컨텍스트 윈도우와 1.3x 크레딧 배수로 제공된다고 설명했다. 새 모델을 이용하려면 IDE 또는 CLI를 최신 버전으로 업데이트한 뒤 재시작하고 모델 선택기에서 선택해야 한다.
