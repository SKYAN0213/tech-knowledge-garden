# GitHub Enterprise Cloud, 팀 구성원을 비용센터에 자동 귀속


GitHub는 2026년 6월 25일(한국시간), Enterprise Cloud의 비용센터에 엔터프라이즈 팀을 리소스로 추가하는 기능을 발표했다. 팀 구성원이 발생시킨 사용량은 해당 비용센터에 귀속되며, 구성원 변경에 맞춰 귀속 대상도 자동으로 갱신된다. [원문 1](<https://github.blog/changelog/2026-06-25-assign-enterprise-teams-to-cost-centers/>)

### 팀 구성과 지출 한도

수동 구성원 변경과 SCIM을 통한 인증 제공자 동기화가 비용 귀속에 반영된다. 예산과 사용량 한도는 팀 자체가 아니라 비용센터에 설정한다. [원문 1](<https://github.blog/changelog/2026-06-25-assign-enterprise-teams-to-cost-centers/>)

### 설정 위치와 대상 정정

엔터프라이즈의 Billing and licensing에서 Cost centers를 열고, 비용센터 생성·수정 시 Resources에 엔터프라이즈 팀을 추가한다.

GitHub는 6월 26일 편집자 주석에서 billing manager를 이용 대상에 잘못 포함했다고 정정했다. 현재 글은 GitHub Enterprise Cloud의 enterprise owner를 대상으로 명시한다. [원문 1](<https://github.blog/changelog/2026-06-25-assign-enterprise-teams-to-cost-centers/>)
