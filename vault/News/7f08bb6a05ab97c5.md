# GitHub, 오픈소스 라이선스 준수 기능 공개 프리뷰 제공


GitHub는 2026년 7월 1일(한국시간) 기업의 오픈소스 라이선스 정책에 맞지 않는 의존성을 PR 병합 전에 차단할 수 있는 기능을 공개 프리뷰로 제공했다. GitHub Advanced Security Code Security 라이선스를 보유한 GitHub Enterprise Cloud 고객이 대상이다. [원문 1](<https://github.blog/changelog/2026-06-30-open-source-license-compliance-is-in-public-preview>)

### 기업 정책을 PR 검사에 적용

기존 dependency review action을 확장해 기업 전체 라이선스 정책을 적용한다. 저장소를 지정하는 규칙에서 Require license compliance check results before merging 조건을 활성화하면, 의존성을 추가하거나 수정하는 PR에 정책 검사가 실행되고 비준수 의존성이 표시된다. [원문 1](<https://github.blog/changelog/2026-06-30-open-source-license-compliance-is-in-public-preview>)

### 비준수 의존성과 승인 요청 처리

표시된 문제는 의존성을 제거하거나 교체하고, 정책을 수정하거나 패키지 예외를 만드는 방법으로 해결해야 한다.

새 역할인 Enterprise Open Source License Policy Manager는 개인이나 팀에 지정할 수 있다. 정책 관리자는 대기 중인 요청의 이메일 알림을 받고 기업 콘솔에서 종료 요청을 검토·승인한다. [원문 1](<https://github.blog/changelog/2026-06-30-open-source-license-compliance-is-in-public-preview>)
