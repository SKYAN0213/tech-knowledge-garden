# AWS, OpenSearch Serverless에 S3용 지능형 수집 기능 제공


AWS는 2026년 10월 22일 Amazon OpenSearch Serverless에 S3의 로그와 문서를 검색 가능한 콘텐츠로 바꾸는 완전 관리형 intelligent ingestion을 제공한다고 밝혔다. 이 기능은 JSON·NDJSON·JSON array 형식의 관측 로그와 구조화 데이터, PDF·Word·일반 텍스트·Markdown 파일을 지원한다. Amazon S3를 소스로 하는 Amazon OpenSearch Serverless (NextGen) 컬렉션에서 AWS 7개 리전에 제공되며, 마이그레이션·백필용 일회성 작업과 새 객체를 반영하는 수집 스트림을 지원한다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-opensearch-intelligent-ingestion-logs-documents-s3>)

### 입력 처리와 용량·과금 범위

AWS 설명에 따르면 Console에서 몇 번의 클릭 또는 API 호출 한 번으로 수집을 설정할 수 있다. S3 소스와 컬렉션 인덱스를 지정하면 데이터 유형 감지, 문서 파싱, 텍스트 분할과 색인 처리를 맡으므로 별도의 수집·문서 처리 인프라를 관리할 필요가 없다.

구조화 데이터에는 파이프라인 코드 없이 변환을 적용하고 임베딩을 선택적으로 추가할 수 있다. 비구조화 문서는 제목 구조와 읽기 순서, 표를 보존해 파싱하며, 차트·도표·스크린샷·사진이 있는 문서는 비전 언어 모델이 만든 설명도 주변 콘텐츠와 함께 색인한다.

S3 소스 버킷은 컬렉션과 같은 AWS 계정이나 다른 계정에 둘 수 있다. 처리 용량은 워크로드에 따라 컬렉션에 설정된 한도까지 확장되며, 사용자는 실제 처리가 이뤄지는 동안에만 요금을 낸다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-opensearch-intelligent-ingestion-logs-documents-s3>)
