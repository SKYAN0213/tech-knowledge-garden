# ASEC, PHP2Shell 재현 공개…AhnLab EDR 탐지 사례 소개


AhnLab SEcurity intelligence Center(ASEC)는 2026년 10월 22일 공개 PoC를 참고해 PHP2Shell 취약점 재현 테스트를 진행하고 AhnLab EDR 탐지 사례를 소개했다. 대상은 PHP 내부 요청 처리 과정의 CVE-2026-109618과 CVE-2026-109619로, 두 취약점 모두 인증되지 않은 공격자의 원격 코드 실행으로 이어질 수 있다고 보고됐다. ASEC이 정리한 평가에서 두 취약점은 각각 CVSS v4.0 9.2점이며, PHP 보안팀은 하루 전인 10월 21일 수정 업데이트를 배포하고 PHP 8.2\~8.5 사용자에게 즉시 업데이트를 권고했다. 문서에 적힌 계열별 수정 버전은 PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35이며, 업데이트 뒤 웹 서비스를 재시작하도록 안내한다. [원문 1](<https://asec.ahnlab.com/ko/95955/>)

### 두 취약점의 원인

ASEC 문서는 CVE-2026-109618을 메모리 부족으로 요청 처리가 중단될 때 데이터가 완전히 초기화되지 않은 채 남아 정리 과정에서 잘못된 데이터가 유효한 것으로 취급될 수 있는 문제로 설명했다. 해당 취약점의 잠재적 영향은 인증 없는 원격 코드 실행으로 기재됐다.

CVE-2026-109619은 요청 처리에 쓰인 내부 상태가 메모리 해제 뒤에도 남아 초기화 전에 후속 요청에서 재사용될 가능성으로 설명됐다. ASEC 자료는 이 취약점도 인증 없는 원격 코드 실행의 잠재적 영향을 가지며 CVSS v4.0 점수를 9.2로 제시한다. [원문 1](<https://asec.ahnlab.com/ko/95955/>)

### 공개 PoC 재현 과정

ASEC의 재현 타임라인은 0\~6초에 공격자와 피해 서버 IP 주소를 확인하고, 6\~16초에 PHP 웹사이트 대상 테스트 스크립트를 실행하는 순서다. 16\~20초에는 피해 서버가 공격자 PC에 연결되어 공격자가 피해 서버의 명령 셸을 사용할 수 있게 되는 장면을 제시한다.

이어 20\~23초 구간에는 명령이 서버의 웹 계정인 www-data 권한으로 실행되는 것을 확인하고, 23\~29초에는 서버 IP 주소를 확인해 재현 접속이 대상 서버에 도달했는지 검증한다고 설명한다. 이는 ASEC이 공개 PoC를 참고해 수행한 재현 과정이다. [원문 1](<https://asec.ahnlab.com/ko/95955/>)

### 패치와 탐지 정보

ASEC의 안내는 PHP 보안 업데이트 적용 뒤 웹 서비스를 재시작하도록 한다. AhnLab EDR/XDR 설명은 PHP 서비스에서 발생하는 의심스러운 명령 실행이나 파일 생성 등 행위를 위협 또는 주요 행위로 탐지해 관리자의 원인 파악과 대응·재발 방지 절차 수립을 돕는다는 내용이다. [원문 1](<https://asec.ahnlab.com/ko/95955/>)
