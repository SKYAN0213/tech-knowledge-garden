# Palantir·NVIDIA, 미국 정부용 Nemotron 자체 운영 환경 발표


NVIDIA는 2026년 6월 29일 Palantir가 미국 정부기관·중요 인프라 운영자를 위한 AI 엔진에 Nemotron 공개 모델을 적용한다고 발표했다. 기관은 자체 인프라와 데이터로 모델을 운영·학습하고, 학습 결과의 가중치도 소유하는 구조다. [원문 1](<https://blogs.nvidia.com/blog/palantir-secure-ai-us-agencies-nemotron-open-models/>)

### 격리된 모델 실행과 데이터 권한

NVIDIA 설명에서 에어갭은 비보안 네트워크와 완전히 분리된 실행 환경이다. Nemotron은 이 환경의 NVIDIA 가속 컴퓨팅 위에서 실행된다.

Palantir의 운영체계는 AIP·Ontology·Foundry·Apollo를 기반으로 데이터 접근 권한, 구조적 격리, 감사 기록을 담당한다.

모델 개선에는 고객 환경에서 나온 새 데이터와 피드백을 사용하며, 기업용 배포 지원 계층으로 NVIDIA AI Enterprise를 제시했다. [원문 1](<https://blogs.nvidia.com/blog/palantir-secure-ai-us-agencies-nemotron-open-models/>)
