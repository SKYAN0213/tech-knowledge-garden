# GitHub, 커버리지 기준에 따른 PR 병합 보호 공개 프리뷰


GitHub는 2026년 7월 1일(한국시간) 테스트 커버리지 기준을 충족하지 못한 풀 리퀘스트(PR)의 병합을 막는 기능을 공개 프리뷰로 제공했다. github.com의 GitHub Code Quality 사용자를 대상으로 하며, 브랜치 규칙으로 병합 조건을 설정한다. [원문 1](<https://github.blog/changelog/2026-06-30-github-code-coverage-merge-protection-for-pull-requests>)

### 커버리지 기준과 적용 모드

최소 커버리지 비율과 기본 브랜치 대비 허용할 최대 감소 폭 중 하나 또는 둘 다 설정할 수 있다. 평가 모드에서 영향을 먼저 확인한 뒤 활성 모드로 전환해 병합을 차단할 수 있다. [원문 1](<https://github.blog/changelog/2026-06-30-github-code-coverage-merge-protection-for-pull-requests>)

### 제공 대상

GitHub Code Quality는 GitHub Enterprise Cloud와 Team에서 제공되며, GitHub Enterprise Server에서는 제공되지 않는다. 프리뷰 기간에는 무료다. [원문 1](<https://github.blog/changelog/2026-06-30-github-code-coverage-merge-protection-for-pull-requests>)
