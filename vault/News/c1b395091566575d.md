# GitHub Copilot, 저장소 개요를 대화로 요청하는 기능 제공


GitHub는 7월 9일 github.com에서 저장소 개요를 요청하는 GitHub Copilot 기능을 모든 요금제에 제공한다고 밝혔다. 아직 기여하지 않은 저장소를 처음 살펴볼 때 개요 생성을 제안하고, Copilot Chat에서 요청하면 목적·사용 기술·기여 지침을 요약한다. [원문 1](<https://github.blog/changelog/2026-07-09-ask-copilot-for-a-repository-overview/>)

### README가 없는 저장소

GitHub는 README가 없는 저장소라면 Copilot으로 README를 생성할 수 있다고 설명했다. 저장소가 무엇을 하는지, 어떤 기술을 사용하는지 파악하도록 돕는 기능이다. [원문 1](<https://github.blog/changelog/2026-07-09-ask-copilot-for-a-repository-overview/>)
