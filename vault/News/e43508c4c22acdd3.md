# NVIDIA, 원자 시뮬레이션 도구 공개…반도체 설계·제조로 CUDA-X 확대


NVIDIA가 10월 14일 원자·분자 상호작용을 계산하는 CUDA-X 라이브러리 cuPotential의 얼리 액세스를 발표했다. 회사는 초기 접근 테스트에서 이미 GPU에 최적화된 시뮬레이션 작업을 추가로 2\~3배 가속했다고 설명했다. [원문 1](<https://nvidianews.nvidia.com/news/nvidia-and-semiconductor-leaders-advance-ai-across-chip-design-and-manufacturing-for-ai-defined-labs>)

### 공정 모델링과 검사·로봇 시뮬레이션

Lam Research는 식각 공정 모델링 플랫폼 SEMulator3D에 NanoVDB를 통합해 특정 웨이퍼 식각 모델링을 최대 30배 가속하는 기능을 연말 출시 목표로 개발한다.

KLA의 영상 처리 커널은 이전 CPU 버전 대비 50배 성능을 냈다는 결과가 소개됐다. FANUC과 Foxconn은 공장 디지털 트윈에서 배치 전 로봇 동작을 검증하도록 로봇 모델을 Mega Omniverse Blueprint에 연결하고 있다. [원문 1](<https://nvidianews.nvidia.com/news/nvidia-and-semiconductor-leaders-advance-ai-across-chip-design-and-manufacturing-for-ai-defined-labs>)
