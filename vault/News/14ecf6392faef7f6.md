# CodeQL, macOS 27·Xcode 27에서 빌드 추적 지원 제한


한국시간 2026년 10월 19일 공개된 CodeQL 안내에 따르면 macOS 27과 Xcode 27부터 일부 시스템 바이너리와 라이브러리에서 빌드 추적에 필요한 Intel(x86\_64) 코드가 빠져, CodeQL은 이 운영체제와 개발환경의 traced scan을 지원하지 않고 Swift 6.4도 분석하지 못한다. Xcode 27이 설치되면 C/C++, C\#, Go, Java, Kotlin, Swift의 traced extraction을 사용할 수 없고, macOS 27에서는 같은 언어들의 extraction이 불가능할 수 있다. CodeQL은 Swift 6.4를 모든 플랫폼에서 지원하지 않으며, Intel 기반 Mac 지원은 2026년 12월 중순부터 deprecated 상태로 전환될 예정이다. [원문 1](<https://github.blog/changelog/2026-10-19-codeql-changes-for-macos-27-xcode-27-and-swift-6-4>)

### 워크플로 고정과 대안

Swift 스캔이나 다른 언어의 traced build를 사용하는 경우 macOS 26 이하와 Xcode 26 이하에 워크플로를 고정하라는 안내다. GitHub Actions에서는 최신 버전에 의존하지 말고 runner image와 toolchain을 워크플로에 고정하도록 했다.

C/C++, C\#, Java는 build mode none으로 전환할 수 있으며, 이 모드는 빌드 추적을 요구하지 않는다. [원문 1](<https://github.blog/changelog/2026-10-19-codeql-changes-for-macos-27-xcode-27-and-swift-6-4>)
