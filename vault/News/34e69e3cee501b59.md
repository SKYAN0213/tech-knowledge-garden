# 앤트로픽, 클로드 오피스 도구 정식 출시하고 대시보드·애니메이션 기능 추가


2026년 10월 9일 디일렉 보도에 따르면, 앤트로픽은 클로드에 데이터 대시보드와 애니메이션 제작 기능을 추가했으며 코딩 없이 자연어로 비즈니스 데이터 분석과 시각화 콘텐츠를 만들 수 있다고 설명했다. 베타 테스트를 거친 Docs, Slides, Design은 모든 요금제 사용자에게 정식 출시됐다. 보도에서 소개한 Claude Dashboards는 기업 내부 데이터 플랫폼과 CRM에 연동돼 실시간 대시보드와 분석 리포트를 생성하며, 유료 구독자에게 베타로 우선 제공된다. Claude Motion은 수정 가능한 애니메이션을 만들고 비디오 파일로 내보내며, 팀 및 엔터프라이즈 요금제 고객에게 베타 버전으로 제공된다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63510>)

### 기존 아티팩트 기능의 확장

앤트로픽은 앞서 Claude Cowork의 라이브 아티팩트와 Claude Code 아티팩트로 데이터 연동 및 자동 갱신 대시보드를 선보였고, 이번 기능을 비개발자용으로 확장했다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63510>)

### 기업 환경에서 필요한 조건

기업 환경에서 데이터 시각화를 활용하려면 지표 정의를 통일하는 시맨틱 레이어와 접근 권한 관리, 감사 기록, 대규모 데이터 처리가 요구된다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63510>)
