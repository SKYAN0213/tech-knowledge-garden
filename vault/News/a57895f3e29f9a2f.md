# CycloneDX 저장소에 Agent BOM 구성 요소 추적안 등록


2026년 3월 26일 CycloneDX 명세 저장소에 AI 에이전트의 구성 요소를 추적하는 Agent BOM 제안이 등록됐다. 제안은 MCP 서버·도구·모델·자격증명을 에이전트의 구성 명세에 포함하자는 내용이다. [원문 1](<https://github.com/CycloneDX/specification/issues/895>)

### 제안에 포함한 식별 정보

MCP 서버는 이름·버전·해시를, 도구는 정의와 기능 권한 범위를 기록하도록 제안했다. 모델 항목에는 모델 ID·버전·출처, 신원 항목에는 에이전트 ID·신뢰 수준·서명 키 지문을 포함한다.

글은 제재 목록 확인 상태와 지출 한도·금융 권한도 추적 대상으로 제시했다. 자율 에이전트가 어떤 구성 요소를 사용하고 어떤 작업을 허용받았는지를 확인하려는 저장소 제안이다. [원문 1](<https://github.com/CycloneDX/specification/issues/895>)
