# GitHub, 오래된 Dependabot 보안 알림을 CSV 보관으로 전환 예고


GitHub는 2026년 6월 30일(한국시간) 닫힌 Dependabot 보안 알림에 대한 데이터 보존 정책을 예고했다. 정책은 github.com과 GitHub Enterprise Cloud에 적용하며 GitHub Enterprise Server는 대상에서 제외한다. [원문 1](<https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts>)

### 열린 알림과 닫힌 알림의 조회 범위

열린 알림은 오래돼도 화면과 API에서 조회할 수 있고, 닫힌 알림은 종료 후 2년 동안 조회할 수 있다. 그보다 오래된 닫힌 알림은 보관 저장소로 옮기고, 기업·조직·저장소 관리자와 보안 관리자가 해당 수준의 보안 알림 페이지에서 CSV로 내려받도록 한다. [원문 1](<https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts>)

### 갱신된 공지의 적용 일정

갱신된 공지는 적용 예정일을 2026년 9월 25일로 명시한다. Dependabot 이외의 알림 유형에 대한 변경 일정은 시행 최소 60일 전에 changelog로 알리겠다고 밝혔다. [원문 1](<https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts>)

### 보관 기간과 저장 지역

GitHub는 계정이 유지되는 동안 보관 알림의 원래 내용을 보존한다고 설명했다. 데이터 거주 지역을 지정한 Enterprise Cloud에서는 보관 알림도 기존 데이터와 같은 지역에 남는다. 관련 저장소·조직·계정을 삭제하거나 기업 계약이 종료되면 알림 데이터도 삭제된다. [원문 1](<https://github.blog/changelog/2026-06-30-cloud-data-retention-policy-for-closed-security-alerts>)
