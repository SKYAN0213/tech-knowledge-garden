# GitHub Actions, 같은 작업 안에서 단계 병렬 실행 지원


GitHub는 2026년 6월 26일(한국시간), Actions의 단일 작업 안에서 여러 단계를 동시에 실행하는 기능을 발표했다. 각 단계의 로그를 분리한 채 백그라운드 실행·완료 대기·종료를 제어할 수 있다. [원문 1](<https://github.blog/changelog/2026-06-25-actions-steps-can-now-be-run-in-parallel/>)

### 단계 실행과 대기

background: true는 단계를 비동기로 실행하고 다음 단계로 진행한다. wait는 지정한 백그라운드 단계 하나 또는 여러 개를, wait-all은 앞서 실행한 백그라운드 단계 모두를 기다린다.

cancel은 필요 없어진 백그라운드 단계를 종료한다. parallel은 여러 단계를 백그라운드로 실행한 다음 기다리는 패턴을 한 구문으로 묶는다. [원문 1](<https://github.blog/changelog/2026-06-25-actions-steps-can-now-be-run-in-parallel/>)

### 단일 작업 안의 활용 예

공식 글은 여러 빌드의 동시 실행, 서비스를 띄운 뒤 관련 작업을 수행하고 종료하는 흐름, 패키징 중 원격 분석 데이터를 전송하는 경우를 예로 들었다. 기존 셸의 & 실행과 달리 개별 단계의 로그를 나눠 유지한다. [원문 1](<https://github.blog/changelog/2026-06-25-actions-steps-can-now-be-run-in-parallel/>)
