# Amazon Bedrock, Anthropic Claude 전 모델에 structured outputs 지원


2026년 10월 20일 Amazon Bedrock은 bedrock-runtime과 bedrock-mantle 엔드포인트 모두에서 Anthropic Claude의 모든 모델에 structured outputs를 지원한다고 밝혔다. 이 기능은 Claude 모델이 제공되는 곳에서 사용할 수 있으며, boto3와 bedrock-runtime APIs 또는 Messages API와 bedrock-mantle endpoint로 호출하면 별도의 사용자 정의 파싱, 재시도 로직, 후처리 없이 정의된 구조에 맞는 JSON 응답을 받을 수 있다.
