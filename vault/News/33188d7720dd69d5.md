# AWS, Bedrock 모델 사양·가격·지역을 비교하는 오픈소스 Model Profiler 소개


AWS는 2026년 7월 2일(한국시간) 오픈소스 Amazon Bedrock Model Profiler의 수집·비교·배포 기능을 소개했다. 이 웹 도구는 모델 기능·가격·지역별 제공 정보를 하나의 검색 가능한 화면에 모아 모델 선택에 사용한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-model-selection-in-amazon-bedrock-with-the-open-source-model-profiler/>)

### 검색과 모델별 상세 정보

Model Explorer는 공급사·기능·입출력 모달리티·지역·수명주기 상태로 필터링하고 카드 또는 표로 보여준다. 모델 이름·설명·공급사 정보를 대상으로 전문 검색을 지원한다.

상세 화면에서는 모달리티·컨텍스트 창·추론 유형, 지역·이용 방식별 가격, 교차 리전 추론을 포함한 제공 범위, 지역별 분당 토큰·요청 수 쿼터와 공식 문서 링크를 확인한다.

즐겨찾기 목록은 브라우저 세션이 바뀌어도 유지되며, 저장한 모델에 대해서도 필터·정렬·상세 보기를 제공한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-model-selection-in-amazon-bedrock-with-the-open-source-model-profiler/>)

### 동시 비교와 지역별 제공 방식

동시에 비교할 수 있는 모델은 최대 25개다. 가격, 지역별 제공 여부, 컨텍스트·출력 토큰 등 사양과 기능을 나란히 비교한다.

지역 화면은 모델별·지역별 행렬로 제공 여부를 표시하고, 같은 지역에서의 추론·교차 리전 추론·Mantle을 구분한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-model-selection-in-amazon-bedrock-with-the-open-source-model-profiler/>)

### 공통 수집과 데이터 처리

자료는 AWS API 5개와 공개 URL 2개에서 수집한다. 가격·모델·쿼터 수집을 병렬로 수행하고 지역별 모델 목록은 중복을 제거한다. 이후 보강 단계는 저장된 원자료를 사용해 같은 API를 다시 호출하지 않는다.

최종 결과는 bedrock\_models.json과 bedrock\_pricing.json으로 합쳐 S3에 저장하고 CloudFront로 제공한다. 공개 전 데이터 누락을 검사하며, 자동 수정은 안전 기준을 만족한 것만 버전과 복구본을 남겨 적용하고 나머지는 수동 검토로 넘긴다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-model-selection-in-amazon-bedrock-with-the-open-source-model-profiler/>)

### 로컬 실행과 서버리스 배포

로컬 모드는 기존 AWS 자격 증명과 Bedrock·Pricing API 읽기 권한으로 수집기와 화면을 실행하며 별도 클라우드 인프라를 배포하지 않는다. 원문에 명시된 개발 도구 조건은 Python 3.11 이상과 Node.js 18 이상이다.

AWS 배포 모드는 서버리스 구성으로 매일 UTC 오전 6시에 데이터를 갱신하고 호스팅된 화면을 제공한다. 로컬 수집기는 Lambda 코드와 같은 변환 함수를 가져와 동일한 출력 형식을 유지한다.

프로젝트는 MIT No Attribution(MIT-0) 라이선스로 공개됐다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-model-selection-in-amazon-bedrock-with-the-open-source-model-profiler/>)
