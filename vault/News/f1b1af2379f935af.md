# NVIDIA, Claude Science의 BioNeMo 연구 도구 연동과 공개 베타 소개


NVIDIA는 2026년 7월 1일(한국시간) Anthropic의 과학 연구 워크벤치 Claude Science에 BioNeMo Agent Toolkit을 연결했다고 밝혔다. 회사는 연구자가 Claude Science의 공개 베타에서 BioNeMo 기반 연구 작업에 접근할 수 있다고 설명했다. [원문 1](<https://blogs.nvidia.com/blog/claude-science-bionemo-agent-toolkit/>)

### 연구 요청을 계산 도구에 연결

NVIDIA의 설명에 따르면 연구자가 유전체 서열 분석, 단백질 구조 예측이나 결합 후보 설계 같은 작업을 자연어로 요청하면, Claude Science가 미리 구성된 분야별 에이전트로 작업을 조정한다. BioNeMo Agent Toolkit은 Evo 2·Boltz-2·OpenFold3 같은 가속 모델을 연결한다.

툴킷은 가속 기능을 호출 가능한 스킬로 묶는다. 스킬마다 목적과 필요한 입력을 제공해 도구 선택·입력 준비·실행을 돕고, 연구자는 반환된 결과를 확인한 뒤 질문을 수정하거나 다음 단계를 결정한다. [원문 1](<https://blogs.nvidia.com/blog/claude-science-bionemo-agent-toolkit/>)

### 추론 API와 이용 경로

BioNeMo NIM은 가속 소프트웨어 스택을 컨테이너 기반 추론 마이크로서비스로 묶고, 에이전트가 호출할 수 있는 API를 제공한다.

NVIDIA는 툴킷과 스킬을 개발자 리소스와 GitHub에서 제공하며, 특정 에이전트 프레임워크에 종속되지 않는다고 설명했다. Anthropic은 공개 베타를 통해 추가 분야 전문가와 도구 연동에 대한 연구자의 의견을 받고 있다. [원문 1](<https://blogs.nvidia.com/blog/claude-science-bionemo-agent-toolkit/>)
