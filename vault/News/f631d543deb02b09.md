# GitHub Enterprise, 토큰·SSH 키 목록을 CSV와 API로 제공


GitHub는 9월 21일 Enterprise Cloud에서 기업 자격증명 목록을 내보내는 기능을 공개했다. 기업 소유자 또는 자격증명 열람 권한을 가진 구성원은 설정 화면이나 페이지 단위 REST API로 목록을 가져올 수 있다. CSV는 사용자·앱·자격증명 유형·조직별로 필터링할 수 있다. [원문 1](<https://github.blog/changelog/2026-09-21-github-enterprise-adds-credential-inventory-exports/>)

### 자격증명 메타데이터와 감사 로그 대조

목록은 SSH 키와 개인 접근 토큰, OAuth 앱 토큰, GitHub App의 사용자·설치 토큰을 포함한다. 소유자·권한과 생성·만료·최근 사용 시점, 대상 조직·저장소 메타데이터를 감사 로그 활동과 대조할 수 있다.

Enterprise Server 지원은 향후 릴리스에서 제공할 예정이다. [원문 1](<https://github.blog/changelog/2026-09-21-github-enterprise-adds-credential-inventory-exports/>)
