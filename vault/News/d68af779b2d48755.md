# Microsoft, Talos 유전체 재분석 결과 소개…4,735명에서 추가 진단 확인


Microsoft Research는 2026년 6월 24일(한국시간), 희귀질환의 기존 유전체 데이터를 반복 재분석하는 오픈소스 도구 Talos의 연구 결과를 소개했다. 새로운 유전자·질병 관계나 변이 판정 근거를 반영해 후보를 추리고, 반복 실행에서는 지난 분석 이후 근거가 바뀐 변이만 전문가 검토에 올리는 구조다. [원문 1](<https://www.microsoft.com/en-us/research/blog/talos-scaling-rare-disease-diagnosis-with-automated-iterative-genomic-reanalysis/>)

### 새 근거와 환자 조건의 결합

PanelApp Australia에서 유전자·질병 관계와 유전 방식을, ClinVar에서 변이의 병원성 정보를 읽는다. 가족 구조와 이용 가능한 환자 표현형으로 후보를 추가로 좁힌다. [원문 1](<https://www.microsoft.com/en-us/research/blog/talos-scaling-rare-disease-diagnosis-with-automated-iterative-genomic-reanalysis/>)

### 검증 집단과 실제 재분석 집단

ACG·RGP 검증 집단은 합계 1,089명의 발단자를 포함한다. ACG 부모·자녀 조합에서 분석 범위 안의 기존 진단 90%를 회수했고, RGP 조합에서는 54건 중 47건을 회수했다고 연구진은 밝혔다.

별도의 미진단 4,735명 재분석 집단에서 238명에게 241개의 새로운 진단이 나왔고 추가 진단 수율은 5.1%였다. 원인일 가능성이 있는 변이는 이후 인증 검사실에서 병원성 또는 병원성 가능 변이로 확인됐다. [원문 1](<https://www.microsoft.com/en-us/research/blog/talos-scaling-rare-disease-diagnosis-with-automated-iterative-genomic-reanalysis/>)

### 월별 반복 실행

29회의 월별 재분석에서는 새로 검토할 변이가 평균적으로 환자 200명당 1개였다고 보고했다. 공개 데이터베이스의 새 근거부터 진단까지 걸린 시간은 평균 32일이었다. [원문 1](<https://www.microsoft.com/en-us/research/blog/talos-scaling-rare-disease-diagnosis-with-automated-iterative-genomic-reanalysis/>)
