# RL 학습 모델과 기준 모델의 확률비로 에이전트 진행을 평가하는 연구


연구진은 2026년 6월 24일 arXiv에 에이전트의 단계별 진행을 평가하는 progress advantage 연구를 사전공개했다. 강화학습으로 사후 학습한 정책과 기준 정책의 로그 확률비를 이용해, 별도 보상 모델 학습 없이 단계별 평가 신호를 얻는 방법을 제시했다. [원문 1](<https://arxiv.org/abs/2606.26080v1>)

### 방법과 비교 대상

저자들은 확률적 마르코프 의사결정 과정에서 최적 어드밴티지와 연결되는 신호를 유도했다. 실행 중 추가 계산, 불확실성 정량화, 실패 원인 배정의 세 응용을 시험했다.

초록은 5개 벤치마크와 4개 모델 계열에서 신뢰도 기반 비교 방법 및 별도로 학습한 보상 모델보다 나은 결과를 보고한다. 작업별 추가 보상 모델 학습이 필요 없는 신호라는 점을 강조했다. [원문 1](<https://arxiv.org/abs/2606.26080v1>)
