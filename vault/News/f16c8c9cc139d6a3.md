# PHP2Shell 두 취약점, 인증 없는 원격 코드 실행 가능…CVSS v4.0 9.2


AhnLab ASEC가 2026년 10월 22일 공개한 보안 글은 하루 전 공개된 CVE-2026-109618과 CVE-2026-109619가 PHP 내부 요청 처리 과정에서 발생하며, 인증되지 않은 원격 코드 실행을 허용할 수 있다고 설명했다. PHP 공식 공지에 따르면 CVE-2026-109618은 메모리 부족 처리 중 일부만 초기화된 요청 데이터를 정리할 때, CVE-2026-109619는 메모리 해제 뒤에도 남은 요청 소유 내부 상태를 같은 워커의 후속 요청이 사용할 때 발생할 수 있다. 공식 공지는 두 취약점 모두 인증 없는 원격 코드 실행을 허용할 수 있으며 각각 CVSS v4.0 점수는 9.2이고, 위험도는 mod\_php 환경에서 가장 높다고 밝혔다. 일부 GitHub 저장소는 session.upload\_progress를 공격 경로로 설명하고 PHP 5.4부터 기본 활성화됐다고 적었지만, AhnLab ASEC는 이 내용이 저장소 설명에 근거하며 PHP 공식 공지에서는 확인되지 않았다고 구분했다.
