# AWS, Bedrock 모델 구독을 여러 계정에 배포하는 절차 설명


AWS는 2026년 7월 1일(한국시간) Bedrock의 managed entitlements를 이용해 중앙 계정의 모델 구독을 조직 내 여러 계정에 배포하는 지침을 공개했다. 대상은 Claude·Cohere 같은 AWS Marketplace의 외부 모델이며, Amazon 모델과 Amazon이 판매하는 모델은 Bedrock 권한으로 접근하는 방식이 적용된다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-multi-account-access-to-amazon-bedrock-models-with-managed-entitlements/>)

### 구독·배포·활성화

절차는 관리 계정에서 모델 구독, 자동 생성된 라이선스 확인, 구성원 계정에 대한 grant 생성, 구성원 계정의 활성화 순서다. AWS Organizations의 모든 기능 활성화와 관리 계정의 Marketplace·License Manager 권한, 두 서비스의 서비스 연결 역할이 필요하다.

조직의 모든 기능을 활성화하면 grant는 자동 수락되지만 Disabled 상태로 남는다. 구성원 계정의 관리자가 직접 활성화해야 한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-multi-account-access-to-amazon-bedrock-models-with-managed-entitlements/>)

### 청구 계정과 관리 리전

모델 사용료는 구독을 보유한 관리 계정에 청구된다. 라이선스와 grant의 생성·활성화는 License Manager의 us-east-1 엔드포인트에서 수행하며, 모델 호출은 지원되는 다른 리전에서도 할 수 있다.

구성원 계정은 private offer 구독이나 활성화한 grant 없이도 모델을 호출할 수 있으나, 이 경우 공개 요금이 청구된다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-multi-account-access-to-amazon-bedrock-models-with-managed-entitlements/>)

### 기존 구독과 해지 처리

이미 같은 모델의 구독 권한을 가진 구성원 계정에 결제 계정이 새 구독을 배포하면, 기존 구독의 entitlement는 비활성화되고 배포된 grant의 권한을 사용한다.

구독을 취소해도 grant는 자동 삭제되지 않는다. private pricing 적용을 철회하려면 grant를 따로 삭제해야 한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/simplify-multi-account-access-to-amazon-bedrock-models-with-managed-entitlements/>)
