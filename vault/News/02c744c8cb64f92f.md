# MIT 연구진, AI 3D 설계의 일부를 고쳐 출력하는 InstructMesh 개발


MIT는 10월 1일 CSAIL·Google·Northeastern University 연구진이 AI로 생성한 3D 설계의 특정 부분을 선택해 수정하고 출력할 수 있는 InstructMesh를 개발했다고 발표했다. 이 도구는 텍스트·이미지에서 3D 모델을 만드는 Microsoft TRELLIS와 언어 모델 GPT-4를 결합한다. 사용자는 자연어로 문제를 설명한 뒤 기하 형상의 수정 결과를 평가·승인하고, 슬라이더로 특정 부분의 확대나 돌출 정도를 조절할 수 있다. [원문 1](<https://news.mit.edu/2026/instructmesh-tool-lets-users-repair-ai-3d-models-then-fabricate-them-1001>)

### 생성 모델의 결함을 초보 사용자가 수정

MIT 발표에 따르면 연구진은 TRELLIS로 Thingiverse의 인기 3D 모델을 재생성했다. 생성 모델 중 거의 80%에서 구조 결함이 발견됐으며, 초보 사용자는 InstructMesh로 문제를 식별하고 수정하는 데 약 90%의 성공률을 보였다. 결과는 전문가가 검토했다. [원문 1](<https://news.mit.edu/2026/instructmesh-tool-lets-users-repair-ai-3d-models-then-fabricate-them-1001>)

### 후속 개발 방향

연구진은 설계가 사용 조건에 어떻게 반응하는지와 재료를 살펴보는 물리 시뮬레이션, 더 작은 특징을 다듬기 위한 TRELLIS.2 통합을 후속 개발 방향으로 제시했다. [원문 1](<https://news.mit.edu/2026/instructmesh-tool-lets-users-repair-ai-3d-models-then-fabricate-them-1001>)
