# AWS Transit Gateway·Cloud WAN, attachment에 관리형 1:1 NAT 추가


AWS는 2026년 10월 23일 AWS Transit Gateway와 AWS Cloud WAN attachment에서 Regional Private NAT Gateway 통합을 통한 관리형 1:1 NAT를 제공한다고 발표했다. 이 기능으로 고객은 IP 주소 대역이 겹치는 사설 네트워크를 주소 변경이나 NAT 장비 배포, 반환 트래픽 규칙 작성 없이 연결할 수 있다. AWS는 두 서비스가 운영되는 모든 상용 리전에서 이 기능을 제공한다고 밝혔다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/>)

### 양방향 변환과 관리 범위

고객은 Transit Gateway 또는 Cloud WAN attachment에서 각 source CIDR이 변환될 private IP 범위를 지정한다. 지원 연결에는 Amazon VPC, AWS Site-to-Site VPN, AWS Direct Connect, Transit Gateway Connect를 통해 연결된 SD-WAN 장비가 포함된다. 두 서비스가 변환을 양방향으로 자동 적용하며, AWS는 attachment의 NAT 기능을 운영·확장·관리한다.

설정은 AWS Management Console, AWS CLI, AWS SDKs, AWS CloudFormation으로 할 수 있으며, 변환된 트래픽은 Amazon CloudWatch 지표와 Amazon EventBridge 이벤트로 모니터링할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-transit-gateway-cloud-wan-1-1-nat/>)
