# Amazon EC2 R8gd, 독일 AWS 유럽 소버린 클라우드 리전에 출시


AWS는 2026년 10월 9일 Amazon EC2 R8gd 인스턴스를 AWS European Sovereign Cloud (Germany) 리전에서 사용할 수 있다고 발표했다. R8gd는 AWS Graviton4 프로세서를 탑재하고 최대 11.4 TB의 로컬 NVMe 기반 SSD 블록 스토리지를 제공하며, AWS는 Graviton3 기반 인스턴스보다 성능이 최대 30% 높다고 밝혔다. 인스턴스는 12가지 크기로 제공되며 네트워크 대역폭은 최대 50 Gbps, Amazon EBS 대역폭은 최대 40 Gbps다. 고객은 EC2 instance bandwidth weighting 설정으로 R8gd의 네트워크 및 Amazon EBS 대역폭을 25% 조정할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-ec2-r8gd-thf/>)

### 크기별 대역폭 조정과 EFA 지원

Elastic Fabric Adapter 네트워킹은 24xlarge, 48xlarge, metal-24xl, metal-48xl 크기에서 제공된다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-ec2-r8gd-thf/>)
