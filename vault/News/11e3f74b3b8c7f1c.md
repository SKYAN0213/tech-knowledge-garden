# AWS Security Hub, findings를 S3에 CSV·JSON으로 내보내기 지원


AWS Security Hub는 2026년 10월 9일, findings를 Amazon S3로 CSV 또는 JSON(OCSF) 형식으로 내보내는 기능을 발표했다. 사용자는 Threats, Exposure, Vulnerabilities, Posture Management, Sensitive Data, All Findings를 포함한 콘솔의 각 findings 페이지에서 내보내기를 시작할 수 있으며, 결과는 사용자 계정의 S3 버킷으로 전달된다. CSV는 스프레드시트에서 검토·공유할 때, JSON은 Open Cybersecurity Schema Framework(OCSF) 형식이 필요할 때 선택할 수 있다. 이 기능은 AWS Security Hub를 사용할 수 있는 모든 AWS 리전에서 이용 가능하다.
