# Google, Nano Banana 2 Lite 출시·Omni Flash 개발자 공개


Google은 2026년 7월 1일(한국시간) 이미지 생성 모델 Nano Banana 2 Lite를 출시하고, 기존 Gemini Omni Flash의 영상 생성·편집 기능을 개발자에게 공개했다. 두 모델은 Google AI Studio·Gemini API·Gemini Enterprise Agent Platform에서 제공하며, Omni Flash는 Google AI Studio와 Gemini API에서 공개 프리뷰로 이용할 수 있다. [원문 1](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/>)

### 이미지 생성 시간과 가격

Google이 제시한 Nano Banana 2 Lite의 텍스트-이미지 생성 시간은 4초, 가격은 1K 해상도 이미지당 0.034달러다. [원문 1](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/>)

### 영상 출력과 API 지원 범위

Gemini Omni Flash는 자연어로 영상을 생성·수정하는 모델로, 영상 출력 1초당 0.10달러다. 공개 당시에는 10초 길이의 영상 생성을 제공하며, Gemini API에서 오디오 참조 업로드와 장면 확장은 지원하지 않는다.

3초 이하의 영상 참조는 API 스키마가 허용하지만 당시 모델은 이를 올바르게 처리하지 못한다. Google은 장면 변경과 카메라 패닝에서 인물 일관성에도 제한이 있다고 밝혔다. [원문 1](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/>)

### 이미지를 영상으로 이어 만드는 방식

Nano Banana 2 Lite가 만든 이미지를 Omni Flash의 참조로 넘겨 영상으로 만들 수 있다. 여러 차례 수정하는 작업에서는 Interactions API로 세션 이력과 문맥을 유지한다. [원문 1](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/>)

### 생성 콘텐츠의 워터마크

두 모델은 SynthID 워터마킹을 사용한다. Google은 Gemini 앱·Chrome의 Gemini·Search에서 생성 콘텐츠 확인 기능을 제공한다고 설명했다. [원문 1](<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/>)
