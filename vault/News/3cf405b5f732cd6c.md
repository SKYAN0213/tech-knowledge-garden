# AWS Glue Data Catalog, 캘리포니아 북부 리전서 Iceberg 테이블 자동 최적화 지원


AWS Glue Data Catalog는 2026년 10월 30일 Apache Iceberg 테이블 자동 최적화를 US West 리전(캘리포니아 북부)에서 지원한다고 밝혔다. 사용자는 Data Catalog의 개별 테이블이나 전체 테이블에 최적화를 활성화할 수 있다. 최적화는 테이블을 지속적으로 모니터링해 백그라운드에서 작은 파일을 압축하고, 보존 설정 기간이 지난 스냅샷과 더 이상 참조되지 않는 파일을 삭제한다. 사용자는 AWS Glue 콘솔, Amazon CloudWatch 지표와 로그에서 각 최적화 실행을 모니터링할 수 있다.
