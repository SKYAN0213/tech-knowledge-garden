# GitHub, OpenSSF 악성 패키지 정보를 Dependabot 경보에 자동 반영


GitHub는 7월 28일 OpenSSF malicious-packages 저장소의 악성 패키지 보고를 Advisory Database에 자동 반영하기 시작했다고 발표했다. npm과 PyPI 등을 포함해 경보 범위가 넓어졌으며, Malware alerts를 켠 저장소의 의존성이 등록된 악성 패키지 정보와 일치하면 Dependabot 경보를 받는다. [원문 1](<https://github.blog/changelog/2026-07-28-dependabot-alerts-on-malicious-packages-across-more-ecosystems/>)

### 기능을 켜면 새 보고가 자동 반영

이미 Malware alerts를 사용 중이면 추가 설정 없이 확대된 데이터를 적용받으며, 새 보고가 게시될 때 경보가 생성된다. 처음 사용하는 경우 저장소나 조직의 Settings → Advanced security → Dependabot에서 Malware alerts를 켠다. [원문 1](<https://github.blog/changelog/2026-07-28-dependabot-alerts-on-malicious-packages-across-more-ecosystems/>)

### 악성 패키지 보고 조회

Advisory Database에서는 type:malware 필터로 악성 패키지 보고를 확인할 수 있다. [원문 1](<https://github.blog/changelog/2026-07-28-dependabot-alerts-on-malicious-packages-across-more-ecosystems/>)
