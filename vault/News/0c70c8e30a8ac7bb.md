# GitHub Copilot 코드 리뷰, 조직별 분석 깊이 설정과 파일 탐색 도구 변경


GitHub는 2026년 6월 26일(한국시간), Copilot 코드 리뷰의 파일 탐색 도구와 Medium 분석 깊이 공개 미리보기 설정을 갱신했다. 조직 기본 분석 수준을 지정하고, 풀 리퀘스트의 개요 댓글에서 Medium 수준으로 실행됐는지 확인할 수 있다. [원문 1](<https://github.blog/changelog/2026-06-25-copilot-code-review-analysis-depth-and-efficiency-updates>)

### 조직 기본값과 저장소 설정

Medium 공개 미리보기에 참여한 조직은 아직 수준을 설정하지 않은 저장소에 적용할 기본 리뷰 수준을 지정할 수 있다. 저장소는 조직 기본값을 별도로 덮어쓸 수 있다. [원문 1](<https://github.blog/changelog/2026-06-25-copilot-code-review-analysis-depth-and-efficiency-updates>)

### 탐색 방식과 회사의 비용 평가

리뷰 경로의 파일 탐색에는 Copilot CLI·SDK의 grep·rg·glob·view가 쓰인다. GitHub는 기존 맞춤형 탐색 도구를 대체하고 내부 지침도 조정했다고 설명했다.

GitHub는 오프라인·온라인 평가에서 같은 리뷰 품질 기준을 유지하면서 코드 리뷰 비용이 약 20% 줄었다고 밝혔다. 이 수치는 회사가 평가한 리뷰 비용이며 이용자의 요금 인하 발표는 아니다. [원문 1](<https://github.blog/changelog/2026-06-25-copilot-code-review-analysis-depth-and-efficiency-updates>)
