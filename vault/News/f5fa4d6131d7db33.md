# GitHub Actions, 의존성 커밋을 잠그는 파일 공개 미리보기


GitHub가 한국시간 10월 14일 무료 요금제를 포함한 GitHub Actions 워크플로 의존성 잠금 파일을 공개 미리보기로 제공했다. 사용자가 태그나 브랜치를 워크플로에 유지해도, 잠금 적용 이후에는 actions.lock에 기록한 액션·하위 의존성·재사용 워크플로의 정확한 커밋을 실행한다. [원문 1](<https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview>)

### 버전 업데이트와 잠금 파일을 함께 관리

gh actions-lock 확장으로 잠금 파일을 관리하고 관리자는 사용을 정책으로 요구할 수 있다. Dependabot의 버전 업데이트 PR은 해당 잠금 항목도 함께 갱신하며, 의존성 자체의 안전성 검토는 잠금과 별도로 필요하다. [원문 1](<https://github.blog/changelog/2026-10-14-github-actions-workflow-lockfiles-in-public-preview>)
