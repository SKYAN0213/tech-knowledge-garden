# Dream Labs, 9000만 달러 시드 투자 유치와 Dream API 공개


2026년 10월 22일(한국시간) 보도에 따르면 Dream Labs는 시드 투자 9000만 달러를 유치하고, 로봇 카메라 영상과 영어 자연어 지시를 모터 명령으로 바꾸는 Dream API를 출시했다고 밝혔다. 회사는 Dream-1이 일상 작업을 수행하는 사람들의 영상으로 학습해 다음 상황과 로봇 동작을 예측하며, 제조사가 다른 로봇에서도 작동한다고 설명했다. Dream Labs에 따르면 Dream-1은 평행 그리퍼가 달린 양팔 로봇을 추가 데이터 없이 제어할 수 있고, 현재 물체 집기·놓기와 빨래 개기 같은 탁상 작업을 처리하며 바퀴형 이동 로봇과 손재주 로봇 지원은 계획 중이다. [원문 1](<https://www.therobotreport.com/dream-labs-raises-90m-and-launches-dream-api/>)

### 사용 조건과 추가 작업 지원

보도 시점인 10월 22일부터 개발자와 로봇 애호가가 회사의 AI 제품을 사용할 수 있다고 보고서는 전했다. Dream Labs는 등록 사용자가 그리퍼 장착 로봇을 연결해 Dream API를 이용할 수 있고, 현재 지원하는 로봇의 가격은 약 2,000\~10,000달러라고 설명했다.

Dream Labs는 20곳이 넘는 하드웨어 파트너와 협력하며 로봇별로 모델을 조정한다고 밝혔다. 지원되지 않는 하드웨어나 새로운 기능에는 소량의 시연 데이터를 제출하면 몇 시간 안에 맞춤 모델을 제공하는 미세 조정 서비스를 운영한다. [원문 1](<https://www.therobotreport.com/dream-labs-raises-90m-and-launches-dream-api/>)

### 투자 참여사와 자금 사용 계획

이번 투자 라운드는 B Capital과 Kindred Ventures가 주도했으며 A.Capital, Unusual Ventures, SV Angel, Wing VC, Scribble VC 등이 참여했다. Dream Labs는 투자금을 주로 컴퓨팅에 투입해 Dream-1의 지원 작업과 로봇 범위를 넓히고 더 많은 사용자를 지원할 계획이라고 밝혔다. [원문 1](<https://www.therobotreport.com/dream-labs-raises-90m-and-launches-dream-api/>)
