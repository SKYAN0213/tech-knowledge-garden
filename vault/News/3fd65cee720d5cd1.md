# Citrix, NetScaler ADC·Gateway 취약점 보안 업데이트 발표


Citrix는 2026년 9월 29일 자사 제품의 취약점을 해결하는 보안 업데이트를 발표했다. 영향받는 버전을 사용하는 사람은 해결 방안에 따라 최신 버전으로 업데이트하라는 권고를 받았다. NetScaler ADC와 NetScaler Gateway에서 입력값 검증 취약점(CVE-2026-88771), HTTP Request/Response Smuggling 취약점(CVE-2026-88773), Improper Restriction of Operations within the Bounds of a Memory Buffer 취약점(CVE-2026-88772)이 확인됐다고 KISA가 설명했다. 두 제품에서는 보안 설정 미흡(CVE-2026-88774)과 Classic Buffer Overflow(CVE-2026-88775) 취약점도 확인됐다.
