# Claude Code v2.1.196, 조직 모델 설정·MCP 승인·백그라운드 복구 개선


Claude Code는 2026년 6월 30일(한국시간) v2.1.196 릴리스에서 조직 관리자의 기본 모델 설정을 지원했다. MCP 서버 승인 경계를 수정하고, 프로세스가 중지·재시작·업데이트돼도 긴 백그라운드 작업을 유지하도록 개선했다. [원문 1](<https://api.github.com/repos/anthropics/claude-code/releases/tags/v2.1.196>)

### 조직 설정과 파일 접근

관리자가 조직 콘솔에서 기본 모델을 정하면, 사용자가 직접 모델을 선택하지 않은 경우 /model에 Org default 또는 Role default로 표시된다. 세션을 시작할 때 읽기 쉬운 기본 이름을 붙이고, 채팅에 첨부한 파일은 Cmd/Ctrl 키와 함께 클릭해 Finder나 Explorer에서 찾을 수 있다. [원문 1](<https://api.github.com/repos/anthropics/claude-code/releases/tags/v2.1.196>)

### MCP 서버와 인증 범위

claude mcp list/get은 저장소에 커밋된 .claude/settings.json의 자체 승인만으로 .mcp.json 서버를 실행하지 않는다. 신뢰하지 않는 작업 공간에는 Pending approval을 표시한다.

MCP OAuth에서 scope를 지정하지 않았을 때 인증 서버의 scopes\_supported 전체 목록을 요청해 GitLab 자체 호스팅과 기업 인증 제공자에서 invalid\_scope 오류가 발생하던 동작도 수정했다. [원문 1](<https://api.github.com/repos/anthropics/claude-code/releases/tags/v2.1.196>)

### 백그라운드 작업과 원격 세션 복구

백그라운드 작업을 깨울 때 실제 대화 기록을 잘못 읽어 파일을 영구 삭제하고 원래 프롬프트를 다시 실행하던 오류를 수정했다. 이제 해당 파일은 삭제하지 않고 별도로 둔다.

긴 명령과 작업 흐름은 세션 프로세스를 중지·재시작·업데이트해도 유지한다. Windows에서는 백그라운드 셸을 종료하는 대신 인계한다. daemon 재시작으로 종료된 에이전트 worker는 다음 agents 화면 열기 때 중단 지점부터 이어서 실행한다.

서버 재시작으로 실행 중 끊긴 Remote 세션은 다음 worker에서 자동으로 재개하도록 수정했다. [원문 1](<https://api.github.com/repos/anthropics/claude-code/releases/tags/v2.1.196>)

### 검토 비용과 운영 동작

릴리스 설명에 따르면 /code-review는 코드 정리 항목을 찾는 모듈 5개를 하나로 통합해 토큰 사용량을 약 25% 줄였다. 병렬 요청 중 사용량 한도에 도달하면 경고가 깜박이고 집계가 중복되던 오류도 수정했다. /deep-research의 검증기 오류는 모든 주장이 반박됐다는 결과로 표시하지 않고 미검증으로 구분한다.

모든 제공자에서 스트리밍 유휴 감시 기능을 기본으로 켰다. 응답 스트림에 5분 동안 이벤트가 없으면 중단 후 재시도하며, CLAUDE\_ENABLE\_STREAM\_WATCHDOG=0으로 끌 수 있다. ANTHROPIC\_BASE\_URL이 Anthropic 이외의 호스트를 가리키면 Remote Control은 비활성화한다. [원문 1](<https://api.github.com/repos/anthropics/claude-code/releases/tags/v2.1.196>)
