# Cisco Catalyst SD-WAN Manager API 인증 우회 취약점 공개


Cisco는 9월 30일 Catalyst SD-WAN Manager API 인증 우회 취약점 CVE-2026-76504를 공개했다. 영향받는 시스템에서는 인증되지 않은 원격 공격자가 관리자 권한으로 API에 접근할 수 있으며, Cisco PSIRT는 9월 실제 악용을 인지했다고 밝혔다. 회사는 수정된 소프트웨어로 업그레이드할 것을 권고했다. [원문 1](<https://www.cisco.com/c/en/us/support/docs/csa/cisco-sa-sdwan-webauth-xr8beuuU.html>)

### 수정 버전과 임시 부분 보호

취약·수정 소프트웨어 판본은 Cisco의 수정 버전 표에서 구분한다. 10월 2일 개정판에 추가된 Live Protect shield는 업그레이드 준비 시간을 위한 임시 부분 보호로 소개됐으며, 취약점을 해결하는 조치는 수정 버전 업그레이드다. [원문 1](<https://www.cisco.com/c/en/us/support/docs/csa/cisco-sa-sdwan-webauth-xr8beuuU.html>)

### 관리형 클라우드와 온프레미스 대응

Cisco 관리형 SD-WAN Cloud에는 수정 릴리스의 조치가 반영돼 사용자 추가 조치가 필요 없다고 회사는 설명했다. 온프레미스 환경에서 신뢰할 수 없는 네트워크의 접근을 제한하는 것은 완화 조치이며 소프트웨어 수정을 대체하지 않는다. [원문 1](<https://www.cisco.com/c/en/us/support/docs/csa/cisco-sa-sdwan-webauth-xr8beuuU.html>)
