# GitHub Desktop 3.6, 워크트리·Copilot 병합 충돌 해결 지원


GitHub는 2026년 6월 26일(한국시간) Desktop 3.6의 Git 워크트리 지원과 Copilot 기반 커밋·병합 기능을 발표했다. Copilot 기능은 공통 SDK로 동작하며, 모델 선택기와 외부 제공사·로컬 모델 연결을 지원한다. [원문 1](<https://github.blog/changelog/2026-06-26-github-desktop-3-6-worktrees-and-deeper-copilot-integration>)

### 여러 브랜치에서 작업하기

Git 워크트리 지원으로 변경사항을 반복적으로 임시 저장하거나 브랜치를 전환하지 않고 여러 브랜치에서 작업할 수 있다. [원문 1](<https://github.blog/changelog/2026-06-26-github-desktop-3-6-worktrees-and-deeper-copilot-integration>)

### 커밋 메시지와 병합 충돌

커밋 메시지 생성은 .github/copilot-instructions.md와 AGENTS.md의 지침, 저장소의 커밋 메타데이터 규칙을 반영한다.

Copilot이 병합 충돌을 설명하고 해결안을 제안하면, 사용자가 검토·수정한 뒤 병합을 완료한다. [원문 1](<https://github.blog/changelog/2026-06-26-github-desktop-3-6-worktrees-and-deeper-copilot-integration>)

### 모델 선택과 이용 조건

각 Copilot 기능에서 GitHub를 통해 이용 가능한 모델을 선택할 수 있다. BYOK로 외부 제공사나 로컬 모델을 연결하는 방식도 제공한다.

Desktop 3.6.0은 macOS·Windows에서 무료로 내려받아 사용할 수 있으며, Copilot 기능에는 GitHub Copilot 접근 권한이 필요하다. [원문 1](<https://github.blog/changelog/2026-06-26-github-desktop-3-6-worktrees-and-deeper-copilot-integration>)
