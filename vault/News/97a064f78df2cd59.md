# RAG 개인정보 보호 연구, 검색 문서를 세 에이전트로 오프라인 재작성


연구진은 2026년 6월 23일 arXiv에, 검색 결과 문서의 민감 식별자를 제거하고 의미를 유지하는 RAG 개인정보 보호 방법을 사전공개했다. v1 초록은 개인정보 추출·의미 분석·재구성 담당 에이전트를 결합해, 온라인 추론 전에 문서를 한 번 재작성하는 구성을 제안한다. [원문 1](<https://arxiv.org/abs/2606.24623v1>)

### 데이터셋과 표적 공격 결과

ChatDoctor·Wiki-PII와 여섯 언어 모델에서 평가했으며, LLaMA-3-8B의 표적 정보 노출은 기준 방법의 144건에서 1건으로 줄었다고 초록은 보고했다. [원문 1](<https://arxiv.org/abs/2606.24623v1>)

### 문맥 보존과 사전 처리

문맥 보존을 평가하는 BLEU-1은 제안 방법이 0.122, 비교 방법 SAGE가 0.117이었다. 재작성은 일회성 오프라인 전처리로 수행하므로 온라인 추론 단계에 추가 지연을 넣지 않는 구성이라고 연구진은 설명했다. [원문 1](<https://arxiv.org/abs/2606.24623v1>)
