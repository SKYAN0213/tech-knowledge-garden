# Meta Muse Spark Open, AWS JumpStart에 추가…활성 파라미터 420억 개


AWS가 10월 15일 SageMaker JumpStart에 Meta의 개방형 가중치 코딩 모델 Muse Spark Open을 추가했다. MoE 구조로 전체 파라미터는 8,160억 개, 토큰당 활성 파라미터는 420억 개이며, 100만 토큰 문맥과 여러 단계의 도구 호출을 지원한다고 AWS는 설명했다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/01/muse-spark-open-on-sagemaker-jumpstart/>)

### 계정 내부에 배포하는 두 판본

JumpStart는 BF16과 NVFP4 양자화 판본을 제공하며, AWS는 NVFP4가 BF16의 약 4분의 1 메모리를 필요로 한다고 설명한다. 배포 엔드포인트는 고객의 AWS 계정에서 실행되고 텍스트·이미지·문서·음성·영상을 입력받아 텍스트를 출력한다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/01/muse-spark-open-on-sagemaker-jumpstart/>)
