# LineShine, TOP500 1위…CPU로 HPL 2.198 엑사플롭/초


The Verge는 2026년 6월 29일(한국시간) 중국 선전의 LineShine이 TOP500 1위에 올랐다고 보도했다. TOP500의 6월 23일 공식 발표에서 CPU 기반 시스템의 HPL 측정 성능은 2.198 엑사플롭/초였다. [원문 1](<https://www.theverge.com/tech/958768/china-claims-the-worlds-fastest-supercomputer>) [원문 2](<https://top500.org/news/lineshine-debuts-no-1-top500-enters-new-global-exascale-era/>) [원문 3](<https://top500.org/lists/top500/2026/06/>) [원문 4](<https://www.netlib.org/benchmark/hpl/>)

### CPU·연결망과 전력

공식 목록은 304코어 LX2 프로세서, LingQi 연결망, Kylin 운영체제와 총 13,789,440개 코어를 명시한다. GPU 가속기 없이 CPU로 구성한 시스템이다.

TOP500은 소비전력을 약 42.2메가와트, 에너지 효율을 와트당 52.07기가플롭으로 발표했다. 이론상 최대 성능 2.736 엑사플롭/초와 HPL 측정 성능은 서로 다른 값이다. [원문 2](<https://top500.org/news/lineshine-debuts-no-1-top500-enters-new-global-exascale-era/>) [원문 3](<https://top500.org/lists/top500/2026/06/>)

### HPL이 측정하는 계산

HPL은 분산 메모리 컴퓨터에서 64비트 배정밀도 연산으로 밀집 선형 연립방정식을 풀고, 결과의 정확도와 계산 시간을 측정하는 벤치마크다.

HPL의 공식 목록에서는 LineShine이 2.198 엑사플롭/초, 2위 El Capitan이 1.809 엑사플롭/초다. [원문 4](<https://www.netlib.org/benchmark/hpl/>) [원문 2](<https://top500.org/news/lineshine-debuts-no-1-top500-enters-new-global-exascale-era/>) [원문 3](<https://top500.org/lists/top500/2026/06/>)

### 혼합 정밀도 평가는 별도 순위

혼합 정밀도 HPL-MxP에서는 LineShine이 7.92 엑사플롭/초로 4위이며, El Capitan이 16.7 엑사플롭/초로 1위다. 계산 정밀도와 평가 과제가 다른 결과를 구분해 기록한다. [원문 2](<https://top500.org/news/lineshine-debuts-no-1-top500-enters-new-global-exascale-era/>) [원문 3](<https://top500.org/lists/top500/2026/06/>)
