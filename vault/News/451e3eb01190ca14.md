# AWS, GovCloud Bedrock에 GPT OSS·Nemotron 모델 제공


AWS는 7월 2일(한국시간) Amazon Bedrock의 AWS GovCloud(US)에서 OpenAI GPT OSS와 NVIDIA Nemotron 오픈웨이트 모델을 제공한다고 발표했다. AWS는 이 모델의 추론이 미국 시민이 미국 영토에서 운영하는 인프라를 통해 GovCloud 격리 경계 안에서 수행된다고 설명했다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/run-nvidia-nemotron-and-openai-gpt-oss-models-on-amazon-bedrock-in-aws-govcloud-us/>)

### 제공 모델과 GPT OSS 사양

제공 목록에는 OpenAI gpt-oss-120b·gpt-oss-20b와 NVIDIA Nemotron Nano 9B v2·Nano 12B v2·Nano 30B·Super 120B가 포함된다.

AWS가 소개한 GPT OSS 두 모델은 텍스트를 입력받아 텍스트를 생성하며, 128K 토큰의 컨텍스트 창과 최대 16K 토큰 출력을 지원한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/run-nvidia-nemotron-and-openai-gpt-oss-models-on-amazon-bedrock-in-aws-govcloud-us/>)

### 단일 리전과 GovCloud 내 교차 리전

AWS에 따르면 단일 리전 추론은 us-gov-west-1에서 제공된다. 지리적 교차 리전 추론은 us-gov-west-1과 us-gov-east-1 사이로 요청을 분산하며, 트래픽은 GovCloud(US) 경계 안에 유지된다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/run-nvidia-nemotron-and-openai-gpt-oss-models-on-amazon-bedrock-in-aws-govcloud-us/>)

### 호출 API와 모델별 차이

bedrock-mantle은 OpenAI 호환 API로 OpenAI Python·TypeScript SDK와 함께 사용한다. bedrock-runtime은 AWS SDK를 통해 Converse·InvokeModel API를 호출하며 Guardrails 같은 Bedrock 고유 기능을 제공한다.

GPT OSS는 Responses API를 지원한다. 반면 Nemotron 3 Super 120B는 이 API를 지원하지 않으며 Chat Completions·Converse·Invoke를 사용한다.

bedrock-mantle에서 GPT OSS는 클라이언트 측·서버 측 도구 호출을 모두 지원하고, Nemotron 3 Super 120B는 클라이언트 측 도구 호출만 지원한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/run-nvidia-nemotron-and-openai-gpt-oss-models-on-amazon-bedrock-in-aws-govcloud-us/>)

### 접근 자격과 호출 조건

bedrock-mantle을 이용하려면 Bedrock 모델 호출 권한이 있는 GovCloud(US) 계정과 Bedrock API 키 또는 일반 AWS 자격 증명이 필요하다.

AWS는 Standard 티어의 온디맨드 용량이 리전별 공유 자원이며, 보도자료의 오픈웨이트 모델에 대해 Service Quotas 콘솔에 계정별 토큰 쿼터가 게시되어 있지 않다고 설명했다.

단기 Bedrock API 키는 최대 12시간 후 자동으로 만료된다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/run-nvidia-nemotron-and-openai-gpt-oss-models-on-amazon-bedrock-in-aws-govcloud-us/>)
