# DigitalOcean, 에이전트 실행·추론·저장을 묶은 Agent Droplets 공개


DigitalOcean은 10월 1일 Managed Agents 공개 프리뷰에 Agent Droplets를 도입했다. 월간 Pro는 50달러, Team은 200달러이며 에이전트 사용료를 각각 15%와 20% 할인한다. 기존 에이전트 실행 도구를 전용 microVM에서 이용하고 유휴 상태에는 자동으로 일시정지하는 방식이다. [원문 1](<https://www.digitalocean.com/blog/introducing-agent-droplets>)

### 실행 상태와 잔액 소진 후 재개

회사 설명에 따르면 microVM은 일시정지 상태에서 약 300밀리초에 재개한다. AI 잔액이 모두 소진되면 세션은 다음 안전한 지점에서 정지하며 스냅샷에 작업 상태를 보존한다. 자금을 추가하면 그 상태에서 작업을 이어 갈 수 있다. [원문 1](<https://www.digitalocean.com/blog/introducing-agent-droplets>)

### AI 선불 잔액과 일반 클라우드 요금

Agent Droplet 이용 한도를 소진하면 에이전트가 Inference and Agents Balance를 사용한다. 이 선불 잔액은 AI 제품에만 적용되며 일반 Droplets·Spaces·Managed Databases 비용은 기존 결제 주기에 따로 청구된다. 월간 요금과 할인율만으로 전체 클라우드 비용이 고정된다고 볼 수 없다. [원문 1](<https://www.digitalocean.com/blog/introducing-agent-droplets>)
