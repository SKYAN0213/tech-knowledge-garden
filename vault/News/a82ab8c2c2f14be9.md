# DigitalOcean, 에이전트 실행·추론·저장을 묶은 Agent Droplets 공개


DigitalOcean은 10월 1일 에이전트 실행 환경·추론·저장공간·도구 사용료를 월 구독과 단일 청구서로 묶는 Agent Droplets를 공개 프리뷰로 내놨다. Pro는 월 50달러, Team은 월 200달러이며 각각 사용량 할인 15%와 20%를 적용한다고 밝혔다. 구독 허용량을 넘기면 정가 과금이 이어질 수 있어 총비용은 실제 사용량에 따라 달라진다. [원문 1](<https://www.digitalocean.com/blog/introducing-agent-droplets>)

각 세션은 전용 microVM에서 실행되고 유휴 상태가 되면 자동으로 멈췄다가 재개한다. DigitalOcean은 수초 내 시작과 약 300밀리초 재개를 제시했으나 이는 회사 수치이며 독립 비교는 없다. [원문 1](<https://www.digitalocean.com/blog/introducing-agent-droplets>)
