# AWS, GovCloud에 S3 Vectors 메타데이터 사전 필터링 제공


AWS는 2026년 10월 9일 Amazon S3 Vectors의 메타데이터 사전 필터링을 AWS GovCloud (US-East)와 AWS GovCloud (US-West)에서 제공한다고 밝혔다. 필터가 결과 범위를 좁히는 조건일 때, 메타데이터 사전 필터링으로 일치 벡터를 최대 5배 더 반환할 수 있다고 AWS는 설명했다. Amazon S3 Vectors에는 경로나 URL 같은 값으로 필터링할 수 있는 접두사 일치 연산자 `$startsWith`도 추가됐다. AWS는 10월 9일 공지 당시 배포를 진행 중이었으며, 이후 며칠 안에 완료할 계획이라고 밝혔다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/s3-vectors-metadata-pre-filtering-in-govcloud-regions/>)

### 기존 인덱스 적용 방법

AWS GovCloud (US) 리전의 새 벡터 버킷에 있는 인덱스는 메타데이터 사전 필터링을 기본으로 사용하며, 기존 인덱스는 `UpdateIndexMode` API로 제자리에서 업데이트할 수 있다.

사용자는 업데이트 전에 `QueryVectors`의 쿼리별 매개변수를 사용해 동일한 인덱스에서 사전 필터링과 현재 필터링을 비교할 수 있다.

AWS는 메타데이터 사전 필터링을 Amazon S3 Vectors가 제공되는 모든 상용 리전과 AWS 중국 리전에서 추가 비용 없이 제공한다고 밝혔다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/s3-vectors-metadata-pre-filtering-in-govcloud-regions/>)
