# OpenAI, 저장소 서비스 Rust로 재작성…발표 당시 요청 95% 처리


OpenAI는 9월 11일 온라인 저장소 서비스 Habitat의 확장 경험을 공개했다. 회사에 따르면 엔지니어 2명이 Codex와 GPT-5.5를 이용해 2026년 2분기에 서비스를 Rust로 재작성했으며, 발표 당시 운영 요청의 95%를 처리하고 있었다. OpenAI는 자사 측정에서 Python 버전 대비 CPU 효율 6배, 메모리 효율 15배를 기록했다고 밝혔다. [원문 1](<https://openai.com/index/scaling-storage-one-billion-users-part-one/>)

### 느린 요청을 추적한 배경

OpenAI는 Habitat의 Python 서비스에서 p99 이상 지연 요청의 추적 기록을 분석한 결과, 하위 저장소는 빨리 응답해도 코루틴 재스케줄링을 기다리느라 요청이 멈추는 경우가 잦았다고 설명했다.

회사 측정에서는 Rust 서비스가 Python 버전보다 평균 지연과 꼬리 지연도 낮았다고 밝혔다. [원문 1](<https://openai.com/index/scaling-storage-one-billion-users-part-one/>)
