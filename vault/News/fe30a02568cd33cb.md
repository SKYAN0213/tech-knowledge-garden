# AirJoule, Kubota와 주택용 대기 물 생산 시스템 판매 계약


AirJoule Technologies는 Kubota를 텍사스·캘리포니아 다세대 주거 개발용 시스템의 독점 판매 채널로 지정했고, Kubota가 Core 시스템 2대를 구매했다고 발표했다. 두 현장의 배치는 2026년 3분기 시작 예정이므로 계약·구매와 실제 가동은 구분해야 한다. 회사는 첫 전규모 Prime 시스템을 5월 뉴어크에서 가동했다고 보고했지만, 성능 수치는 회사 설명이며 독립 검증 데이터는 이 발표에 제시되지 않았다. [원문 1](<https://www.sec.gov/Archives/edgar/data/1855474/000119312526349663/airj-ex99_1.htm>)

### 상용화 계획과 실제 성능은 별도 확인 대상

발표문은 Prime 시스템의 유럽 출하와 쿠보타 경로의 두 Core 시스템 설치를 향후 일정으로 제시했다. 현장 가동 데이터, 연속 운전 성능, 고객 인수 결과가 다음 확인 지점이다. 회사가 제시한 물 생산량·에너지 효율 수치는 독립 검증과 동일시하지 않는다. [원문 1](<https://www.sec.gov/Archives/edgar/data/1855474/000119312526349663/airj-ex99_1.htm>)
