# Microsoft Copilot, Home·Code·Autopilot과 Office 편집 통합 발표


Microsoft는 9월 25일 Copilot에 Home·Code·Autopilot을 배치하고 Word·Excel·PowerPoint 파일을 직접 만들고 편집하는 기능을 발표했다. Home과 Code는 Frontier 프로그램에 단계적으로 제공하고, Autopilot은 월말 비공개 프리뷰로 넓힐 계획이다. Code는 자연어로 앱과 자동화를 만드는 기능으로 소개됐으며 자사 조직 환경 내 적용을 내세웠다. [원문 1](<https://news.microsoft.com/source/emea/2026/09/new-microsoft-copilot-brings-home-code-and-autopilot-together/>)

회사는 Autopilot이 사용자가 자리를 비운 동안에도 작업을 이어가는 에이전트라고 설명했다. 이는 발표된 기능 방향과 제한적 배포 일정이며, 모든 고객에게 정식 제공된 상태나 장기 자율 실행의 신뢰성 평가를 뜻하지 않는다. [원문 1](<https://news.microsoft.com/source/emea/2026/09/new-microsoft-copilot-brings-home-code-and-autopilot-together/>)
