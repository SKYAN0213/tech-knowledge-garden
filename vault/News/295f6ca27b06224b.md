# Microsoft Copilot, Home·Code·Autopilot과 Office 편집 통합 발표


Microsoft는 9월 25일 Copilot의 Home·Code·Autopilot 작업공간과 Word·Excel·PowerPoint 통합을 발표했다. Home과 Code는 Frontier 프로그램에 단계적으로 제공하고, Autopilot은 9월 말 비공개 프리뷰로 확대할 계획이다. Code는 GitHub Copilot 기술을 바탕으로 자연어로 앱과 자동화를 만드는 기능으로 소개됐다. [원문 1](<https://news.microsoft.com/source/emea/2026/09/new-microsoft-copilot-brings-home-code-and-autopilot-together/>)

### 대화·작업 위임과 Office 파일 편집

Home은 Chat과 작업 위임용 Cowork를 모으며, Autopilot은 사용자가 컴퓨터를 떠난 동안에도 작업을 이어 가도록 설계됐다고 회사는 설명했다. Word·Excel·PowerPoint 파일을 Copilot 안에서 생성·편집하고 Office 앱과 동기화하는 기능도 함께 소개했다. [원문 1](<https://news.microsoft.com/source/emea/2026/09/new-microsoft-copilot-brings-home-code-and-autopilot-together/>)
