# GitHub, Copilot에 Claude Sonnet 5 순차 제공


GitHub는 2026년 7월 1일(한국시간) Copilot에 Anthropic의 Claude Sonnet 5를 추가했다고 발표했다. Pro·Pro+·Max·Business·Enterprise 이용자가 제공 대상이며, 배포는 순차적으로 진행할 예정이다. [원문 1](<https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot>)

### 모델을 선택할 수 있는 개발 환경

모델 선택 화면의 제공 범위에는 Visual Studio Code·Visual Studio·Copilot CLI·Copilot cloud agent·Copilot App·github.com·GitHub Mobile(iOS·Android)·JetBrains·Xcode·Eclipse가 포함된다. [원문 1](<https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot>)

### 조직 설정과 데이터 정책

Business와 Enterprise 관리자는 Copilot의 모델 정책 설정에서 조직의 Sonnet 5 접근을 활성화할 수 있다. GitHub는 다른 Sonnet 모델과 마찬가지로 Zero Data Retention(ZDR) 정책을 적용한다고 설명했다. [원문 1](<https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot>)

### 사용량에 따른 과금

사용량 기반 과금(Usage Based Billing)에서는 모델 제공자의 공시 가격으로 청구한다. [원문 1](<https://github.blog/changelog/2026-06-30-claude-sonnet-5-is-generally-available-for-github-copilot>)
