# 엔비디아, 에이전틱 AI용 CPU 랙 설계 공개…OCP에 제출


디일렉은 10월 14일 보도에서 엔비디아가 10월 12일(현지시간) OCP 글로벌 서밋에서 에이전틱 AI 작업용 Vera CPU 랙을 처음 공개하고 MGX 1.2 기반 설계를 OCP Open DC 이니셔티브에 제출했다고 전했다. 엔비디아 설명에 따르면 GPU 중심 Vera Rubin NVL72가 기존 LLM 학습·추론을 맡고, CPU 랙은 CPU 연산 비중이 높은 에이전틱 AI 작업을 맡는다. 랙에는 연산·네트워크·전력·냉각을 공통 모듈 플랫폼으로 묶어 서버 제조사가 목적별 서버를 설계하도록 했다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63657>)

### 랙 전력·냉각과 OCP 설계 제출

MGX 1.2는 19인치 랙 장비와 호환되고 랙당 최대 250킬로와트를 지원한다. 액체 냉각과 표준 연결 구조, 재구성 가능한 I/O 슬롯, 팬 없는 연산 트레이를 적용했으며 조립·정비 시간을 줄였다고 엔비디아는 설명했다.

엔비디아는 서버 제조사들이 차세대 AI 팩토리용 인프라를 개발·공급하도록 설계 자료를 OCP에 냈다고 밝혔다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63657>)
