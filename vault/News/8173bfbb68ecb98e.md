# Copilot 영향 대시보드, 사용 단계별 PR 지표와 6개월 추세 표시


GitHub는 7월 22일 기업 관리자와 조직 소유자를 위한 Copilot 사용 영향 대시보드를 출시했다고 발표했다. 코드 중심·에이전트 중심·다중 에이전트 또는 Copilot 앱 사용 집단과 미참여 집단을 나눠 PR 처리 지표를 보여준다. [원문 1](<https://github.blog/changelog/2026-07-22-new-copilot-usage-metrics-impact-dashboard/>)

### 집단별 표시 지표

사용자 한 명당 월평균 병합 PR 수·PR 병합 속도 중앙값·집단별 사용자 수와 전체 비중·하루 평균 코드 줄 수를 제공한다.

미참여 집단과 참여 Copilot 사용자의 평균 처리량·속도를 비교하고, 6개월의 집단 성장과 PR 처리량 추세를 보여준다. [원문 1](<https://github.blog/changelog/2026-07-22-new-copilot-usage-metrics-impact-dashboard/>)

### 분류 기간과 접근 권한

집단 분류는 최근 28일의 제품 사용에 따른 ai_adoption_phase를 사용한다. 대시보드는 Copilot 사용 지표 접근 권한을 가진 기업 관리자와 조직 소유자가 사용할 수 있다. [원문 1](<https://github.blog/changelog/2026-07-22-new-copilot-usage-metrics-impact-dashboard/>)
