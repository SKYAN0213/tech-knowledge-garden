# AWS, AG-UI로 에이전트와 화면을 연결하는 구현 예제 공개


AWS는 2026년 7월 1일(한국시간) Amazon Bedrock AgentCore에서 AG-UI를 활용하는 구현 지침과 CopilotKit 예제를 공개했다. 예제는 에이전트가 화면에 차트를 띄우고, 사용자와 작업 상태를 공유하며, 실행 중 사용자 입력을 받아 작업을 이어가는 구조를 보여준다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-generative-ui-for-ai-agents-on-amazon-bedrock-agentcore-with-the-ag-ui-protocol/>)

### 에이전트와 화면 사이의 이벤트 규약

AG-UI는 에이전트와 사용자 화면을 연결하는 공개 프로토콜이다. Strands·LangGraph·CrewAI 같은 에이전트 프레임워크와 React·Angular·Vue 같은 화면 라이브러리를 분리해 연결한다.

FAST v0.4.1에는 Strands와 LangGraph용 AG-UI 패턴이 추가됐다. 두 패턴은 Server-Sent Events(SSE)로 같은 형식의 이벤트를 보내므로, 화면의 공통 파서를 유지하면서 백엔드 프레임워크를 바꿀 수 있다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-generative-ui-for-ai-agents-on-amazon-bedrock-agentcore-with-the-ag-ui-protocol/>)

### 화면 구성 요소와 사용자 입력

이 예제에서는 화면이 미리 준비한 React 구성 요소를 소유하고, 에이전트가 표시할 구성 요소와 데이터를 선택한다. 차트 도구는 샘플 CSV에서 데이터를 가져와 AG-UI 도구 호출 이벤트로 전달한다.

할 일 캔버스는 STATE\_SNAPSHOT으로 상태를 양방향 동기화하며, 사용자가 직접 바꾼 내용은 다음 에이전트 실행에 반영된다. 회의 예약 예제는 시간 선택기를 띄운 뒤 실행을 멈추고, 사용자 선택을 TOOL\_CALL\_RESULT로 받아 이어간다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-generative-ui-for-ai-agents-on-amazon-bedrock-agentcore-with-the-ag-ui-protocol/>)

### Runtime 인증과 선택형 메모리

AG-UI 플래그로 컨테이너를 배포하면 AgentCore Runtime은 프록시로 동작하면서 인증·세션 격리·확장·관측을 처리한다. FAST의 두 패턴에서 AgentCore Memory는 선택 사항이며, MEMORY\_ID를 설정하지 않으면 메모리를 별도로 준비하지 않고 실행할 수 있다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-generative-ui-for-ai-agents-on-amazon-bedrock-agentcore-with-the-ag-ui-protocol/>)
