# AWS, Quick Sight 자산·사용자 정보를 분리 백업하는 도구 공개


AWS는 2026년 6월 30일(한국시간) Quick Sight의 대시보드·분석·데이터셋 등을 백업하는 AssetsAsBundle API 지침과 샘플 도구를 공개했다. 자산 묶음은 S3에, 사용자·그룹·그룹 구성원 정보는 DynamoDB에 나누어 보관한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/implement-a-backup-strategy-for-amazon-quick-sight-bi-assets/>)

### 대시보드와 의존 자산을 함께 내보냄

대시보드에는 데이터셋·데이터 소스·VPC 연결·테마 등의 의존성이 있다. 샘플은 기본적으로 의존 자산을 함께 내보내고, 자산 종류별로 최대 100개씩 묶어 비동기 export 작업을 시작한다.

완료 상태는 DescribeAssetBundleExportJob으로 조회한다. 반환되는 다운로드 URL은 5분 동안 유효하며 같은 API를 다시 호출해 갱신할 수 있다. 다운로드한 묶음은 지속 보관용 S3 위치로 옮긴다.

사용자와 그룹은 AssetsAsBundle API에 포함되지 않는다. 별도 API로 조회해 날짜를 붙인 DynamoDB 테이블에 저장하며, identity\_region과 자산의 aws\_region을 따로 설정해 두 리전이 다른 계정을 처리한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/implement-a-backup-strategy-for-amazon-quick-sight-bi-assets/>)

### 샘플 도구의 실행 범위

도구는 전체·사용자 전용·자산 전용 모드를 제공하고 이전 백업을 덮어쓰지 않는다. 일부 데이터 소스와 연결된 SageMaker 추론 열이 있는 데이터셋은 export 대상에서 제외해야 한다.

이 샘플은 요청 시 실행하는 도구다. EventBridge·Step Functions·Lambda를 이용한 정기 백업은 별도의 설계안으로 소개됐으며, 그 구조의 구현 코드는 글에 포함되지 않았다. 같은 계정에서 샘플 도구를 동시에 여러 번 실행하면 API 제한에 걸릴 수 있어 동시 실행을 피하도록 안내한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/implement-a-backup-strategy-for-amazon-quick-sight-bi-assets/>)
