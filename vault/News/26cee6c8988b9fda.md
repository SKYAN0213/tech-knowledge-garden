# KRCERT, PHP2Shell 취약점 대응 위해 패치와 침해 흔적 점검 권고


KRCERT는 2026년 10월 22일 PHP에서 로그인 없이 외부 명령을 실행할 수 있는 CVE-2026-109618·CVE-2026-109619 취약점이 발견됐으며, 심각도는 CVSS 9.2라고 밝혔다. 권고문은 PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35 이상을 해결 버전으로 제시하고, 호환성과 안정성을 검토한 뒤 패치를 적용하도록 안내했다. 이 취약점은 서버 메모리의 비밀번호·토큰·API 키를 유출시킬 수 있으며, 기록에 이상이 없더라도 안전이 보장되지는 않아 업데이트와 침해 점검, 인증정보 교체가 함께 권고됐다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72230>)

### 실제 웹 실행 환경의 패치 반영

업데이트 후에는 PHP-FPM, Apache mod\_php, php-cgi, FrankenPHP, LiteSpeed 등 실제 PHP 웹 서비스를 재시작해야 하며, 그렇지 않으면 메모리에 남은 이전 버전이 계속 동작할 수 있다. 컨테이너는 신규 이미지를 재배포해야 한다. 명령줄 php -v 결과와 웹 서비스의 실행 버전이 다를 수 있어, PHP가 여러 개 설치된 서버는 각각 확인해야 한다.

리눅스 배포판·제조사가 제공하는 보안 업데이트도 대응에 포함된다. 이런 패키지는 패치 뒤에도 버전 번호가 바뀌지 않을 수 있으므로 패키지 변경 이력에서 해당 CVE 반영 여부를 확인해야 한다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72230>)

### 지원 종료 버전과 임시 설정

PHP 8.1 이하는 공식 업데이트가 제공되지 않아 지원 버전으로 전환해야 한다. PHP 8.2의 보안 지원은 2026년 12월 31일 끝날 예정이므로 8.3 이상으로 전환하도록 권고했다. 전환에 시간이 걸리면 배포판·장기지원 업체의 패치나 PHP 보안팀이 공개한 7.4·8.0·8.1용 소스 패치를 임시 적용하고 전환 계획을 세우도록 안내했다.

공식 임시 설정은 php.ini, PHP-FPM pool 또는 웹 서버 설정에서 session.upload\_progress.enabled=0, memory\_limit=-1을 적용하는 방식이다. memory\_limit은 프로그램이 변경하지 못하도록 관리자 설정으로 강제하며, post\_max\_size를 낮게 두고 upload\_max\_filesize를 그보다 작게 유지하도록 했다.

업로드가 필요 없으면 post\_max\_size를 8M, 필요하면 32M 수준으로 두고, PHP 8.5에서는 fatal\_error\_backtraces=0을 추가하도록 했다. 임시 설정은 공격을 완전히 막지 못하므로 패치 업데이트가 필요하다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72230>)

### 침해 점검과 증거 보존의 순서

취약점 정보 유출일인 10월 20일 이후의 기록 전체를 점검하고, 가능하면 그 이전 기록도 확인하도록 권고했다. 침해 대응의 격리 단계에서는 서버 전원을 끄거나 재시작하지 말고 외부 네트워크 접속만 차단하며, 업데이트·재시작 전에 메모리 등 공격 흔적을 확보해야 한다.

증거 확보 뒤에는 업데이트·재시작, 웹셸 제거, 인증정보 교체를 진행하도록 안내했다. 업데이트 전까지 인터넷에 노출된 서버에는 DB 비밀번호·외부 서비스 연동 키·관리자 계정 비밀번호 교체를 권장하고, 침해 흔적이 발견된 서버에는 반드시 교체하도록 했다. [원문 1](<https://www.krcert.or.kr/kr/bbs/view.do?searchCnd=&bbsId=B0000133&searchWrd=&menuNo=205020&pageIndex=1&categoryCode=&nttId=72230>)
