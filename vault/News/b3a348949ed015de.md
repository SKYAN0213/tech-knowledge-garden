# SkillFortify, 에이전트 스킬의 정적 분석·권한 격리·의존성 해결 제안


연구진은 2026년 2월 27일 arXiv에, AI 에이전트 스킬 공급망을 형식적으로 분석하는 SkillFortify 사전공개 논문을 제출했다. v1 초록은 공격자 모델·정적 분석·권한 기반 샌드박스·의존성 그래프를 결합하는 구성을 제안한다. [원문 1](<https://arxiv.org/abs/2603.00195v1>)

### 분석과 의존성 처리

정적 분석은 추상 해석에 기반하며, 스킬의 실행 권한을 제한하는 샌드박스와 SAT 기반 의존성 해결·잠금 파일 의미를 함께 다룬다. 연구진은 공격자 모델의 최대성과 격리 범위에 대한 증명을 제시한다고 설명했다. [원문 1](<https://arxiv.org/abs/2603.00195v1>)

### 초록이 보고한 평가 조건

연구진은 스킬 540개로 구성한 SkillFortifyBench에서 F1 96.95%, 정밀도 100%, 거짓 양성률 0%를 보고했다. 이 수치는 해당 벤치마크의 평가 결과다. [원문 1](<https://arxiv.org/abs/2603.00195v1>)
