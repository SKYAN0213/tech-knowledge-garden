# AWS Lambda, 자체 운영 Kafka ESM에 OAuth 인증 지원


AWS는 2026년 10월 9일 AWS Lambda의 자체 운영 Kafka 클러스터용 이벤트 소스 매핑(ESM)에 OAuth 인증을 지원한다고 밝혔다. 이번 지원은 고객 자체 운영 클러스터와 Confluent Cloud, Aiven, Redpanda 등 관리형 서비스에 적용되며, 고객은 기업 ID 공급자를 이용해 Lambda Kafka consumer를 인증할 수 있다. OAuth 인증은 자체 운영 Kafka ESM을 이용할 수 있는 모든 AWS 상용 리전에서 제공되며, 사용자는 AWS Management Console, Lambda API, AWS CLI, AWS CloudFormation 또는 AWS SAM으로 인증 구성을 포함한 새 ESM을 만들어야 한다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-Lambda-supports-oauth-kafka-esm/>)

### 인증 방식과 정책 적용

기존 Kafka ESM이 지원하던 인증 방식은 SASL/PLAIN, SASL/SCRAM, 상호 TLS(mTLS)였으며, OAuth 추가로 Amazon Cognito나 Okta 같은 기업 ID 공급자를 사용해 Kafka 클러스터와 Lambda consumer 전반에 동일한 ID 거버넌스 및 접근 정책을 적용할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/aws-Lambda-supports-oauth-kafka-esm/>)
