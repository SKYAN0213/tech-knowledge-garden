# AMD, 에이전트 실행 겨냥 CPU 중심 AI 랙 Helion 공개


더일렉은 2026년 10월 13일 보도에서 AMD가 12일(현지시간) OCP Global Summit에서 AI 에이전트 실행에 초점을 둔 CPU 중심 랙 설계 Helion을 공개했다고 전했다. 대형 데이터센터 구성은 랙 하나에 최대 3만2,768개의 서버 CPU 코어를 탑재하고 에이전트를 실행하며, 모델 추론은 별도 GPU 시스템에 요청하도록 설계됐다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63596>)

### 고객 구성에 따라 CPU와 GPU를 나누거나 결합

기업용 구성은 AMD EPYC CPU와 Instinct MI350P GPU를 한 랙에 결합해 에이전트 실행과 모델 추론을 함께 처리하며 GPU를 최대 16개 탑재한다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63596>)

### 모델 요청 라우팅과 개방형 공급 계획

Helion에 통합된 토큰 라우터는 에이전트의 모델 요청을 고성능 모델과 오픈소스 모델로 나누며, AMD는 일부 요청을 자체 서버의 오픈소스 모델로 보내면 AI 사용 비용을 줄일 수 있다고 설명했다.

Helion은 완제품 서버가 아닌 OCP 기반 개방형 참조 설계로 공랭·수랭과 고객별 CPU·전력 구성을 지원하며, AMD는 관련 사양을 OCP에 제공하고 서버 업체를 통한 공급을 11월 시작할 계획이라고 밝혔다. [원문 1](<https://www.thelec.kr/news/articleView.html?idxno=63596>)
