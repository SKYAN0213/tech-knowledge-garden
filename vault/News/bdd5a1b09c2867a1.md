# 생기원, 휴머노이드 학습용 전신 동작 데이터 플랫폼 구축


한국생산기술연구원은 10월 14일 관절·보행·손동작을 함께 기록하는 전신동작 데이터 수집 플랫폼 HHIP를 구축했다고 발표했다. 연구원은 착용형 로봇 검증에 이어 휴머노이드 제어 모델 개발에도 활용한다고 밝혔다. 돔 안의 고속 트레드밀과 광학 모션캡처 카메라, 바닥 힘판, 손 글러브 센서와 피부 근전도 센서로 관절 위치·발 디딤 힘·손가락 움직임·근육 신호를 수집한다. 트레드밀 최고 속도는 시속 45㎞다. [원문 1](<https://www.kitech.re.kr/pages/61?id=14409&menuMode=READ&q=>)

### 여러 센서의 시간을 맞춰 전신을 기록

연구팀은 센서마다 다른 시점을 하나의 시간 축에 맞춰 저장하는 소프트웨어를 개발해 정확도를 검증했다. 같은 동작을 맨몸과 착용형 로봇 상태에서 측정해 전후를 비교할 수 있다고 연구원은 설명했다.

연구원은 이 플랫폼으로 무릎 착용형 로봇 AirKnee의 동작·힘 사용을 검증했고, 현재는 사람이 작업할 때의 동작 자료를 모아 휴머노이드 제어 모델 개발에 활용하고 있다고 밝혔다. [원문 1](<https://www.kitech.re.kr/pages/61?id=14409&menuMode=READ&q=>)
