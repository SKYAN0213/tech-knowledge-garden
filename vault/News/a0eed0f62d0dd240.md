# NVIDIA, 공개 모델 체크포인트를 C++ 추론으로 연결하는 Model Connect 소개


NVIDIA는 2026년 8월 28일 기술 블로그에서 지원되는 공개 모델을 TensorRT 기반 네이티브 C++ 애플리케이션으로 배포하는 TensorRT Model Connect를 소개했다. Hugging Face 모델 ID나 로컬 체크포인트에서 TensorRT 엔진과 모델별 실행 자산을 담은 번들을 만든 뒤 C++ 애플리케이션에서 불러와 추론한다. 모델 준비에는 Python을 사용할 수 있지만, 배포된 애플리케이션의 실행에는 PyTorch나 Python 인터프리터가 필요하지 않다. [원문 1](<https://developer.nvidia.com/blog/deploy-an-open-model-from-checkpoint-to-inference-in-two-commands-with-nvidia-tensorrt-model-connect/>)

### 체크포인트 매핑과 실행 자산을 담은 번들

Model Connect는 확인·수정·확장할 수 있는 공개 참조 구현 모음으로, 체크포인트 매핑과 TensorRT 엔진 생성, 전처리, 실행 조정, 후처리를 처리한다.

NVIDIA는 이 구현이 새로운 추론 프레임워크나 TensorRT 대체물이 아니라 공개 모델의 전체 추론 경로와 TensorRT 엔진을 연결한다고 설명했다. [원문 1](<https://developer.nvidia.com/blog/deploy-an-open-model-from-checkpoint-to-inference-in-two-commands-with-nvidia-tensorrt-model-connect/>)

### 작업 입출력 API와 텐서 수준 API

작업 수준의 semantic API는 프롬프트·이미지·오디오 등의 입출력을 받는다. module API는 이름이 지정된 텐서와 개별 TensorRT 구성요소를 다뤄 추론 경로를 조정하게 한다. [원문 1](<https://developer.nvidia.com/blog/deploy-an-open-model-from-checkpoint-to-inference-in-two-commands-with-nvidia-tensorrt-model-connect/>)

### 모델 일부의 GPU 커널 교체

TVM FFI를 통해 모델의 일부를 사용자 GPU 커널로 바꾸고, 나머지 추론 경로는 TensorRT로 실행할 수 있다. [원문 1](<https://developer.nvidia.com/blog/deploy-an-open-model-from-checkpoint-to-inference-in-two-commands-with-nvidia-tensorrt-model-connect/>)
