# Amazon SageMaker AI, Muse Glimmer·Qwen3.8·Ministral 3 서버리스 맞춤화 지원


Amazon은 2026년 10월 22일 Amazon SageMaker AI에서 Muse Glimmer, Qwen3.8 27B, Ministral 3 3B·8B·14B 모델의 기존 배포 지원에 더해 서버리스 맞춤화 지원을 추가했다고 발표했다. Amazon은 도메인과 업무 흐름에 맞춘 학습에 지도 미세 조정(SFT)·직접 선호도 최적화(DPO)·강화 미세 조정(RFT)을 사용할 수 있으며, 모델 적응 방식으로 저랭크 적응(LoRA) 또는 전체 미세 조정을 지원한다고 설명했다. Amazon은 사용자가 자체 데이터를 제공하면 SageMaker AI가 인프라 준비와 학습 오케스트레이션을 맡고, 사용자는 데이터와 평가에 집중하며 사용한 만큼 비용을 낸다고 설명했다. Amazon에 따르면 서버리스 맞춤화는 미국 동부(버지니아 북부), 미국 서부(오리건), 아시아 태평양(도쿄), 유럽(아일랜드)에서 이용할 수 있으며, SageMaker Studio의 Models 페이지, SageMaker Python SDK 또는 코딩 보조 도구와 함께 쓰는 Agent skills로 맞춤화 작업을 시작할 수 있다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-sagemaker-muse-qwen-ministral/>)

### 맞춤화 방식

Amazon은 라벨이 붙은 데이터로 도메인별 작업의 정확도를 높이는 데 SFT를, 선호 데이터로 출력을 조직의 어조에 맞추는 데 DPO를, 보상 신호로 새 작업 성능을 높이는 데 RFT를 활용할 수 있다고 설명했다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-sagemaker-muse-qwen-ministral/>)
