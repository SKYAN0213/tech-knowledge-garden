# 이력서의 자격 정보 없는 자기 홍보 문구가 LLM 채용 순위를 바꾼 실험


연구진은 2026년 6월 25일 arXiv에 LLM 기반 이력서 심사에서 프롬프트 주입이 순위를 바꾸는지 조사한 사전공개 논문을 등록했다. 실험에서는 새 자격을 추가하지 않는 자기 홍보 문구를 이력서에 넣고, 지원자 간 품질 차이와 주입 사용 비율에 따른 순위 변화를 비교했다. [원문 1](<https://arxiv.org/abs/2606.27287v1>)

### 품질과 주입 비율에 따른 결과

초록에 따르면 이력서 품질이 비슷하고 주입을 쓰는 지원자가 적을 때 순위 상승이 안정적으로 나타났다. 주입 사용자가 늘면 효과가 빠르게 줄었고 조작이 널리 퍼지면 효과가 무너졌다.

지원자 품질 차이가 있을 때 평균 효과는 더 작았지만, 일부 조건에서는 낮은 품질의 지원자가 더 높은 품질의 지원자를 앞섰다. 저자들은 조작이 드물고 품질 차이가 작을 때 심사 시스템이 특히 취약했다고 설명했다. [원문 1](<https://arxiv.org/abs/2606.27287v1>)
