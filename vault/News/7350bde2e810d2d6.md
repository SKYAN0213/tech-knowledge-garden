# 아우디, 잉골슈타트 공장서 휴머노이드 물류 PoC 착수


2026년 10월 26일 게시된 기사에서 아우디는 애자일 로봇·다쏘시스템·엔비디아 등과 독일 잉골슈타트 공장의 자동차 생산 물류 현장에서 휴머노이드 로봇 개념검증(PoC)에 착수했다고 밝혔다. 실증은 부품 공급과 순서 배치 작업을 자동화하기 위해 진행 중이다. [원문 1](<https://www.irobotnews.com/news/articleView.html?idxno=49213>)

### 휴머노이드의 작업

애자일 로봇의 이동형 휴머노이드는 부품 보관함에서 부품을 꺼내 최종 조립에 필요한 순서대로 운반 카트에 배치한다. [원문 1](<https://www.irobotnews.com/news/articleView.html?idxno=49213>)

### 실제 생산·물류 환경에서 검증

시험은 아우디의 미래 생산·물류 기술 시험 공간인 프로덕션 랩에서 진행된다. 아우디 공급망 전문가들이 실제 작업 요건을 정의하고, 휴머노이드 로봇이 기존 생산·물류 환경에서 해당 작업을 수행할 수 있는지 확인한다. [원문 1](<https://www.irobotnews.com/news/articleView.html?idxno=49213>)
