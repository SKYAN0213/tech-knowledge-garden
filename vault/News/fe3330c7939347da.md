# 에이전트 보안 연구, 사람의 정책·승인·권한 설정을 분석


연구진은 2026년 5월 23일 arXiv에, 언어 모델 에이전트의 보안을 사람과 에이전트의 상호작용 문제로 다루는 사전공개 논문을 제출했다. v1 초록은 정책 명세·실행 시점 승인·권한 범위 설정이 실제 시스템에서 널리 쓰이는 반면, 학계의 연구 관심은 다른 방어 방식에 집중돼 있다고 설명한다. [원문 1](<https://arxiv.org/abs/2605.24309v1>)

### 분석에 포함한 자료와 시스템

연구진은 2026년 4월까지의 학술 논문 59편, 운영 에이전트 시스템 21개, 보안 플러그인 26개를 체계적으로 분석했다. 정책 명세·실행 시점 승인·권한 설정은 조사한 시스템에서 각각 14개·15개·16개에 채택돼 있었다.

초록은 사람이 반복 승인을 수행할 때의 인지 부담과 보안 보장 사이에 상충이 있다고 지적한다. 조사 대상 운영 시스템에서는 intent anchoring과 trust labeling의 도입 사례를 찾지 못했다고 보고하며, 사람의 참여를 설계·평가하는 연구 의제를 제안했다. [원문 1](<https://arxiv.org/abs/2605.24309v1>)
