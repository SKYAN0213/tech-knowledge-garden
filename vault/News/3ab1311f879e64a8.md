# GitHub Copilot, Claude Opus 4.8 fast mode 프리뷰 확대


GitHub는 2026년 6월 30일(한국시간) Copilot에 Claude Opus 4.8 fast mode 프리뷰를 순차 제공한다고 발표했다. Pro+·Max·Business·Enterprise 이용자가 대상이며, 기업용 플랜에서는 관리자가 기본 꺼짐 상태인 정책을 활성화해야 한다. [원문 1](<https://github.blog/changelog/2026-06-29-claude-opus-4-8-fast-mode-is-now-in-preview-for-github-copilot>)

### 접근 조건과 비용

GitHub는 fast mode가 표준 Opus 4.8의 지능을 유지하면서 출력 토큰 속도를 높인다고 설명했다.

모델 선택기는 VS Code·Visual Studio·Copilot CLI·cloud agent·Copilot 앱·github.com·모바일·JetBrains·Xcode·Eclipse에서 제공된다. 점진 배포이므로 모든 이용자에게 동시에 나타나는 방식은 아니다.

사용량 기반 과금에서는 공급자 정가를 적용한다. GitHub에 따르면 이전 fast mode보다는 저렴하지만 표준 Opus 4.8보다는 비용이 높다. [원문 1](<https://github.blog/changelog/2026-06-29-claude-opus-4-8-fast-mode-is-now-in-preview-for-github-copilot>)
