# Cloudflare, Deno 인수 발표…Workers 개선에 활용 계획


2026년 10월 10일 TechCrunch 보도에 따르면, Cloudflare는 동명의 프로그래밍 런타임을 개발한 스타트업 Deno를 인수한다고 발표했다. Cloudflare Workers 수석 엔지니어 Kenton Varda에 따르면, Cloudflare는 이번 인수를 Workers 프로그래밍 모델과 플랫폼 개선에 활용할 계획이며, 이 플랫폼은 고객이 Cloudflare 네트워크에서 소프트웨어를 만들고 실행하도록 지원한다. TechCrunch는 Deno가 최근 Workers의 오픈소스 구현체를 ‘celld’라는 표기로 출시했고, Kenton Varda가 이를 Cloudflare 팀이 반긴 프로젝트로 소개했다고 전했다. Deno 공동 창업자 Ryan Dahl은 팀이 서버 구축의 주류 방식으로 Workers 프로그래밍 모델을 만들기 위해 Cloudflare에 합류한다고 썼다. [원문 1](<https://techcrunch.com/2026/10/10/cloudflare-acquires-deno-to-improve-its-workers-programming-model/>)

### 거래와 Deno의 자금 조달

인수의 재무 조건은 공개되지 않았다. Deno는 Sequoia가 주도한 시리즈 A를 포함해 총 2,600만 달러를 조달했다. [원문 1](<https://techcrunch.com/2026/10/10/cloudflare-acquires-deno-to-improve-its-workers-programming-model/>)
