# GitHub Mobile, Copilot 세션의 상태·저장소 필터와 정렬 추가


GitHub는 2026년 7월 10일 GitHub Mobile의 Copilot 세션 목록에 필터와 정렬 기능을 추가했다고 발표했습니다. 발표 당시 iOS와 Android의 최신 정식 버전에서 제공되는 기능으로, 목록이 늘어났을 때 특정 세션을 찾도록 구성됐습니다. [원문 1](<https://github.blog/changelog/2026-07-10-github-mobile-improved-filters-and-sorting-for-copilot-sessions>)

### 찾을 세션과 표시 순서를 따로 선택

세션을 상태·저장소·유형·에이전트별로 좁힐 수 있습니다. Active 필터는 보관 처리하지 않은 세션을 뜻합니다.

정렬은 최신순, 오래된순, 활성 세션 우선, 확인이 필요한 세션 우선 중에서 선택합니다. 표시 순서를 바꿔도 적용 중인 필터 조건은 유지됩니다. [원문 1](<https://github.blog/changelog/2026-07-10-github-mobile-improved-filters-and-sorting-for-copilot-sessions>)
