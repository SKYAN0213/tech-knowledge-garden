# Base44, 앱 생성용 자체 모델 Base1 운영 시작


Wix는 2026년 6월 29일(한국시간) Base44가 앱 생성용 자체 모델 Base1을 출시해 플랫폼 사용자에게 제공하고 있다고 발표했다. TechCrunch도 6월 30일(한국시간) 자연어 앱 제작을 지원하는 자체 모델의 도입 시작을 보도했다. [원문 1](<https://www.wix.com/press-room/home/post/base44-becomes-first-app-creation-platform-to-launch-its-own-proprietary-llm-base-1-marking-a-maj>) [원문 2](<https://base44.com/blog/maor-shlomo-building-the-model-behind-base>) [원문 3](<https://techcrunch.com/2026/06/29/vibe-coding-platform-base44-launches-own-model-as-ai-startups-seek-defensibility/>)

### 앱 제작 과정에서 얻는 학습 데이터

Wix에 따르면 모델 개발과 최적화에는 플랫폼의 수천만 건 실제 사용자 상호작용에서 만들어진 데이터셋을 사용했다. 창업자 Maor Shlomo는 사용자의 요청, 에이전트가 만든 결과, 오류, 사용자의 수정과 수락·거절, 실제 앱의 작동 여부를 피드백으로 살핀다고 설명했다. [원문 1](<https://www.wix.com/press-room/home/post/base44-becomes-first-app-creation-platform-to-launch-its-own-proprietary-llm-base-1-marking-a-maj>) [원문 2](<https://base44.com/blog/maor-shlomo-building-the-model-behind-base>)

### 모델과 실행 환경을 함께 설계

Wix는 에이전트가 대화·코딩·여러 차례 이어지는 상호작용과 도구 사용, 실행 환경 관리, 백엔드 작업을 처리한다고 설명했다. Shlomo는 모델을 둘러싼 실행 환경인 harness를 도구·맥락·작업 흐름·제품 환경의 묶음으로 설명하며, Base44가 이 환경을 직접 관리한다고 밝혔다.

Shlomo는 Base44가 프런트엔드와 백엔드를 보유하고, 자체 데이터베이스·백엔드·모델·이를 잇는 지능 계층을 함께 갖추는 방향으로 확장한다고 설명했다. [원문 1](<https://www.wix.com/press-room/home/post/base44-becomes-first-app-creation-platform-to-launch-its-own-proprietary-llm-base-1-marking-a-maj>) [원문 2](<https://base44.com/blog/maor-shlomo-building-the-model-behind-base>)

### 개발 인력과 평가 기반

Wix의 데이터 과학·연구팀은 Wix Harmony 학습 경험을 Base44 모델 개발에 적용한다. Wix 발표에 따르면 샌드박스, 평가 프레임워크, 실험 파이프라인을 마련해 여러 에이전트 설정을 실시간으로 시험하고 실제 트래픽에 배포한다. 모델 구축에는 Wix·Base44와 추론 서비스 제공업체들이 참여했다. [원문 1](<https://www.wix.com/press-room/home/post/base44-becomes-first-app-creation-platform-to-launch-its-own-proprietary-llm-base-1-marking-a-maj>)

### 비용 최적화와 후속 개발 방향

TechCrunch는 Shlomo가 모델을 직접 학습·보유하면 지연시간·비용·효율을 더 세밀하게 최적화할 수 있다고 설명했다고 전했다. Wix는 컴퓨팅과 추론 지출을 직접 관리해 시간이 흐르면서 마진이 개선될 것으로 기대한다고 밝혔다.

Shlomo는 작업에 적합한 경우 외부의 고성능 모델도 계속 사용하겠다고 밝혔다. 후속 개발에서는 코드를 구현하는 능력과 함께 제품 설계 판단, 다음 요구 예측, 더 나은 경로 제안을 학습시키며 기술 파트너 역할을 목표로 한다.
