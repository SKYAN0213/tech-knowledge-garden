# GitHub Copilot 영향 대시보드에 업계 비교 기능 추가


GitHub는 2026년 10월 22일 현지 기준 변경 안내에서 Copilot 영향 대시보드에 ‘Industry comparison’ 섹션이 추가됐다고 밝혔다. 참여 기업의 집계 벤치마크와 에이전트 우선·멀티 에이전트 사용자 비중 및 에이전트 사용자와 비에이전트 사용자의 풀 리퀘스트 병합률을 비교하는 기능으로, 참여는 기본 비활성화된 선택 사항이다. [원문 1](<https://github.blog/changelog/2026-10-22-industry-comparisons-in-the-copilot-impact-dashboard>)

### 비교 지표와 집단 선택

충분한 기업이 참여하면 각 점수는 28일 보고 기간의 비교집단 중앙값을 기준으로 순위가 매겨지며, 집단이 더 커지면 상위 십분위(top decile)와도 비교한다.

기업 소유자와 기업 소속이 아닌 조직의 소유자는 직원 규모 구간과 10개 산업 중 하나를 선택해 같은 산업 또는 전체 산업과 비교할 수 있다. 직원 규모의 예시는 1\~999명, 1,000\~4,999명, 5,000명 이상이다.

선택한 산업의 비교집단이 너무 작으면 같은 직원 규모의 전체 산업으로 범위가 넓어지며, 대시보드는 실제 사용한 비교집단을 표시한다. [원문 1](<https://github.blog/changelog/2026-10-22-industry-comparisons-in-the-copilot-impact-dashboard>)

### 참여 자격과 순위가 보이지 않는 경우

기업과 기업 소속이 아닌 조직이 참여할 수 있으며, 기업 소속 조직은 그 기업을 통해 참여한다. Copilot Business 라이선스 할당에만 쓰이는 기업은 참여할 수 없다. Copilot 사용량 지표 정책이 켜져 있어야 하며, 대시보드 열람 권한이 있는 사용자는 비교 결과를 볼 수 있다.

참여 기업이 충분하지 않으면 중앙값만 보이거나 선택보다 넓은 비교집단이 사용되고, 순위가 아직 표시되지 않을 수 있다. 조직의 모든 사용자가 이미 에이전트 우선 또는 멀티 에이전트여서 활용도 지표의 비에이전트 기준선을 계산할 수 없는 경우에도 순위는 제공되지 않는다. [원문 1](<https://github.blog/changelog/2026-10-22-industry-comparisons-in-the-copilot-impact-dashboard>)

### 정책과 데이터 처리

대시보드와 기업·조직의 Copilot 정책 설정은 같은 참여 정책을 조절한다. 어느 경로에서든 끄면 데이터 기여와 비교 접근이 중단되고, 비교 표시는 즉시 사라지며 데이터는 다음 일일 갱신부터 제외된다.

비교 결과는 매일 갱신되고, 식별 정보가 없는 집계 벤치마크는 30일 뒤 삭제된다.

데이터 상주 기능을 사용하는 GitHub Enterprise Cloud에서는 같은 지역의 참여자끼리만 비교하며, 지역 간 데이터는 합쳐지지 않는다. [원문 1](<https://github.blog/changelog/2026-10-22-industry-comparisons-in-the-copilot-impact-dashboard>)

### 대시보드 안에서만 제공

업계 비교 결과는 Copilot 영향 대시보드에서만 제공되며, Copilot 사용량 지표 API·NDJSON 내보내기·다운로드에는 포함되지 않는다. [원문 1](<https://github.blog/changelog/2026-10-22-industry-comparisons-in-the-copilot-impact-dashboard>)
