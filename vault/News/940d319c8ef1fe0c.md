# AI SDK 7.0.8, 비디오 생성에 프레임 이미지·참조 입력 옵션 추가


Vercel의 AI SDK는 2026년 6월 30일(한국시간) ai@7.0.8 패키지를 공개했다. 비디오 생성 호출에 frameImages와 inputReferences를 정식 옵션으로 추가했다. [원문 1](<https://api.github.com/repos/vercel/ai/releases/tags/ai%407.0.8>)

### 변경된 호출 옵션과 의존성

이번 변경은 비디오 생성 호출에서 프레임 이미지와 참조 입력을 별도 옵션으로 받도록 한다. 릴리스에는 @ai-sdk/provider 4.0.1, @ai-sdk/gateway 4.0.6, @ai-sdk/provider-utils 5.0.2로의 의존성 갱신도 포함한다. [원문 1](<https://api.github.com/repos/vercel/ai/releases/tags/ai%407.0.8>)
