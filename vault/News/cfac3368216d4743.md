# Google, Gemini Spark macOS 베타 출시


Google은 2026년 7월 1일(한국시간) 데스크톱 작업을 자동화하는 Gemini Spark를 Gemini macOS 앱에 도입했다. 미국에서 18세 이상 Google AI Ultra 구독자에게 베타로 제공한다. [원문 1](<https://blog.google/innovation-and-ai/products/gemini-app/gemini-spark-updates-june-2026/>)

### 허용한 파일과 Workspace로 작업

Spark는 사용자가 권한을 준 파일에만 접근한다. Google이 제시한 활용 예시는 Downloads의 PDF를 폴더별로 분류하거나, 컴퓨터에 저장한 청구서로 예산 스프레드시트를 만들고 정기 갱신 일정을 설정하는 작업이다. [원문 1](<https://blog.google/innovation-and-ai/products/gemini-app/gemini-spark-updates-june-2026/>)

### 연결 앱의 제공 일정

Google Tasks·Keep 연결을 지원하며 Canva·Dropbox·Instacart·OpenTable·Zillow Rentals 연결도 발표했다. 새 연결은 웹·모바일에서 발표 뒤 일주일에 걸쳐, macOS에서는 향후 몇 주에 걸쳐 순차 제공할 예정이다.

사용자 지정 Model Context Protocol(MCP) 연결 지원도 순차적으로 추가한다. [원문 1](<https://blog.google/innovation-and-ai/products/gemini-app/gemini-spark-updates-june-2026/>)

### 주제 추적과 원격 실행

이메일뿐 아니라 블로그·뉴스·소셜 미디어·금융·쇼핑·날씨·스포츠의 주제를 추적하고 사건에 반응하는 기능을 제공한다.

휴대폰에서 다단계 작업을 지정해 Mac이 원격으로 실행하는 기능은 이후 제공할 예정이다. Google은 Mac의 매출 보고서를 찾아 금액을 추출하고 이메일로 보내는 작업을 예로 들었다. [원문 1](<https://blog.google/innovation-and-ai/products/gemini-app/gemini-spark-updates-june-2026/>)
