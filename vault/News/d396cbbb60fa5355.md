# AWS, Bedrock과 Claude Platform에 Sonnet 5 제공


AWS는 2026년 7월 1일(한국시간) Anthropic의 Claude Sonnet 5를 Amazon Bedrock과 Claude Platform on AWS에서 제공한다고 발표했다. Bedrock에서는 지원 AWS 리전에서, Claude Platform on AWS에서는 북미·남미·유럽·아시아태평양에서 사용할 수 있다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/introducing-claude-sonnet-5-on-aws-anthropics-most-capable-sonnet-model/>)

### AWS 청구·인증과 통합한 Anthropic 플랫폼

Claude Platform on AWS는 AWS Management Console에서 Anthropic의 네이티브 API·기능·콘솔 환경을 제공한다. AWS 청구와 인증을 함께 사용할 수 있다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/introducing-claude-sonnet-5-on-aws-anthropics-most-capable-sonnet-model/>)

### API와 콘솔에서 모델 사용

개발자는 Anthropic Messages API 또는 Bedrock의 Invoke·Converse API로 Sonnet 5를 호출할 수 있다. Anthropic SDK와 AWS CLI·AWS SDK가 프로그램 접근 도구로 제공된다.

Amazon Bedrock 콘솔에서는 Test 메뉴의 Playground를 열어 Claude Sonnet 5를 선택할 수 있다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/introducing-claude-sonnet-5-on-aws-anthropics-most-capable-sonnet-model/>)
