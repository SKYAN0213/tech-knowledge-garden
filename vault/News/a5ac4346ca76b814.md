# NVIDIA, 결함 검사·도시 영상·작업 검증용 비전 AI 구현 지침 공개


NVIDIA는 2026년 6월 30일(한국시간) 합성 결함 이미지 생성·영상 데이터 보강·TAO 미세 조정·영상 검색과 요약을 연결하는 비전 AI 구현 지침을 공개했다. 카메라와 장비 가까이에서 동작하는 에이전트의 지연시간·전력·비용·연결성·현장 조건을 고려해 학습 데이터 생성부터 모델 조정과 배포까지 구성한다. [원문 1](<https://blogs.nvidia.com/blog/vision-ai-agent-skills-omniverse-metropolis/>)

### 실제 결함 이미지와 합성 데이터

NVIDIA는 Roboflow가 Defect Image Generation skill과 Cosmos를 비전 AI 플랫폼에 통합해 실제 학습 자료가 부족할 때 Corning 같은 고객을 위한 합성 결함 이미지를 만드는 사례를 소개했다.

회사에 따르면 Corning의 광섬유 제조 엔지니어링팀과 진행한 벤치마크에서 실제 결함 이미지 8개를 합성 데이터로 보강해 학습한 모델은 가장 어려운 결함 종류에서 평균 정밀도 95%와 완전한 재현율을 얻었다. [원문 1](<https://blogs.nvidia.com/blog/vision-ai-agent-skills-omniverse-metropolis/>)

### 도시 환경을 만들고 영상 작업을 연결

OpenUSD는 3D 세계를 기술·합성·재사용하는 공통 구조이며, 이를 기반으로 한 Omniverse는 조명·날씨·교통·카메라 각도·가림 조건을 달리한 시뮬레이션과 합성데이터·디지털 트윈을 구성한다.

Linker Vision 사례는 VSS로 검색·요약·알림·보고·스트림 관리를 구성하고, Omniverse 디지털 트윈으로 도시 환경을 시험하며, Cosmos로 영상을 보강하고 TAO로 모델을 미세 조정한다. NVIDIA는 가오슝 사례의 개발 작업량이 85%, 사고 대응 시간이 최대 80% 줄었다고 소개했다. [원문 1](<https://blogs.nvidia.com/blog/vision-ai-agent-skills-omniverse-metropolis/>)

### 작업 순서와 표준 절차 확인

Foxconn에서 사용하는 DeepHow의 Live SOP Verification agent는 Metropolis VSS로 영상 검색·요약·분석을 수행하고 Cosmos로 조립 동작과 순서가 표준 작업 절차에 맞는지 해석한다.

NVIDIA는 GB300 서버 생산 라인 사례에서 초회 통과 수율이 3% 개선됐고, 핵심 작업 단계의 미세 동작을 이해하는 과제 수준 정확도가 99%였다고 밝혔다. [원문 1](<https://blogs.nvidia.com/blog/vision-ai-agent-skills-omniverse-metropolis/>)
