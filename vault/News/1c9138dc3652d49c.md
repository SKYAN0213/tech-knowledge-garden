# GitHub Copilot 사용 지표, 조직이 설정한 사용자 지정 항목 이름 표시


GitHub은 한국시간 2026년 10월 23일 공개한 변경으로 GitHub Copilot 사용 지표에 조직이 만든 skills, custom agents, MCP servers, slash commands, plugins의 설정 이름을 other나 custom 대신 표시한다. 이름은 기업·조직의 사용자별 1일·28일 및 집계 1일 보고서와 집계 28일 보고서의 day\_totals 등에 반영되며, 각 totals\_by\_* 배열은 레코드당 최대 25개 항목으로 늘어 종전 5개를 넘는 나머지 활동은 끝의 other 항목에 합쳐진다. API 보고서는 enterprise owners와 billing managers, organization owners, 또는 View Copilot Metrics 권한을 부여하는 custom organization·enterprise role을 가진 사용자가 이용할 수 있으며 Copilot 사용 지표 정책이 켜져 있어야 한다. [원문 1](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)

### 보고서에 반영되는 범위

이름별 집계 배열은 totals\_by\_skill, totals\_by\_custom\_agent, totals\_by\_mcp, totals\_by\_slash\_cmd, totals\_by\_plugin이다. interaction\_count와 distinct\_*\_use\_count 필드는 이전과 같은 방식으로 계산된다. [원문 1](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)

### 이름 수집 조건

이름은 Copilot CLI 대화형 세션과 prompt mode, GitHub Copilot 앱, JetBrains 같은 ACP 연동, Copilot SDK에서 보고된다. prompt mode·앱·ACP에는 Copilot CLI 1.0.97 이상이, SDK에는 v1.0.21 이상이 필요하다. IDE는 agent 경험이 Copilot SDK v1.0.21 이상에서 실행될 때 이름을 보고하며 IDE 내장 채팅 telemetry에서는 이름을 보고하지 않는다. [원문 1](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)

### 표시와 해석의 한계

이름은 설정된 표기를 바탕으로 최대 128자로 자르며, 파일 경로처럼 보이는 이름은 other나 custom으로 계속 묶인다. 조직 밖에 보고서를 공유하기 전에 이름을 검토해야 한다.

이름은 이 릴리스 이후 처리된 보고일에만 나타나며 이전 날짜에는 other나 custom이 남는다. 클라이언트가 오래됐거나 telemetry가 차단되면 활동이 과소 집계될 수 있어 정확한 회계가 아니라 추세와 도입 현황을 보는 데 사용하도록 안내됐다. [원문 1](<https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api>)
