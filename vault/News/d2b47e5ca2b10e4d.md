# ScarfBench, Java 프레임워크 이전을 빌드·배포·동작으로 평가


ScarfBench 개발진은 2026년 7월 1일(한국시간) 엔터프라이즈 Java 프레임워크 간 이전 작업을 수행하는 AI 에이전트의 공개 평가 도구 ScarfBench를 소개했다. 변환된 애플리케이션이 빌드되고 배포되며 기존 동작을 유지하는지를 평가한다. [원문 1](<https://huggingface.co/blog/ibm-research/scarfbench>)

### 이전 작업과 평가 범위

Spring·Jakarta EE·Quarkus 간 이전을 대상으로 개별 작업과 전체 애플리케이션 이전을 다룬다. 개발진은 JSR 기반 엔터프라이즈 Java 분류 체계에서 출발해, 전문가가 프레임워크별로 이전한 검증 구현을 만들었다고 설명했다. [원문 1](<https://huggingface.co/blog/ibm-research/scarfbench>)

### 자체 성공 보고와 독립 빌드 검증

개발진의 평가에서 Claude Code는 전체 애플리케이션 30개 중 29개의 빌드 성공을 보고했다. 성공했다고 보고한 29개 중 실제로 빌드에 성공한 것은 22개였으며, 에이전트가 실패로 분류한 애플리케이션 하나는 최종적으로 빌드에 성공했다. [원문 1](<https://huggingface.co/blog/ibm-research/scarfbench>)

### 작업 경로와 환경 문제

개발진은 Configuration·Web·Database·Service 계층을 가장 자주 방문했으며, Configuration과 Web, Service와 Database 사이의 이동이 흔했다고 보고했다.

Docker 캐시 불일치, 포트 연결, Maven wrapper와 빌드 도구 문제도 관찰했다. 개발진은 이런 환경 문제가 소스 코드 이전이 상당 부분 완료된 경우에도 검증을 지연시키곤 했다고 설명했다. [원문 1](<https://huggingface.co/blog/ibm-research/scarfbench>)

### 공개 자료

공개 자원에는 벤치마크 데이터셋·평가 인프라·리더보드·문서·오픈소스 코드가 포함된다. [원문 1](<https://huggingface.co/blog/ibm-research/scarfbench>)
