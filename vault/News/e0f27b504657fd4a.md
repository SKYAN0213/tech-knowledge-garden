# AWS, S3 PDF를 MCP 도구로 읽는 구현 예제 공개


AWS는 2026년 6월 26일(한국시간) Amazon S3의 PDF를 필요할 때 읽어 AI 도우미에 전달하는 MCP 서버 구현 글을 공개했다. 예제는 텍스트가 포함된 PDF를 대상으로 하며, Kiro CLI에서 문서를 요청하는 개발·개념검증 환경을 다룬다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-interactive-pdf-text-extraction-from-amazon-s3/>)

### 요청과 결과의 흐름

클라이언트가 S3 버킷 이름과 객체 키를 전달하면 MCP 서버가 PDF를 내려받고 텍스트를 추출해 반환한다. CLI·MCP 통신 계층·서버·S3가 구성 요소이며 IAM이 S3 접근을 제어한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-interactive-pdf-text-extraction-from-amazon-s3/>)

### 예제 도구의 구현

Python 예제의 extract\_s3\_pdf\_text 도구는 bucket·key를 필수 입력으로 받는다. boto3로 파일을 가져오고 PyPDF2의 PdfReader로 페이지별 텍스트를 읽은 뒤 MCP TextContent로 반환한다.

Kiro CLI의 MCP 설정에는 Python으로 실행할 서버 파일 경로를 등록한다. 서버 예제는 임시 파일을 사용하고 처리가 끝나면 해당 파일을 삭제한다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-interactive-pdf-text-extraction-from-amazon-s3/>)

### 문서와 접근 범위

AWS는 기존 AWS 자격 증명을 사용하고 PDF가 있는 특정 버킷에 읽기 권한만 부여하도록 설명했다. 추출은 요청 시 수행하며, S3 접근 요청은 CloudTrail에 기록된다는 안내다.

이 예제는 PDF에 포함된 텍스트를 읽으며 OCR·표 구조 복원·폼 추출은 수행하지 않는다. AWS는 스캔 문서, 복잡한 레이아웃과 대규모 운영 처리를 Textract의 적용 범위로 구분했다. [원문 1](<https://aws.amazon.com/blogs/machine-learning/build-interactive-pdf-text-extraction-from-amazon-s3/>)
