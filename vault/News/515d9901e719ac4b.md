# Amazon EMR, EKS 추가 요금 30% 인하


Amazon EMR은 2026년 10월 23일 EMR on EKS 실행 시 EKS 요금에 추가되는 EMR 요금을 30% 인하한다고 발표했다. 인하 대상은 vCPU-hour당 요금과 GB-hour당 요금이며, 기본 Amazon EKS 요금은 그대로다. 인하는 EKS 배포 옵션에서 실행되는 모든 EMR 워크로드에 적용되며, 새 가격은 별도 조치 없이 자동 적용된다. 인하된 요금은 Amazon EMR on EKS를 이용할 수 있는 모든 AWS 리전에서 제공된다.
