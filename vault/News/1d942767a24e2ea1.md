# GitHub, 저장소 push 이메일 알림 종료…자체 메일 발송 방식 안내


GitHub는 한국시간 2026년 10월 15일 게시한 안내에서 repository push events 이메일 알림이 10월 15일 현재 폐기돼 더 이상 발송되지 않는다고 밝혔다. 회사는 수신자 동의 없이 이메일이 발송될 수 있어 스팸·남용을 막기 위해 기능을 종료했으며, 자사 이메일 인프라를 통한 원치 않는 메시지 전송에 악용될 가능성이 있었다고 설명했다. 계속 알림을 보내려는 사용자는 push 이벤트로 실행되는 GitHub Actions workflow에서 자체 SMTP 서버나 이메일 제공자를 이용할 수 있다고 GitHub는 안내했다.
