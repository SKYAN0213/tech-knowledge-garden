# npm, 중요 계정의 이메일 변경·복구 코드 사용 뒤 72시간 읽기 전용 보호


npm은 2026년 6월 26일(한국시간), 널리 사용되는 패키지를 담당하는 중요 계정에 예방적 보호 기능을 도입했다. 이메일 변경이나 2단계 인증 복구 코드 사용을 감지하면 계정을 72시간 읽기 전용으로 바꾸고 이전 이메일 주소에 알림을 보낸다. [원문 1](<https://github.blog/changelog/2026-06-25-npm-adds-preventive-account-protection-for-high-impact-accounts/>)

### 보호 중 유지되는 작업

보호 기간에도 패키지 설치·다운로드, 조직과 팀 조회, 계정·패키지 설정 열람은 가능하다. 해당 계정이 담당하는 패키지도 이용자에게 계속 제공된다. [원문 1](<https://github.blog/changelog/2026-06-25-npm-adds-preventive-account-protection-for-high-impact-accounts/>)

### 잠시 중지되는 권한

패키지 발행, 토큰 관리, 패키지 공개 범위 변경, 조직·팀 구성원 변경처럼 레지스트리나 계정 보안에 영향을 주는 작업은 보호가 끝날 때까지 중지된다.

72시간이 지나면 추가 확인 절차 없이 정상 권한으로 자동 복귀한다. npm은 계정 탈취 뒤 이메일을 바꾸고 새 토큰으로 악성 버전을 배포하는 공격 경로에 대응하는 조치라고 설명했다. [원문 1](<https://github.blog/changelog/2026-06-25-npm-adds-preventive-account-protection-for-high-impact-accounts/>)
