# OpenAI·Broadcom, LLM 추론 칩 Jalapeño 시제품 공개…연말 초기 배치 계획


OpenAI와 Broadcom은 2026년 6월 24일(한국시간), 대규모 언어 모델의 추론을 위해 설계한 가속기 Jalapeño를 공개했다. Broadcom 발표에 따르면 엔지니어링 시제품은 연구실에서 목표 주파수·전력으로 모델 작업을 실행하고 있으며, 여러 세대에 걸친 플랫폼의 초기 배치는 2026년 말까지 진행할 계획이다. [원문 1](<https://investors.broadcom.com/news-releases/news-release-details/openai-and-broadcom-unveil-llm-optimized-intelligence-processor>)

### 칩과 시스템의 역할

OpenAI는 모델·커널·서빙 구조에 맞춰 칩을 설계하고, Broadcom은 실리콘 구현·네트워킹을, Celestica는 보드·랙·시스템 통합을 맡는다. 설계는 데이터 이동을 줄이고 연산·메모리·네트워크 자원의 균형을 맞추는 방향이다. [원문 1](<https://investors.broadcom.com/news-releases/news-release-details/openai-and-broadcom-unveil-llm-optimized-intelligence-processor>)

### 개발 기간과 초기 평가

양사는 초기 설계부터 제조용 설계 확정인 테이프아웃까지 9개월이 걸렸으며, 설계·최적화 일부에 OpenAI 모델을 활용했다고 밝혔다. 시제품 공개와 데이터센터 배치 계획은 별개 단계다.

와트당 성능 개선은 초기 시험에 근거한 회사의 설명이다. 최종 성능 측정은 진행 중이며 구체적 기술 보고서를 추후 공개할 예정이라고 밝혔다. [원문 1](<https://investors.broadcom.com/news-releases/news-release-details/openai-and-broadcom-unveil-llm-optimized-intelligence-processor>)
