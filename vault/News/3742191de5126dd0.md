# Cadence, 설계 사양을 RTL로 만드는 에이전트 공개…4분기 제한 제공


Cadence는 한국시간 2026년 9월 22일 자연어 설계 사양에서 RTL 코드를 생성하고 전력·성능·면적(PPA)을 최적화하는 ChipStack RTL Generation Agent를 발표했다. 새 기능은 기존 RTL을 새로운 설계 요구에 맞춰 수정하고 기능과 PPA를 분석·검증한다. 확대된 ChipStack·InnoStack 기능은 2026년 4분기 일부 조기 접근 고객에게 제공할 예정이다. [원문 1](<https://fwnbc.marketminute.com/article/bizwire-2026-9-22-cadence-expands-chipstack-ai-super-agent-with-a-new-agent-for-rtl-generation-and-early-ppa-optimization>)

### 에이전트와 설계 도구의 역할

Cadence는 상위 super agent가 작업별 에이전트를 조율하고, 각 에이전트가 EDA 소프트웨어를 사용하는 구조라고 설명했다. [원문 1](<https://fwnbc.marketminute.com/article/bizwire-2026-9-22-cadence-expands-chipstack-ai-super-agent-with-a-new-agent-for-rtl-generation-and-early-ppa-optimization>)

### Honda R&D의 초기 평가

Honda R&D는 자동차용 SoC에서 에이전트를 평가하며, 설계 사양부터 RTL 개발까지의 생산성을 높이는 작업을 진행하고 있다고 밝혔다. [원문 1](<https://fwnbc.marketminute.com/article/bizwire-2026-9-22-cadence-expands-chipstack-ai-super-agent-with-a-new-agent-for-rtl-generation-and-early-ppa-optimization>)

### 기반 모델과 비교한 회사 평가

Cadence는 초기 평가에서 기반 모델만으로 코드를 생성한 경우와 비교해 평균 면적이 24%, 전력이 18% 줄었다고 발표했다. [원문 1](<https://fwnbc.marketminute.com/article/bizwire-2026-9-22-cadence-expands-chipstack-ai-super-agent-with-a-new-agent-for-rtl-generation-and-early-ppa-optimization>)
