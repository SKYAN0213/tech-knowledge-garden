# Dependabot, 개인 토큰 없이 비공개 GitHub Packages 접근 지원


GitHub는 9월 8일 Dependabot이 개인 액세스 토큰 없이 비공개 GitHub Packages를 읽는 기능을 다시 활성화했다고 공지했다. 패키지 설정에서 저장소에 부여한 읽기 권한을 Dependabot의 GITHUB\_TOKEN이 재사용한다. 6월 최초 제공 후 npm 패키지 경로 충돌로 철회했던 기능으로, 재활성화 버전에서는 명시적인 레지스트리 인증과 기존 경로를 우선하고 자동 인증을 보조 수단으로 사용한다. [원문 1](<https://github.blog/changelog/2026-09-08-automatic-dependabot-access-to-github-hosted-registries/>)

### 패키지에서 읽기 권한을 부여

패키지 설정의 Manage Actions access에서 Dependabot을 실행하는 저장소에 Read 권한을 부여한다. 해당 패키지는 dependabot.yml을 바꾸지 않고 읽을 수 있으며, 이 패키지용으로 추가했던 PAT 레지스트리 설정은 제거할 수 있다고 GitHub는 안내했다. [원문 1](<https://github.blog/changelog/2026-09-08-automatic-dependabot-access-to-github-hosted-registries/>)

### 적용되는 레지스트리

Dependabot은 *.pkg.github.com과 ghcr.io에서 패키지를 가져올 때 GITHUB\_TOKEN을 전달한다. GitHub Packages 중 Dependabot이 지원하는 모든 생태계에 적용된다. [원문 1](<https://github.blog/changelog/2026-09-08-automatic-dependabot-access-to-github-hosted-registries/>)
