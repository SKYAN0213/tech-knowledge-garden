# 코딩 에이전트 탐지 연구, 저장소 파일·커밋·계정 신호를 함께 대조


연구진은 2026년 6월 23일 arXiv에, 1억8천만 개 이상 Git 저장소에서 AI 코딩 에이전트의 흔적을 여러 방식으로 탐지하는 사전공개 논문을 제출했다. v1 초록은 설정 파일·커밋 메시지·작성자 식별·봇 서명을 결합하고 탐지 유형에 따라 활동을 분류했다고 설명한다. [원문 1](<https://arxiv.org/abs/2606.24429v1>)

### 한 가지 신호로 찾은 커밋의 비율

한 스냅샷에서 여러 탐지 방법으로 찾은 Claude Code 커밋은 850,157개였고, 봇 계정 조회로 회수한 것은 28,154개(3.3%)였다. 이는 해당 표본에서 탐지 방식별 회수량을 비교한 수치다.

연구진은 탐지 패턴을 495개 수작업 라벨로 검증했다. PR 조사와 커밋 탐지가 서로 다른 도입 집단과 작업을 잡아내며, 관찰된 작업 구성은 도구 자체뿐 아니라 배포·탐지 방식에 영향을 받는다고 초록은 설명한다. [원문 1](<https://arxiv.org/abs/2606.24429v1>)
