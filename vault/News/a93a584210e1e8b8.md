# Amazon SageMaker AI, 서버리스 모델 맞춤화에 학습 세션 API 추가


Amazon SageMaker AI는 2026년 10월 22일 서버리스 모델 맞춤화에 학습 세션 API를 지원한다고 발표했으며, 고객은 GPU 인프라를 직접 프로비저닝하거나 관리하지 않고 추가 학습(post-training) 알고리즘을 제어할 수 있다. 고객은 라이브 상태형 세션에서 자체 학습 루프와 연산 호출을 구성하고, SageMaker AI는 GPU 할당, 모델·LoRA 로딩, 분산 실행, 장애 복구, 체크포인트 저장과 보안을 처리한다. 요금은 처리 토큰 기준으로 부과돼 보상 점수 계산 같은 로컬 연산은 GPU 시간으로 청구되지 않으며, API는 미국 동부(버지니아 북부), 미국 서부(오리건), 아시아 태평양(뭄바이)에서 일반 제공된다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/training-session-apis-on-sagemaker-ai>)

### 학습 연산과 재개

고객은 Python 코드에서 forward\_backward(), optim\_step(), sample()을 호출해 상태가 유지되는 세션의 학습 루프를 구성할 수 있다. 강화학습, 지도 미세조정 또는 자체 학습 목표를 구동할 수 있고, 체크포인팅과 재개 기능도 제공된다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/training-session-apis-on-sagemaker-ai>)

### 학습 레시피

Amazon SageMaker AI는 고객이 자체 학습 루프의 청사진으로 활용할 수 있는 실행 준비된 SFT 및 강화학습 레시피를 담은 트레이닝 세션 쿡북도 공개한다. [원문 1](<https://aws.amazon.com/about-aws/whats-new/2026/10/training-session-apis-on-sagemaker-ai>)
