# Google Cloud Data Agent Kit 정식 제공…Bigtable·Spark 지원 추가


Google Cloud는 9월 30일 Data Agent Kit를 정식 제공하고 BigQuery Graph, Bigtable, Managed Service for Apache Spark 지원을 추가했다. 이 도구 묶음은 15개가 넘는 데이터 서비스의 스키마와 작업 로그를 읽고 쿼리·리소스 관리를 수행하며, 사용자의 IAM 권한을 따른다고 회사는 설명했다. 키트 자체는 무료지만 에이전트가 호출하는 클라우드 서비스 비용은 별도다. [원문 1](<https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/>)

Google은 그래프 관계를 만들기 전 계획을 검토하고, Bigtable 스키마 제안에서 핫스폿·전체 테이블 스캔 위험을 확인하도록 했다고 밝혔다. 실제 데이터 생성·수정 권한도 연결되므로 승인 전 쿼리와 변경안을 검토해야 한다. [원문 1](<https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/>)
