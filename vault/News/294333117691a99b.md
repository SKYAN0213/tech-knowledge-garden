# Google Cloud Data Agent Kit 정식 제공…Bigtable·Spark 지원 추가


Google Cloud는 9월 30일 Data Agent Kit을 정식 제공하며 BigQuery Graph·Bigtable·Managed Service for Apache Spark 지원을 추가했다. MCP 도구와 에이전트 skills를 통해 기존 코딩 에이전트가 Google Cloud 데이터 제품을 사용하도록 하는 구성이다. 도구 묶음 자체는 무료지만 실제 클라우드 서비스 사용에는 표준 요금이 적용된다. [원문 1](<https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/>)

### 사용자·서비스 계정 권한을 따르는 데이터 접근

에이전트는 사용자 본인이나 impersonate한 서비스 계정으로 연결하며 행·열 보안 정책을 적용받는다. 회사는 관리자가 IAM으로 접근을 관리하고 Model Armor로 MCP 트래픽을 검사하며 VPC Service Controls와 Principal Access Boundary로 범위를 제한할 수 있다고 설명했다. [원문 1](<https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/>)

### 쿼리 실행 전 비용 점검

skills는 파티션 키 확인과 BigQuery 쿼리의 dry run처럼 전체 테이블을 불필요하게 스캔하지 않는 방법을 안내한다. 에이전트가 이용한 클라우드 서비스의 사용료는 Data Agent Kit의 무료 제공과 별개다. [원문 1](<https://cloud.google.com/blog/topics/developers-practitioners/data-agent-kit-is-now-ga-bring-google-data-cloud-to-any-coding-agent/>)
