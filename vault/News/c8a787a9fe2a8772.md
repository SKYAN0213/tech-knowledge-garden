# Microsoft, Copilot 대화에 SPFx 업무 화면을 띄우는 SharePoint Copilot Apps 소개


Microsoft는 2026년 6월 23일(한국시간), SharePoint Framework(SPFx) 구성요소를 Copilot 캔버스에 표시하는 SharePoint Copilot Apps를 소개했다. MCP Apps 모델을 바탕으로 대화 안에서 업무 화면을 열고 동작을 수행하도록 하며, 같은 구성요소를 Copilot·SharePoint·Teams에 재사용할 수 있다고 설명했다. [원문 1](<https://devblogs.microsoft.com/microsoft365dev/going-beyond-text-in-microsoft-365-copilot-introducing-sharepoint-copilot-apps/>)

### 개발과 호스팅

SPFx는 React·Angular·Vue·Svelte·TypeScript 등 웹 개발 기술을 지원한다. 구성요소는 Microsoft 365 고객 테넌트에 자동 호스팅되고, 플랫폼이 요청을 해당 도구로 전달하는 구조라고 Microsoft는 설명했다. [원문 1](<https://devblogs.microsoft.com/microsoft365dev/going-beyond-text-in-microsoft-365-copilot-introducing-sharepoint-copilot-apps/>)

### 최초 일정과 이후 수정

최초 글은 SPFx v1.24 프리뷰와 함께 7월 초 프리뷰를 제공하고 가을에 일반 제공을 순차 진행할 계획을 제시했다.

9월 23일 추가한 문구에서는 명칭을 UX components in Copilot으로 바꾸고, SPFx 1.24에 포함해 2026년 10월부터 일반 제공할 계획이라고 안내했다. [원문 1](<https://devblogs.microsoft.com/microsoft365dev/going-beyond-text-in-microsoft-365-copilot-introducing-sharepoint-copilot-apps/>)
