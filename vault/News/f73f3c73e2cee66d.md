# Proofpoint, 데이터·AI 보안을 묶는 세 가지 에이전트 발표


Proofpoint는 9월 22일 데이터 보호와 AI 사용 통제를 결합한 Agentic Data and AI Security 기능을 발표했다. 탐지·조사·대응 에이전트가 신원·접근·데이터·행동·의도를 연결한 공통 그래프를 활용하도록 설계됐다. 제공 시점은 2026년 말까지로 예고했다. [원문 1](<https://www.proofpoint.com/us/newsroom/press-releases/proofpoint-breaks-down-divide-between-data-security-and-ai-security>)

### 자연어 업무 정책과 실행 통제 연결

회사는 자연어 업무 정책의 의도를 해석해 실행 통제를 생성하고, AI 상호작용과 도구 사용·정책 결정을 조사하도록 설계했다고 설명했다. 대응 과정에는 접근 권한 조정·DLP 정책 최적화와 사람의 검토를 포함한다. [원문 1](<https://www.proofpoint.com/us/newsroom/press-releases/proofpoint-breaks-down-divide-between-data-security-and-ai-security>)
