# 안랩, PHP 식별 결과 ‘약 11만 개’의 집계 기준과 해석 범위 설명


2026년 10월 22일 안랩은 앞선 글의 ‘국내 PHP 서버 IP 약 11만 개’가 A사에서 ‘PHP’로 식별한 검색 결과 건수이지 국내 웹사이트 수나 취약점에 노출된 서버 수가 아니라고 설명했다. 안랩 ASEC은 미국·한국·중국의 민간 인터넷 자산 검색 서비스 3곳에서 PHP 사용 서비스를 조회했으며, A·B·C사 전체 검색 결과는 각각 3,035,754건·852,802건·19,093,049건이었다고 밝혔다. 안랩에 따르면 한국 검색 결과는 B사가 47,209건으로 4위, C사가 2,848,656건으로 13위였다. 안랩은 해당 취약점이 지원 중인 PHP 8.2\~8.5와 지원이 끝난 구버전 등 사실상 대부분의 PHP 버전에 영향을 미치며, 보안 업데이트를 적용하지 않은 서버는 국내외에서 공격 대상이 될 수 있다며 운영자에게 사용 버전을 확인하고 즉시 최신 보안 버전으로 업데이트하라고 권고했다. ### 검색 서비스마다 집계 단위가 다르다

안랩은 국가·지역별 상위 20개 결과도 제시했으며, 서비스마다 집계 기준이 다르므로 숫자는 같은 서비스 안에서만 비교해야 한다고 설명했다. 검색 결과 한 건은 서비스에 따라 IP 주소 하나, IP와 포트의 조합 또는 개별 도메인을 뜻할 수 있다.

공유 호스팅에서는 서버 한 대를 여러 웹사이트가 함께 쓰고 도메인마다 결과가 따로 잡힐 수 있어 비슷한 검색 조건에서도 서비스별 결과가 몇 배씩 차이 날 수 있다. 검색 범위와 조회 시점도 달라 서비스 간 수치를 비교하거나 합산하는 것은 적절하지 않다고 안랩은 설명했다. [원문 1](<https://asec.ahnlab.com/ko/95982/>)

여기서 ‘국내’는 검색 서비스의 국가 위치 정보로 분류한 결과를 뜻하며, 국내 기업·기관이 운영하는 사이트 전체를 가리키지 않는다. 검색 조건에는 PHP 버전이나 취약 여부를 확인하는 기준도 없어 특정 취약점에 영향을 받는 서버 수로 볼 수 없다고 안랩은 밝혔다. [원문 1](<https://asec.ahnlab.com/ko/95982/>)
