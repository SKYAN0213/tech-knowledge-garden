# GitHub, npm 패키지 방화벽 공개 미리보기 제공


2026년 10월 21일(한국시간) GitHub는 데이터 레지던시 적용 환경을 포함한 모든 GitHub Enterprise Cloud 고객에게 패키지 방화벽을 공개 미리보기로 제공한다고 밝혔다. 방화벽은 Actions 실행기나 코딩 에이전트 같은 엔드포인트와 패키지 저장소 사이에서 메타데이터 요청과 패키지 다운로드를 검사하며, 현재 npm 패키지만 지원한다. 엔드포인트는 저장소에 직접 연결하는 대신 방화벽을 사용하도록 구성해야 하며, 요청은 설정된 정책으로 평가되고 오탐으로 차단된 패키지에는 예외를 요청할 수 있다. GitHub는 미리보기 기간에는 무료로 제공하고 정식 출시 후에는 Actions와 비슷한 사용량 기준으로 과금할 예정이라고 밝혔다. [원문 1](<https://github.blog/changelog/2026-10-20-github-package-firewall-in-public-preview>)

### 설정할 수 있는 정책

관리자는 대기 기간(cooldown) 조정, GitHub Advisory Database의 악성코드·취약점 경보 확인, 검증 증명(attestation)의 수준이 낮아졌는지 확인하는 공급망 점검을 정책으로 설정할 수 있다. [원문 1](<https://github.blog/changelog/2026-10-20-github-package-firewall-in-public-preview>)
