# npm, 패키지 하나에 여러 OIDC 배포 설정 지원


GitHub는 9월 3일 npm 패키지 하나에 여러 OIDC 기반 신뢰 배포 설정을 등록하는 기능을 정식 제공했다. 각 설정에 저장소·워크플로·환경 조건을 지정하며, 들어온 토큰이 어느 한 설정과 일치하면 게시 또는 게시 대기가 허용된다. 게시 대기 패키지는 악성코드 검사가 끝난 뒤 승인할 수 있고, 관리자는 버전 탭에서 승인·거부·대기 이력을 확인할 수 있다. [원문 1](<https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/>)

### 게시 대기가 기본, 즉시 게시는 구성별 선택

각 신뢰 배포 구성은 기본적으로 패키지를 게시 대기 상태로 올릴 수 있다. 즉시 게시는 구성별로 별도 허용해야 하며, 게시 대기 방식에는 버전이 레지스트리에 공개되기 전 사람의 승인 단계가 있다. [원문 1](<https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/>)

### 여러 구성은 서로를 제한하지 않는다

구성은 독립적으로 추가되며 다른 구성의 권한을 제한하지 않는다. 평가 순서도 보장하지 않으므로 특정 구성이 먼저 일치한다는 조건에 의존해 배포 로직을 작성할 수 없다. [원문 1](<https://github.blog/changelog/2026-09-03-multiple-trusted-publishing-configurations-for-npm/>)
